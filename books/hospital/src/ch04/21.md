# 4.1 组织结构：院长、职能部门与临床科室

挂号记录上写着“呼吸内科”，导诊图上却还列着检验科、放射科、药房和收费窗口。读者容易把医院理解为一排科室：进哪扇门，就由哪个科室负责。可如果检查设备需要维修、药品需要补充、门诊临时调整诊室，谁来协调？医院的组织结构，正是回答“谁决定、谁执行、谁负责协调”的一张工作地图。

## 4.1.1 院长管理的不是每一项诊疗决定

在中国，医院的举办主体和管理形式并不完全相同。以公立医院为例，按照中国现行制度要求，公立医院实行**党委领导下的院长负责制**：医院党委发挥领导作用，院长在其职责范围内负责医疗、教学、科研和行政管理等工作。民营医院的治理安排则取决于其举办和法人治理结构，不能照搬公立医院的称谓与分工。

院长的工作也不是逐一批准医生开出的检查申请。医院管理层要考虑的是全院层面的事项：怎样配置人员与场地，怎样维持服务连续性，怎样落实质量与安全要求，以及有限的经费应优先支持哪些工作。具体诊疗由具备相应资质的医务人员依据专业规范实施；管理者提供资源、明确责任并监督制度运行。把管理权与专业判断分开，才能理解医院为什么既需要院长，也需要各科室的专业负责人。

## 4.1.2 职能部门：让全院遵循共同规则

假设一位虚构的患者在门诊完成检查后需要住院。门诊、病区、检查部门都参与了这一过程，但病床调配、病历管理、护理安排和费用结算不能只靠几个科室临时商量。医院通常设置职能部门，处理跨科室的共同事务。

不同医院的部门名称和划分会变化，常见职责可以这样理解：

| 职责方向 | 常见工作 |
| --- | --- |
| 医疗管理与质量 | 协调医疗工作，推动诊疗规范、病历质量和医疗安全管理 |
| 护理管理 | 组织护理人员配置、培训和护理质量管理 |
| 人事与财务 | 负责人员管理、预算、成本及会计等事务 |
| 信息、设备与后勤 | 维护信息系统、医疗设备、建筑设施与物资保障 |

感染防控、药事管理等工作也有专门的管理要求，具体由哪些部门承担，要看医院的组织设置。职能部门好比连接各个车间的轨道和信号系统：它们通常不替代一线人员完成诊疗，却让不同科室能按相容的规则工作。例如，全院统一的身份核对要求，不能只在某一个病区有效；信息系统停机时的应对流程，也需要多个部门事先约定。

## 4.1.3 临床科室：围绕患者承担专业责任

读者最熟悉的是临床科室，如内科、外科、儿科等。科室通常依据服务对象、疾病领域或诊疗方式划分，具体设置随医院类型和规模而异。科主任等负责人组织本科室的医疗、教学和质量管理工作；病区的护理工作还需要护士长组织。负责管理，并不意味着负责人亲自完成科室里的每一次诊疗。

科室划分让人员积累专长，也形成清晰的责任范围；但患者的问题未必刚好落在一条科室边界内。一位患者可能在门诊就诊，由检验科完成检测，再回到医生处解读结果。此时，临床科室负责把检查结果放回患者的整体情况中判断，医技科室则对其承担的检查流程和结果质量负责。两者不是上下级关系，而是不同专业职责在同一条服务链上衔接。

## 4.1.4 看组织图，更要看连接处

医院的组织图常画成树：上面是领导与管理部门，下面是各科室。这张图能回答“归谁管理”，却不能独自回答“患者怎样完成一次就诊”。真实工作还需要横向连接：门诊诊室要与检查部门衔接，病区要与药房、后勤和信息部门配合；遇到跨专业问题时，相关科室也需要共同讨论。

因此，读医院组织结构，可以同时问两个问题：**纵向上，谁为人员、资源和质量负责？横向上，一项工作跨过科室边界时，谁来交接与协调？**挂号记录只标出患者进入医院系统的一扇门。门后的诊疗能够持续运转，靠的是专业分工，也靠管理部门与科室之间稳定的连接。这条连接落到具体工作中，就是医生、护士、药师和技师之间的协作。
