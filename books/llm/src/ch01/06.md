# 1.3 大语言模型的边界：模型本体、对话产品与智能体

打开手机上的 AI 对话应用，你问它“明天北京会下雨吗”，它可能先显示“正在搜索”，然后给出一段带来源链接的回答。再上传一张发票照片，它能读出金额；让它“把这些整理成表格发到我邮箱”，有的产品甚至真的会去做。看上去，这一切都是“大模型”的本事。

可如果你把一个开源模型文件下载到自己电脑上，用命令行直接运行它，再问同样的问题，它既不会联网搜索，也不会发邮件，只会根据训练时学到的东西“猜”出一段文字，有时还会编一个看似合理的天气预报。

同样叫“大模型”，表现差别这么大，是因为我们日常说的“大模型”其实混着三样东西：**模型本体、对话产品和智能体**。分清它们的边界，是看懂后面所有章节的前提。

## 1.3.1 模型本体——一个只会“接着写”的函数

上一节打开的模型文件，就是模型本体。从功能上说，它是一个很大的数学函数：输入一串令牌（Token，即模型处理文字的基本单位），输出“下一个令牌是什么”的概率分布。反复调用这个函数，每次把选出的令牌接到末尾，就能生成一整段文字。

模型本体有几个硬边界：

- **没有感官**：它不能自己上网、看时钟、读你的文件，只能看到输入给它的那串令牌。
- **知识有截止点**：它“知道”的东西来自训练数据，训练数据收集截止之后的事，它一概不知。这个时间点通常叫“知识截止日期”（knowledge cutoff）。
- **没有跨对话记忆**：每次运行都从零开始，上一次聊过什么，除非重新放进输入，否则它完全不记得。
- **不会行动**：它的输出只是文字。哪怕它写出“我已经帮你发送了邮件”，也只是生成了这几个字，并没有真的发生什么。

一个直观类比：模型本体像一位读过海量书籍、却被关在没有窗户房间里的写作者。你从门缝塞进一张纸条，他接着往下写，再塞回来。他文笔很好，见识很广，但不知道今天几号，也碰不到外面的任何东西。

## 1.3.2 对话产品——给模型装上“外壳”

我们每天用的 AI 对话应用，是在模型本体外面搭了一整套软件系统。常见的组成部分包括：

- **对话模板与系统提示词**：把你的话包装成模型训练时熟悉的格式，并在前面加上一段你看不见的说明，比如“你是一个有帮助的助手，今天的日期是……”。这就是为什么产品里的模型往往“知道”今天几号——是外壳告诉它的。
- **对话历史管理**：每轮对话时，把之前的问答一并送进模型，让它显得“记得”刚才的话。第二章会讲到，这些内容都要挤进有限的上下文窗口。
- **长期记忆功能**：写作时，一些产品提供“记住用户偏好”的功能，做法通常是把摘要存在数据库里，下次对话时再塞进提示词。记忆在外壳里，不在模型里。
- **安全过滤与界面**：对输入输出做检查，处理文件上传、语音转文字、格式渲染等。

所以，同一个模型本体，套上不同的外壳，体验可能大不相同；反过来，你在产品里感受到的某项能力，也未必来自模型本身。

## 1.3.3 智能体——让模型的输出变成行动

再往外一层，是智能体（Agent）。它的核心思路是：让模型输出的不只是给人看的回答，还可以是结构化的“指令”，比如“调用搜索工具，关键词是北京天气”。外部程序读到这条指令，真的去执行搜索，再把结果作为新文字送回模型，模型据此继续推理或下一步行动。如此循环，直到任务完成。

这里的关键在于：**真正执行动作的是外部程序，模型负责决定“做什么”和“怎么说”**。联网搜索、运行代码、读写文件、发送邮件，靠的都是这种“模型提议—程序执行—结果回传”的循环。第四章会专门拆解工具调用和检索增强的细节。

## 1.3.4 一张对照表：能力到底来自哪一层

| 你看到的能力 | 主要来自哪一层 | 说明 |
|---|---|---|
| 写文章、翻译、解释概念 | 模型本体 | 训练中学到的语言与知识 |
| 知道今天的日期 | 对话产品 | 系统提示词告诉模型 |
| 记得上一轮说过的话 | 对话产品 | 历史对话被重新送入模型 |
| 记得上周提过的偏好 | 对话产品 | 外部存储的记忆被注入提示词 |
| 回答最新新闻并附来源 | 智能体/检索 | 外部搜索结果送入模型 |
| 精确计算、运行代码 | 智能体 | 由代码执行工具完成 |
| 发送邮件、预订会议 | 智能体 | 由外部程序真正执行 |

需要说明的是，不同公司的产品在哪一层实现哪种功能，做法并不统一，而且变化很快。上表描述的是写作时较为常见的分工，而不是某一家的具体设计。

## 1.3.5 分清边界有什么用

第一，**判断可信度**。产品给出的答案若附带检索来源，可以点开核对；若只是模型本体凭记忆生成，就要警惕它在细节上出错——第六章讨论的“幻觉”，主要发生在这一层。

第二，**正确归因**。看到“某某 AI 能订机票”，要分清这是模型变聪明了，还是外壳接入了新工具。媒体报道和产品宣传常把二者混为一谈。

第三，**理解本地模型**。在自己电脑上运行开源模型时，你拿到的基本只是最内层。想要记忆、联网和工具，就得自己或借助开源软件把外两层搭起来。

本书聚焦的是最内层的模型本体：它的结构、训练方式和运行机制；外壳与智能体只在“建立关系”一章讲清它们如何与模型相连。至于支撑这一切运行的芯片、服务器与数据中心，则属于丛书第十七册《人工智能系统》的范围。

记住这三层同心圆：最里面是只会“接着写”的模型，中间是让它能好好对话的产品外壳，最外面是让它能动手做事的智能体。下一节，我们回到时间线上，看看最里面这一层——语言模型——是怎样从简单的统计计数一步步长成今天的样子的。
