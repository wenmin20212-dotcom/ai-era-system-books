# 6.2 多头注意力与前馈网络的分工

打开你下载的开源模型的配置文件 `config.json`，往往能看到这样几行（字段名因模型而异）：`num_attention_heads`（注意力头数）、`hidden_size`（隐藏维度）、`intermediate_size`（前馈层中间维度）。不少模型的 `intermediate_size` 是 `hidden_size` 的好几倍，注意力头数则常见几十个。这几个数字背后藏着一个分工问题：每一层 Transformer 里，多头注意力和前馈网络各做什么？上一节讲清了单个注意力怎样用查询、键、值计算，本节把镜头拉远，看“多个头”和“前馈层”怎样配合。

## 6.2.1 一个头不够用：为什么要“多头”

先看一句话：“小明把书还给了图书馆，因为它下周要闭馆。”读懂这句话，至少要同时追踪几种关系：“它”指的是图书馆还是书；“还给”的主语是小明；“因为”连接的是前后两个分句的因果。

单个注意力在每个位置只算出**一组**注意力权重，相当于只有一种“看别人”的方式。如果这组权重主要用来追踪指代，就很难同时兼顾语法搭配和因果连接。

**多头注意力**（Multi-Head Attention，MHA）的做法是把隐藏向量切成若干份，每一份配上自己的一套查询、键、值投影矩阵，各自独立做一次注意力计算，这一份就叫一个**注意力头**（attention head）。所有头的结果拼接起来，再经过一个输出投影矩阵，合成这一层注意力的最终输出。

打个比方：一份合同交给一个审核员，他只能顺着一条思路读；交给法务、财务、业务几个人并行审读，每人关注不同方面，最后汇总意见，覆盖面就宽得多。多头注意力的“头”就是这些并行审读员。

需要说明两点：
- 切分通常是平均的：若隐藏维度为 4096、头数为 32，每个头处理 128 维（这是公开资料中常见的配置量级，并非某个模型的确切参数）。所以多头并没有让计算量成倍增加，而是把同样的维度分给多个视角。
- 每个头关注什么，**不是人为指定的**，而是训练中自己形成的。

## 6.2.2 头们各看什么：研究中观察到的分工

可解释性研究者把注意力权重画成热力图，发现不同头确实呈现出不同模式。论文中常被报道的类型包括：

| 头的类型（研究者的描述） | 典型行为 |
|---|---|
| 位置型头 | 主要看前一个或附近几个令牌 |
| 语法型头 | 动词关注其主语或宾语，形容词关注被修饰的名词 |
| 指代型头 | 代词关注它所指的名词 |
| 归纳头（induction head） | 发现“A B …… A”的模式后，预测下一个是 B，复制前文出现过的序列 |

其中**归纳头**由 Anthropic 的研究团队在小型模型上系统研究过，被认为与第 6.4 节要讲的上下文学习有关。不过要谨慎看待这些标签：很多头的行为是混合的、难以命名的；也有研究发现剪掉相当一部分头对效果影响不大，说明头与头之间存在冗余。“每个头一个清晰职能”是简化的说法，不是精确事实。

工程上还有一种变化值得认识：为了降低推理时的显存占用，许多新模型采用**分组查询注意力**（Grouped-Query Attention，GQA），让若干个查询头共享同一组键和值。你在配置文件里看到 `num_key_value_heads` 小于 `num_attention_heads`，通常就是这种做法。它省下的是上文提到的键值缓存（第 7.3 节还会进一步展开）。

## 6.2.3 前馈网络：每个令牌各自“加工”

注意力完成后，每个位置的向量已经融合了来自其他令牌的信息。接下来进入**前馈网络**（Feed-Forward Network，FFN，有时也叫 MLP，多层感知机）。

前馈网络的结构很朴素：
1. 把向量从隐藏维度**放大**到中间维度（常见是几倍）；
2. 经过一个非线性激活函数（早期常用 ReLU、GELU，许多新模型用 SwiGLU 一类的门控变体）；
3. 再**压缩**回隐藏维度。

关键特点是：前馈网络**对每个令牌独立处理**，令牌之间在这一步不交换信息。

两者的分工可以这样对照：

| | 多头注意力 | 前馈网络 |
|---|---|---|
| 作用范围 | 在令牌之间搬运信息 | 在单个令牌内部加工信息 |
| 类比 | 开会讨论，互相交换情报 | 回到工位，各自消化整理 |
| 参数占比 | 较小 | 通常占每层参数的大头（约三分之二是常见量级） |
| 被认为承担的角色 | 关系、指代、复制 | 存储和调用大量模式与知识 |

## 6.2.4 前馈层像一张“键值记忆表”

为什么前馈网络要占那么多参数？一种有影响力的解释来自 2020 年前后的研究：前馈层可以看成一张巨大的**键值记忆**。第一次放大时，中间层的每个神经元像一把“钥匙”，检测输入里是否出现某种模式，比如“句子在谈论首都”；第二次压缩时，被激活的神经元把对应的“值”加回向量，比如增强“巴黎”“北京”这类令牌的可能性。

后续研究甚至尝试直接修改某些前馈层的参数来改写模型记住的某条事实，并取得了部分成功。这支持了“事实知识较多地存储在前馈层”的看法。但这仍是研究中的解释框架，知识在模型中的分布是分散、交织的，没有一个“知识存放在第几号神经元”的简单答案，第 8.5 节会进一步展开。

第 7.2 节要讲的混合专家模型，替换的正是这一部分：把一个大前馈网络拆成多个“专家”，每个令牌只调用其中几个。这也从侧面说明前馈层是参数量的主要所在。

## 6.2.5 小结：交替进行的“讨论”与“消化”

一层 Transformer 可以概括为两步：先由多头注意力让令牌们从多个视角互相查看、交换信息，再由前馈网络让每个令牌独自加工、调用存储的模式。几十层这样交替堆叠，靠残差连接把每一步的结果累加起来，一个原本只代表“它”字的向量，逐渐变成包含“它指图书馆、图书馆要闭馆”这层含义的表示。

注意力负责“连接”，前馈负责“记忆与加工”，这是理解后面上下文学习、幻觉和混合专家的一个基本出发点。下一节，我们来到这条流水线的最后一站：模型算出概率分布之后，究竟怎样挑出下一个字。
