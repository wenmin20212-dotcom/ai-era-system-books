# 9.1 用 AI 读懂光网络：看懂光猫指示灯、光功率与设备参数

晚上刷视频突然卡住，你走到光猫前，看到一排小灯：有的常亮，有的闪烁，其中一个泛着红光。很多人此时只会拔电源再插上。其实这几盏灯和光猫管理页面里的几行数字，已经把“光从哪一段出了问题”说出了大半。本节借助前面八章的知识骨架，再配合 AI 的解释能力，把这台每天陪着你的设备读懂。

## 9.1.1 指示灯：光猫的“表情”

光猫的正式名称是光网络单元（ONU，Optical Network Unit），也常被叫作光网络终端（ONT，Optical Network Terminal）。它是无源光网络（PON）在你家的末端。各厂商的面板标注略有不同，下表是写作时常见的命名和含义，具体以设备说明书为准。

| 指示灯 | 常见状态 | 一般含义 |
|---|---|---|
| POWER（电源） | 常亮 | 供电正常 |
| PON / REG（注册） | 常亮 | 已与局端光线路终端（OLT）完成注册 |
| | 闪烁 | 正在注册，或注册失败 |
| LOS（信号丢失） | 熄灭 | 光信号正常 |
| | 红灯亮或闪 | 收不到光或光太弱 |
| LAN / 网口 | 闪烁 | 有数据在网线上收发 |
| 无线 / Wi-Fi | 亮或闪 | 无线功能开启并在工作 |

读灯的关键是按“从光到电”的顺序排查，这正对应第五章讲的光信号流：先看 LOS，它管的是“光有没有到”；再看 PON，它管的是“到了以后能不能和局端对上话”；最后才看网口和 Wi-Fi，它们管的是“家里这一段”。

- **LOS 红灯**：问题多半在光路上。可能是尾纤被门夹到、弯得太急，连接器松了或端面脏了，也可能是楼道分光箱或更远处出了故障。
- **LOS 正常，PON 一直闪**：光到了，但没注册成功。常见原因是设备认证信息不匹配，或者局端配置有问题，通常要联系运营商。
- **光侧都正常，但上不了网**：问题多在拨号、路由器或家中 Wi-Fi，可以参阅本丛书第二十七册《Wi-Fi 与无线网络》。

## 9.1.2 光功率：一个以 dBm 计的数字

在光猫管理页面（地址和账号通常印在机身标签上）里，往往能找到“光模块信息”或“PON 信息”一栏，里面有几项参数：

- **接收光功率**：从局端到达你家的光有多强，单位是 dBm（分贝毫瓦，以 1 毫瓦为基准的对数单位）。0 dBm 等于 1 毫瓦，-10 dBm 是 0.1 毫瓦，-20 dBm 是 0.01 毫瓦。每减少 10，光功率就降为原来的十分之一。
- **发送光功率**：光猫发往局端的上行光强度，一般是正值或接近 0 的数。
- **工作温度、电压、偏置电流**：反映光模块里激光器的工作状态，对应第二章讲过的光源与发射机。

接收光功率为什么是负数，而且常在 -10 到 -25 dBm 之间？回想第四章和第六章就能明白。局端发出的光先要经过若干公里光纤的损耗，再经过一级或两级分光器。一个 1 分 32 的分光器，就会让每一路的光功率降到大约三十二分之一，也就是十几个分贝。GPON 标准（ITU-T G.984 系列）为不同的光功率预算等级规定了接收灵敏度。公开资料中常见的说法是，GPON 光猫的接收光功率大致在 -8 至 -27 dBm 之间都能工作，实际运维中一般希望留出余量，数值不要太接近下限。光太强同样有问题，可能会让接收机“过载”。不同制式、不同运营商的标准有差异，判断时应以运营商或设备手册为准。

## 9.1.3 让 AI 当你的“随身讲解员”

读到这里，你已经有了骨架，AI 的作用是帮你把具体设备上的信息对号入座。比较有效的做法有三种。

1. **拍照问面板**：拍下光猫正面的指示灯，问 AI：“这是某型号光猫，LOS 灯红色闪烁、PON 灯熄灭，按从光路到家庭网络的顺序，我应该怎样排查？”
2. **贴参数问含义**：把管理页面里的“接收光功率 -23.5 dBm、温度 52 ℃”等数据发给 AI，请它解释每一项的意思，并说明离常见正常范围还有多少余量。
3. **追问原理**：让 AI 换算 dBm 和毫瓦，或者解释“为什么分光比翻一倍，损耗大约增加 3 dB”，把数字和第六章的损耗机制联系起来。

使用时要记住两条规矩。第一，AI 给出的阈值和型号细节可能不准确或已经过时，涉及判断故障和维修时，要与说明书、运营商客服的结论相互核对。第二，截图前先遮掉宽带账号、密码、设备序列号（SN）和认证码（LOID）等信息，这些属于你的个人信息，不应随意上传。

## 9.1.4 动手的边界

自己检查时，可以看看尾纤有没有被压住、绕得太紧，也可以把松动的连接器按原样插紧。不要随意拔下光纤去看端面，更不要用眼睛对着光纤口或光猫的光口看。通信激光多在人眼看不见的红外波段，看不见并不代表没有，对着看可能伤害眼睛。楼道里的分光箱、配线箱属于运营商设施，应交给专业人员处理，自己不要去打开或改动。

灯是“定性”的判断，光功率是“定量”的判断，前面八章讲的结构和原理则是解释这些现象的依据。三者结合起来，再让 AI 帮你翻译，家里这台光猫就从一个只会亮灯的黑盒子，变成了你观察整张光网络的窗口。下一节，我们将沿着这根光纤走出家门，追踪它通往城市和海洋的路径。
