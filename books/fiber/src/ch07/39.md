# 7.2 掺铒光纤放大器与密集波分复用

站在一座城市的骨干机房里，你会看到一排排机柜，面板上插着标有“OA”“OMS”“OTU”之类字样的板卡，跳纤密密麻麻却井然有序。其中有两类设备几乎撑起了今天的长途光网络：一类负责把几十路不同“颜色”的光合进同一根光纤，另一类负责在光变弱时把它整体放大。前者是密集波分复用系统，后者是掺铒光纤放大器。两者结合，才让一根光纤能同时承载很多路高速信号，跑过上千公里。

## 7.2.1 一段掺了铒的光纤：放大器长什么样

掺铒光纤放大器（Erbium-Doped Fiber Amplifier，EDFA）的核心部件说出来有些出人意料：它就是一段光纤，只是纤芯里掺进了少量稀土元素铒（Er）的离子。典型的 EDFA 模块里有这样几样东西：

| 部件 | 作用 |
|---|---|
| 掺铒光纤 | 发生放大的“工作区”，长度通常在几米到几十米量级 |
| 泵浦激光器 | 提供能量，常用波长为 980 纳米或 1480 纳米 |
| 波分耦合器 | 把泵浦光和信号光合进同一段掺铒光纤 |
| 光隔离器 | 只让光单向通过，防止反射光干扰放大 |
| 监测与控制电路 | 检测输入输出光功率，调节泵浦强度 |

工作过程可以用“蓄水—放水”来类比。泵浦光先把铒离子“抬”到高能级，相当于把水抽到高处。信号光经过时，处在高能级的铒离子受到“触发”，放出与信号光波长、相位、方向都一致的新光子，信号就被放大了。这正是受激辐射，与激光器的发光原理同源，第八章会详细追溯。

EDFA 最关键的特点是**全光放大**：它不需要把光变成电、处理后再变回光，而是直接在光的层面放大。在它之前，长途线路每隔一段就要做“光—电—光”再生，每路信号都要配一套设备，速率一变还得整体更换。EDFA 不关心信号是什么速率、什么格式，只要波长落在它的放大范围内，就一视同仁地放大。

## 7.2.2 恰好落在 C 波段：为什么是铒

铒离子的放大范围大约覆盖 1530–1565 纳米，也就是常说的 C 波段（Conventional band，常规波段）；经过专门设计的 EDFA 还能工作在约 1565–1625 纳米的 L 波段（Long band，长波段）。而石英光纤的损耗最低点恰好就在 1550 纳米附近。这是光纤通信史上一次“天作之合”：传输损耗最低的窗口，正好有一种成熟的放大器可用。公开资料普遍认为，EDFA 在 20 世纪 80 年代末研制成功、90 年代进入商用，是光纤通信容量飞跃的转折点之一。

EDFA 也有代价。放大时，部分处于高能级的铒离子会自发放出杂乱的光子，这些光子同样被放大，形成放大自发辐射（Amplified Spontaneous Emission，ASE）噪声。每经过一级放大，噪声就累积一些。所以 EDFA 能“补能量”，却不能“清理信号”，它与第三章讲过的电再生是互补关系，而不是替代关系。

## 7.2.3 一根光纤里的几十种颜色：DWDM 的结构

第六章讲过波分复用的原理：不同波长的光在同一根光纤里互不干扰地传输。密集波分复用（Dense Wavelength Division Multiplexing，DWDM）把这个思路推到了“密集”的程度——在 C 波段里，相邻波长之间只隔零点几纳米。

为了让不同厂家的设备能对上“频道”，ITU-T G.694.1 建议规定了 DWDM 的频率栅格：以 193.1 太赫兹为参考点，常见间隔为 100 GHz 或 50 GHz，后来又引入了更灵活的“灵活栅格”（flexible grid），中心频率以 6.25 GHz 为粒度，频谱宽度以 12.5 GHz 为单位分配。按传统固定间隔，C 波段可容纳的波长数常见为 40 路或 80 路量级，这是公开资料中的典型说法，具体以设备为准。

一条典型的 DWDM 长途线路，结构大致如下：

1. **光转发单元（OTU）**：把客户侧的业务信号（如以太网）转换成符合栅格的特定波长。
2. **合波器（Mux）**：把几十个波长合进一根光纤。
3. **功率放大器（BA）**：在发送端把合成后的光整体放大。
4. **线路放大器（LA）**：沿途每隔一段（陆地系统常见几十到一百多公里）设一个光放站，补偿光纤损耗。
5. **前置放大器（PA）**：在接收端把衰减后的光放大到接收机适合的范围。
6. **分波器（Demux）**：把各个波长分开，送到各自的接收机。

此外，系统中通常还有一路独立的光监控信道（Optical Supervisory Channel，OSC），使用业务波段之外的波长，专门传送网管信息，这就是第五章“管理流”的物理载体。

## 7.2.4 一台放大器顶几十台再生器：二者为什么必须搭配

把 EDFA 和 DWDM 放在一起看，就明白它们为什么是一对：

| 对比项 | 逐波长电再生 | EDFA + DWDM |
|---|---|---|
| 每个中继点设备数 | 每个波长各一套 | 一台放大器管所有波长 |
| 对速率和格式 | 绑定，升级要换设备 | 基本透明，升级主要换两端 |
| 能否清除噪声 | 能，重新判决整形 | 不能，噪声逐级累积 |
| 适用位置 | 必要时的再生点 | 沿线常规光放站 |

没有 EDFA，DWDM 的几十个波长就要配几十套再生器，成本和功耗难以承受；没有 DWDM，EDFA 一次只放大一路，“一台放大器服务所有波长”的批量优势也就无从发挥。二者结合后，扩容往往只需在两端增加新波长，沿途光放站基本不动。

不过，“一视同仁”也带来新的工程问题。EDFA 对不同波长的增益并不完全相同，几十级串联后差距会被放大，所以实际设备要用增益平坦滤波器把增益“削平”。某些波长突然断掉或新增时，剩余波长的功率会瞬间变化，放大器需要快速的自动增益控制来稳住。再加上 ASE 噪声积累和光纤非线性效应，总功率既不能太低也不能太高——这正是长途系统设计的核心权衡。如今主流长途系统把 DWDM 与第六章讲的相干检测结合，单波长速率在写作时已普遍达到数百 Gbit/s 量级，但底层的“合波—放大—分波”骨架没有改变。

## 7.2.5 小结：从“一路一放”到“一放多路”

EDFA 让光在光域里直接被放大，DWDM 让一根光纤同时承载许多波长，两者组合，把长途传输从“每路信号各自中继”变成了“一台放大器服务所有波长”。你家光猫上传的数据，进入骨干网后，很可能就混在某个波长里，穿过一连串这样的光放站。下一节，我们把视线移到这些信号进出设备的地方——光模块，看看光与电是在哪个小小的金属壳里完成“翻译”的。
