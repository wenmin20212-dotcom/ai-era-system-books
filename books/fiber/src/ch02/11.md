# 2.3 光探测器与光接收机：把光变回电

打开光猫的管理页面，在“光模块信息”或“PON 状态”一栏里，你多半能看到两个数字：一个叫“发送光功率”，一个叫“接收光功率”，后者通常是一个负数，比如 −18 dBm 左右。这个负数说明，从运营商机房出发、穿过几公里光纤和分光器、最后钻进你家光猫的那束光，已经微弱到只剩约百分之一毫瓦的量级。光猫要从这么一点点光里，准确地读出每秒上亿个“0”和“1”，再交给路由器和电脑。完成这件事的部件，就是光探测器和光接收机。

上一节讲的是怎样把电变成光，这一节讲反过来的一步：怎样把光变回电。

## 2.3.1 光探测器：一块“见光就出电流”的半导体

光探测器（Photodetector）是接收端的核心器件，最常见的是光电二极管（Photodiode，PD）。它的工作原理可以用一个类比来理解：把半导体想象成一排装满了“电子”的座位，平时电子都坐着不动；当一个能量足够的光子（光的最小能量单位）打进来，就像有人拍了一下某个电子的肩膀，它被“叫起来”，在内部电场的推动下跑向一端。大量光子带来大量这样被唤起的电子，宏观上就形成了电流。**光越强，电流越大**，光的明暗变化就变成了电流的大小变化。

这个过程叫光电效应，它是爱因斯坦早年研究的课题之一，第八章还会回到光的本质去溯源。这里只需记住一个关键限制：光子的能量与波长有关，只有当光子能量足以“叫醒”电子时，材料才会响应。因此不同材料适合不同波长：

| 探测器材料 | 主要响应波长范围（典型） | 常见用途 |
|---|---|---|
| 硅（Si） | 约 400–1100 nm | 短距离多模系统（850 nm）、可见光 |
| 铟镓砷（InGaAs） | 约 900–1700 nm | 1310 nm、1490 nm、1550 nm 等主流光纤通信波段 |
| 锗（Ge） | 约 800–1600 nm | 硅光芯片中集成的探测器 |

你家光猫接收的下行光在 1490 nm 或更长的波段，硅“看不见”它，所以里面用的通常是铟镓砷一类的探测器。

## 2.3.2 PIN 与 APD：两种主流光电二极管

光通信里最常用的两种光电二极管是 PIN 和 APD。

- **PIN 光电二极管**：名字来自它的三层结构——P 型层、本征层（Intrinsic）、N 型层。中间那层较厚的本征层是专门“接光子”的区域，光子在这里产生电子，电子被电场快速拉走。它结构简单、噪声低、成本低，一个光子大致最多换来一个电子。
- **雪崩光电二极管（Avalanche Photodiode，APD）**：在内部加了一个高电场区域。被光子唤起的电子在这里高速冲撞，又撞出新的电子，新电子再撞出更多电子，像雪崩一样倍增。于是一个光子能换来几个到几十个电子，对弱光更敏感。

二者的取舍可以这样对照：

| 对比项 | PIN | APD |
|---|---|---|
| 内部增益 | 无（约为 1） | 有，典型为几倍到几十倍 |
| 灵敏度 | 一般 | 更高，能接收更弱的光 |
| 工作电压 | 低 | 较高 |
| 附加噪声 | 小 | 倍增过程会引入额外噪声 |
| 成本 | 低 | 较高 |

在无源光网络里，一根光纤要经过分光器分给几十户，每户分到的光很弱，所以 PON 的接收端常常使用 APD 来换取更大的“功率余量”；而数据中心里几百米的短距离连接光很强，PIN 就足够了。具体某款光猫用哪种，以设备规格为准，这里说的是写作时业界常见的做法。

## 2.3.3 从探测器到光接收机：放大、整形、判决

光电二极管输出的电流非常小，通常在微安量级，而且混着噪声，还不能直接当作数字信号使用。一台完整的光接收机（Optical Receiver）大致是一条四步流水线：

1. **光电转换**：光电二极管把光变成微弱的电流。
2. **前置放大**：跨阻放大器（Transimpedance Amplifier，TIA）把微弱电流转换成电压并放大。它紧贴探测器安放，因为线路越长，引入的干扰越多。
3. **主放大与均衡**：进一步放大，并在一定程度上修补传输中变形的波形。
4. **时钟恢复与判决**：时钟数据恢复电路（Clock and Data Recovery，CDR）从信号里找出节拍，在每个节拍的“最佳时刻”看一眼电压：高于门限判为 1，低于门限判为 0。

这很像在嘈杂的车站听广播：耳朵先捕捉声音（探测），大脑把注意力调大（放大），跟上播音员的语速（时钟恢复），最后逐字确认听到的是什么（判决）。一旦某一步出错，就会出现误码。衡量接收质量的核心指标是误码率（Bit Error Ratio，BER），即错判的比特占总比特的比例。

现代长途系统的接收机更复杂：它不只看光的明暗，还要测量光的相位和偏振，并用强大的数字信号处理芯片做“事后纠错”。这就是相干接收机，第六章 6.5 节会专门展开。

## 2.3.4 灵敏度与过载：接收光功率为什么有“合适区间”

回到光猫页面上那个负数。接收机有两条边界：

- **灵敏度（Sensitivity）**：在满足规定误码率的前提下，接收机能正常工作的最小光功率。光太弱，信号会被噪声淹没。
- **过载点（Overload）**：接收机能承受的最大光功率。光太强，放大器饱和，波形失真，同样会误码。

二者之间就是“合适区间”。以 GPON 为例，ITU-T G.984 系列根据光功率预算等级对光猫的接收范围作了规定，常见等级下，大约在 −8 dBm 到 −27 dBm 之间（具体以设备所符合的等级为准）。因此装维人员常说“收光在 −20 多 dBm 也能用，但再弱就危险了”。如果你的光猫显示的接收光功率接近下限，往往意味着光纤弯折过度、接头脏污或线路老化，第六章讲损耗时会解释原因，第九章会教你借助 AI 判读这些数字。

> 安全提示：接收端测量光功率要用光功率计，切勿用眼睛直视光纤端面或光口。通信波段多为不可见的红外光，人眼没有刺痛感，却可能造成损伤。

## 2.3.5 小结

光发射机把电“写”成光，光接收机把光“读”回电。读的过程依赖半导体中的光电效应，靠 PIN 或 APD 完成转换，再经跨阻放大、时钟恢复和判决，最终还原成比特。光猫页面上的“接收光功率”，就是你观察这一过程的窗口。光在路上会越走越弱，下一节就来看工程师怎样用光放大器和中继，让它跑得更远。
