# 5.2 波长流：一根光纤里的“彩虹”

拿起家里光猫背后那根黄色跳线，对着灯看，你看不到任何颜色。光纤通信用的光大多在红外波段，人眼看不见。可就在这根玻璃丝里，此刻至少有两种“颜色”的光在同时流动：一种从局端流向你家，另一种从你家流回局端。上一节我们追踪了单个脉冲怎样从电变成光、再变回电；这一节换一个角度，把目光放在“波长”上：在一根光纤里，不同波长的光像彩虹里的不同色带，各走各的路，互不干扰。这种按波长组织起来的流动，就是“波长流”。

## 5.2.1 你家光纤里的两三种“颜色”

先看最近的例子。以光纤到户中常见的 GPON（吉比特无源光网络，Gigabit-capable Passive Optical Network，ITU-T G.984 系列）为例，标准为上下行规定了不同波长：

| 方向或用途 | 典型波长 | 说明 |
|---|---|---|
| GPON 下行（局端→家） | 1490 nm 附近 | 广播给同一分光器下的所有用户 |
| GPON 上行（家→局端） | 1310 nm 附近 | 各家轮流发送 |
| XG(S)-PON 下行 | 1577 nm 附近 | 10G PON，可与 GPON 共用一根纤 |
| XG(S)-PON 上行 | 1270 nm 附近 | 同上 |
| 有线电视叠加（部分网络） | 1550 nm 附近 | 是否使用取决于运营商 |

（数据来自 ITU-T G.984、G.9807 等建议，具体以各运营商实际部署为准。）

这张表说明了一个关键事实：同一根入户光纤可以“上下行分色”，也可以让新旧两代系统“分色共存”。运营商从 GPON 升级到 10G PON 时，往往不必重新拉光纤，只需在局端增加 10G PON 板卡和合波器件（或直接采用 Combo PON 板卡），并为升级用户更换光猫，让新旧波长在同一根纤里并行。你家光猫里有一个小小的波分器件，负责把收、发两种波长分开，这就是一个微型的波长“分流口”。

## 5.2.2 骨干网里的“几十条车道”

离开小区，进入城域网和骨干网，波长流的规模迅速放大。这里使用 DWDM（密集波分复用，Dense Wavelength Division Multiplexing）：在 1530–1565 nm 左右的 C 波段里，按照 ITU-T G.694.1 规定的频率栅格，以 193.1 THz 为参考点，每隔 100 GHz 或 50 GHz 排一个波长，较新的系统还采用中心频率以 6.25 GHz 为步进、频谱宽度以 12.5 GHz 为粒度的“灵活栅格”。公开资料中常见的说法是，一根光纤的 C 波段可容纳几十到近百个波长；扩展到 L 波段等更多波段后，数量还能增加。

可以把一根骨干光纤想象成一条高速公路，每个波长是一条车道，车道上跑着一路高速业务。成本较低的城域或企业场景则常用 CWDM（稀疏波分复用，Coarse WDM，ITU-T G.694.2），波长间隔 20 nm，从 1271 nm 到 1611 nm 共 18 个通道，车道少但对器件要求低。

## 5.2.3 波长怎样“上路、换道、下路”

“流动”二字的意义在于，波长不只是静止地并排躺在光纤里，它们在网络中有自己的路线：

1. **上路（Add）**：某个城市的设备把一路业务调制到指定波长，经合波器并入干线光纤。
2. **直通（Pass-through）**：经过沿途节点时，这个波长不需要变回电信号，直接以光的形式穿过，省掉了大量光电转换设备。
3. **下路（Drop）**：到达目的城市，分波器把该波长取出来，交给本地设备还原成电信号。

承担这种“上下路”调度的关键设备叫 ROADM（可重构光分插复用器，Reconfigurable Optical Add-Drop Multiplexer）。它像立交桥上的可编程匝道：管理人员通过网管下发指令，就能改变某个波长在哪个节点下桥、转向哪个方向，而不必派人到现场插拔光纤。这样一来，从北京到广州的一路业务，在整个旅程中可能始终占用同一个波长，形成一条端到端的“光通道”。

如果沿途某段的同一波长已被别的业务占用，就需要“换色”。目前常见做法是在节点处把光变回电，再用另一个波长重新发出，这叫光—电—光（OEO）波长转换；全光波长转换仍以研究和特定应用为主。因此，规划波长就像给航班分配航线和高度层，是光网络设计里的一项核心工作。

## 5.2.4 不传业务的“颜色”：监测与管理

光纤里还有一些波长并不承载用户数据。很多波分系统会单独留出一个光监控信道（OSC，Optical Supervisory Channel），专门传递节点间的管理信息；运营商做在线光纤监测时，常在 1625 nm 或 1650 nm 附近用 OTDR（光时域反射仪）发测试光，避开业务波长。这些“看不见的颜色中的看不见的颜色”，构成了后面 5.4 节要讲的管理与控制流的物理基础。

## 5.2.5 小结：从“一根纤”到“一束光路”

把这一节串起来：在家门口，波长流是上下行两三种颜色的分工；在城市和干线上，它变成几十条可以上路、直通、下路的光车道；在运维层面，还有专门的监测波长守护整条路。理解了波长流，你就会明白，一根光纤的价值不在于“一根”，而在于它能同时容纳多少条彼此独立的光路。至于不同波长为什么能互不干扰、怎样被精确分开，我们留到 6.4 节从机制上细看；下一节，则要看这些车道上到底跑着哪些业务。
