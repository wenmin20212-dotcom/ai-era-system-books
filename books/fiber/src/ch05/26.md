# 5.1 光信号流：从电脉冲到光脉冲再回到电脉冲

晚上点开一段视频，画面几乎立刻开始播放。这一秒钟里，视频数据从远处的服务器出发，经过机房、城域网和小区的光交接箱，最后从墙上那根细细的入户光纤钻进你家的光猫。光猫背面的网线里跑的是电信号，墙里的光纤里跑的是光信号。信号在一路上多次换形态：先是电，再变成光，最后又回到电。本节沿着这条路走一遍，看清“光信号流”在每一站发生了什么。

## 5.1.1 一条完整的旅程：电—光—电

前几章已经把光纤、光源、探测器分别拆开讲过。现在换个角度，盯住“信号”本身，看它的形态怎样变化。一条最简单的光纤链路，信号大致经过下面几站：

| 站点 | 信号形态 | 发生了什么 |
|---|---|---|
| 交换机、服务器的电路 | 电脉冲（高低电平） | 数据以 0 和 1 的电压变化存在 |
| 光发射机（激光器与驱动电路） | 电 → 光 | 电流变化控制激光的强弱或相位，完成“电光转换” |
| 光纤 | 光脉冲 | 光被约束在纤芯里向前传播，逐渐变弱、变形 |
| 光接收机（光电探测器与放大电路） | 光 → 电 | 光子打在探测器上产生电流，完成“光电转换” |
| 判决与时钟恢复电路 | 电脉冲 | 把有些模糊的波形重新判成干净的 0 和 1 |

用一个类比来理解：电信号像写在纸上的一封信，光纤像一条很长的气动传送管。信要先装进专用的“光胶囊”才能送进管道，到站后再拆开，把信取出来交给下一个人。电光转换就是装胶囊，光电转换就是拆胶囊。

为什么要这样折腾？因为电子电路擅长计算和存储，光纤擅长长距离、大容量传输。现代网络的分工是：处理靠电，搬运靠光。

## 5.1.2 出发：电脉冲怎样变成光脉冲

在光猫或光模块内部，数据先经过编码。编码会加入一些冗余位，让 0 和 1 分布均匀，也让接收端更容易找到节拍。随后驱动电路把这串电脉冲送到激光器。

最直观的做法叫强度调制（Intensity Modulation，IM）：电平为“1”时让激光亮一些，为“0”时暗一些。家庭光纤宽带的 PON 系统和数据中心里的大量短距光模块都采用这种思路。比如 GPON 下行一般使用 1490 nm 附近的波长，上行使用 1310 nm 附近的波长，两个方向用不同“颜色”在同一根光纤里互不干扰，具体规定见 ITU-T G.984 系列建议。

长途骨干网对速率和距离要求更高，就不只控制光的明暗，还同时控制光的相位和偏振，在一个脉冲里装进更多比特。这种做法叫相干调制，留到第六章细讲。

这里有一个容易忽略的细节：光脉冲并不是完全“熄灭”和“点亮”。激光器在“0”时通常仍保持微弱发光。“1”和“0”两种光功率之比叫消光比（Extinction Ratio），它直接影响接收端分辨 0 和 1 的难易程度。

## 5.1.3 途中：光脉冲在玻璃里经历了什么

光脉冲进入光纤后，会遇到两类变化。

- **变弱（损耗）**：玻璃对光有吸收和散射，弯曲也会让一部分光漏出去。常见单模光纤在 1550 nm 附近的损耗，公开资料中通常在每公里 0.2 dB 左右。也就是说，大约每走 15 公里，光功率就降到原来的一半。
- **变宽（色散）**：同一个脉冲里，不同波长成分的跑速略有差异，到达终点时前后错开，脉冲被“拉胖”。脉冲胖到和相邻脉冲重叠，0 和 1 就分不清了，这叫码间干扰（Inter-Symbol Interference，ISI）。

另外，光放大器在放大信号的同时会叠加一些噪声。家庭入户这样几公里到二十公里的链路，通常不需要放大；跨城、跨海的线路则要每隔几十公里补一次光，每补一次，噪声就多一点。

所以抵达终点的光脉冲往往“又弱、又胖、还带点毛刺”。接收端的任务，就是从这样的信号里把原来的比特准确找回来。

## 5.1.4 抵达：光脉冲怎样变回电脉冲

光进入光接收机后，先落在光电二极管（Photodiode，PD）上。常见的有 PIN 型和雪崩型（APD），后者内部带有倍增作用，适合信号很弱的场合。光电二极管把光功率转换成微弱电流，跨阻放大器（Transimpedance Amplifier，TIA）再把电流转换成足够大的电压。

接下来有两个关键步骤：

1. **时钟恢复**：从信号本身提取节拍，知道“什么时候该看一眼”。这就像听一段没有节拍器的音乐，需要从旋律里听出拍子。
2. **判决**：在每个节拍的中间时刻比较电压和门限，高于门限判为 1，低于门限判为 0。

经过这两步，模糊的波形重新变成干净的电脉冲，交给后面的芯片处理。判错的比例叫误码率（Bit Error Ratio，BER），它是衡量一条链路好坏的核心指标。现代系统普遍加入前向纠错（Forward Error Correction，FEC），在发送端添加校验信息，让接收端能自行改正一部分错误。

你家光猫管理页面里的“接收光功率”，反映的就是这一站收到的光有多强。光太弱，判决容易出错；光太强，接收机也可能饱和。第九章会教你怎样读这个数字。

## 5.1.5 不只一次转换：中途的“电再生”

在很长的线路上，信号有时会在中途的节点被完整地“光—电—光”转换一次：先收下来，判决成干净的比特，再用新的激光器重新发出去。这叫 3R 再生，即再放大（Re-amplify）、再整形（Re-shape）、再定时（Re-time）。它能把途中积累的噪声和变形一次清零，但每个节点都要使用大量电子设备，成本较高。掺铒光纤放大器普及以后，许多线路改为全程在光域放大，只在必要的节点做电再生，这是第三章“放大与再生”讨论过的取舍。

## 5.1.6 小结

光信号流的本质，可以用一句话概括：**电负责处理，光负责搬运，两次转换连接起两者。** 发射端决定装进多少信息，光纤决定路上损失和变形多少，接收端决定能把信息找回多少。理解了这一条主线，再看一根光纤里同时跑许多种颜色的光，也就是下一节的“波长流”，就会清楚得多。
