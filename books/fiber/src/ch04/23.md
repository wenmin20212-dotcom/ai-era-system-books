# 4.3 光纤与以太网、移动通信和互联网的衔接

晚上你用手机刷短视频，画面从某个机房出发，最后落到你掌心。打开家里的路由器设置页面，你会看到“WAN 口”“IP 地址”“PPPoE 拨号”这些字样；走到楼下，能看到挂在路灯杆或楼顶的 5G 基站天线。这些东西看上去和“光纤”没有直接关系，可它们背后几乎都连着一根光纤。光纤更像一条修好的路，跑在路上的车是以太网帧、移动通信数据和互联网的 IP 包。本节要讲清楚：这条路和路上的车是怎样对接的。

## 4.3.1 分层看问题：光纤在“最底下那一层”

通信系统习惯分层来理解。最常用的是参考 OSI 七层模型（开放系统互连参考模型，Open Systems Interconnection）的简化说法，大致可以分成下面几层：

| 层次 | 负责什么 | 典型例子 |
|---|---|---|
| 物理层 | 把比特变成光或电信号，送过介质 | 光纤、光模块、激光器与探测器 |
| 数据链路层 | 在相邻设备之间组织“帧” | 以太网（Ethernet）、PON 的帧结构 |
| 网络层 | 给数据编地址、选路径 | IP（网际协议，Internet Protocol） |
| 传输层及以上 | 可靠传输、具体应用 | TCP、视频、网页、即时通信 |

光纤和第二章讲的光发射机、光接收机都在物理层。光纤不关心传的是一段电影还是一条微信，它只负责把一串 0 和 1 准确送到对面。上面各层按自己的规则把业务装好，交给物理层去跑。这种分工带来一个好处：光纤技术升级时，上层协议不用跟着重写；上层出了新应用，也不用重新铺光纤。

## 4.3.2 与以太网衔接：光模块是“插座”

以太网是今天局域网和数据中心里最普遍的数据链路层技术，由 IEEE 802.3 系列标准定义。它早期跑在同轴电缆和双绞线上，后来很自然地扩展到光纤上。IEEE 802.3 为不同速率和距离规定了多种光接口，名称里常带有“SR”（短距离，多用多模光纤）、“LR”（长距离，多用单模光纤）这类后缀，比如 10GBASE-SR、10GBASE-LR。名称中的数字是标称速率，实际可用的吞吐量还要扣除帧头等开销。

两者在设备上的衔接点就是光模块。交换机或路由器面板上的一排方口，插进去的就是可插拔光模块，第七章会专门介绍。光模块一头是电接口，接设备里的以太网芯片；另一头是光接口，接光纤跳线。交换机按以太网规则把数据组织成帧，光模块把电信号换成光信号送进光纤，对端再换回来。对以太网来说，光纤只是一种“更远、更快的网线”。

家里的情况稍有不同。光猫正式的名称叫 ONU 或 ONT（光网络单元/光网络终端），它面向墙里的那根光纤说的是 PON 的语言，也就是 4.1 节讲的无源光网络；面向屋里时，它提供普通的以太网口（有的还带 Wi-Fi）。所以光猫本身就是一个“翻译点”：光纤侧是 PON，网线侧是以太网。

## 4.3.3 与移动通信衔接：基站背后全是光纤

很多人以为手机信号是“从天上来”的。其实无线只走了从手机到基站这最后几百米到几公里，基站之后的路程大多靠光纤（也有一部分基站用微波回传）。按照移动通信的常见术语，这段光纤承载大致分成三类：

- **前传**（Fronthaul）：基站里射频单元（常装在天线附近）与基带处理单元之间的连接，对时延和带宽要求很高，常用专门的接口协议，例如 CPRI 或 eCPRI 这类业界规范。
- **中传**（Midhaul）：在 5G 把基带功能拆成分布单元和集中单元时，两者之间的连接。
- **回传**（Backhaul）：基站汇聚后连到核心网的连接。

这三段在城市里大多跑在光纤上，有的利用城域网的波分系统，有的借用 PON 网络。5G 基站数量多、带宽大，对光纤的需求明显超过 4G 时代，这也是公开资料里常说“5G 拉动光纤需求”的原因。移动网络本身的结构，请参见本系列第二十六册《移动通信系统》；家里 Wi-Fi 那一段，请参见第二十七册。

## 4.3.4 与互联网衔接：IP 包坐在光的“车厢”里

互联网的核心语言是 IP。你的一个视频请求被拆成许多 IP 包，在路由器之间逐跳转发。在城域和骨干网里，路由器之间的连接常常是“以太网接口 + 光模块 + 光纤”，距离远时再进入第三章讲的波分复用系统，与其他业务共享一根光纤里的不同波长。

传统运营商网络中，还有一层专门为长途传输设计的“集装箱”：ITU-T 制定的光传送网（OTN，Optical Transport Network，主要见 G.709 建议）。它把以太网、IP 或其他业务装进统一格式的帧里，附加用于性能监测和纠错的开销，再送上波长。可以把它想成：IP 包是货物，以太网帧是包装箱，OTN 是标准集装箱，波长是轨道上的一列车，光纤是铁轨。不同网络里层次可能简化，比如数据中心之间常直接用以太网光模块互联，但“上层装货、下层运输”的思路不变。

## 4.3.5 一条路径串起来

把以上几段连起来，你在家看一段视频，数据大致这样走：

1. 内容所在机房的服务器通过以太网和光模块接入交换机；
2. 数据以 IP 包形式进入运营商的骨干和城域网，在光纤上可能经过 OTN 和波分复用系统；
3. 到达你所在片区的局端设备 OLT（光线路终端），转换为 PON 下行信号；
4. 经分光器到达你家光猫，光猫把 PON 信号翻译成以太网；
5. 路由器再通过网线或 Wi-Fi 送到你的电视或手机。

如果你用的是手机流量，第 3 到 5 步就换成：城域网光纤到基站，基站通过无线送到手机。

## 4.3.6 小结

光纤和以太网、移动通信、互联网之间是分层合作的关系：光纤和光模块管物理传输，以太网和 PON 管帧的组织，IP 管寻址与路由，OTN 和波分复用在长距离上把这些业务装好、汇聚。正因为分层清晰、接口统一，不同厂家的设备才能接在一起工作。这些“统一”从哪里来，由谁来制定，就是下一节要讲的标准与组织。
