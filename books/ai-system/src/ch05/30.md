# 5.5 价值流：算力成本、调用计费与产业链

打开一款 AI 助手的订阅页面，你可能会看到“免费版每天有使用次数限制”“专业版按月付费”这样的说明；如果你是开发者，在模型服务商的价格页上看到的则是另一种写法：“每百万输入令牌多少钱、每百万输出令牌多少钱”。这些价格并不是随手定的。前面几节我们跟踪了数据、计算、令牌和能量的流动，这一节换一个角度，跟踪钱的流向：用户付出的费用最后流到了哪里，一次提问的成本又是由哪些环节叠加出来的。

## 5.5.1 一次提问的成本账单

把一次 AI 对话的成本拆开，大致可以分成两类。

**一次性投入（摊销成本）**：模型训练要占用大量加速器，持续数周到数月，还要付出数据采集与清洗、研究人员薪酬、多次失败实验的费用。公开报道中，前沿大模型单次训练的算力花费常被估计在千万美元到亿美元的数量级，具体数字各家很少正式披露。这笔钱不会因为某个用户多问一句而增加，却要靠此后海量的调用慢慢“摊回来”。

**随用随付（边际成本）**：每一次推理都要实实在在地占用 GPU 时间、显存、电力和网络带宽。回答越长、上下文越长、模型越大，这部分成本越高。

可以用一个类比来理解：训练像拍一部电影，花费集中在前期；推理像电影院每放一场都要付的电费和场地费。电影拍一次，可以放映很多场；大模型训练一次，可以回答无数个问题。随着用户规模扩大，许多公开分析认为推理在总算力开销中的占比正在上升。

## 5.5.2 为什么按“令牌”计费

在 5.3 节我们看到，模型生成回答是一个令牌（token，模型处理文本的基本单位）一个令牌地往外“吐”。这让令牌自然成为计量单位，就像电表按“千瓦时”计费一样，计量单位贴近真实消耗。

在写作时，主流大模型 API（应用程序编程接口，Application Programming Interface）的常见定价结构有几个共同特征：

| 计费要素 | 常见做法 | 背后的系统原因 |
|---|---|---|
| 输入令牌 | 单价较低 | 输入可以并行一次性处理（预填充阶段），GPU 利用率高 |
| 输出令牌 | 单价通常明显高于输入 | 输出必须逐个串行生成，每步都要读取模型权重和 KV 缓存，占用时间长 |
| 缓存命中的输入 | 部分服务商给予折扣 | 重复的前缀可复用已算好的 KV 缓存，省下计算 |
| 批量（非实时）任务 | 部分服务商给予折扣 | 可以在空闲时段集中处理，提高集群利用率 |
| 不同大小的模型 | 大模型贵、小模型便宜 | 参数越多，每个令牌的计算和显存开销越大 |

具体价格各家不同、调整频繁，读者应以服务商当前公布的价格页为准。值得注意的是，这张表的每一行都能在第四、五章讲过的硬件和流动规律中找到原因——价格表其实就是系统结构的一张“投影”。

面向普通用户的产品则多采用订阅制或“免费加限额”模式。订阅费看似与令牌无关，但服务商内部仍然按令牌和 GPU 时长核算成本，并用使用上限防止少数重度用户消耗过多算力。

## 5.5.3 降本的几个杠杆

由于边际成本真实存在，服务商会想方设法降低“每个令牌的成本”。常见的杠杆包括：

- **提高硬件利用率**：用批处理调度把多个用户的请求合在一起计算，减少 GPU 空转（6.3 节将详细介绍）。
- **压缩模型**：通过量化、蒸馏等方法，让更小、更省的模型承担大部分简单请求（7.4 节展开）。
- **分级路由**：一些产品会根据问题难度，把请求分配给不同规模的模型。
- **换用更高能效的芯片与数据中心**：每瓦特电力能完成的计算越多，电费摊到每个令牌上就越少。

公开资料中一个反复被提及的趋势是：达到同等能力水平的模型，单位令牌的调用价格在过去几年里持续大幅下降。但同时，人们使用 AI 的总量在快速增长，更长的上下文、需要反复思考的推理模型和多步执行的智能体又会消耗更多令牌。单价下降、总量上升，这两股力量同时存在，是理解 AI 产业新闻的一条线索。

## 5.5.4 钱沿着产业链流向哪里

把视角从一次提问放大到整个产业，用户付的钱会沿着一条链条向上游流动：

1. **应用层**：手机 App、办公软件中的 AI 功能、各类智能体产品，直接向用户或企业收费。
2. **模型层**：模型开发商通过 API 或授权向应用方收费；有的公司同时做模型和应用。
3. **云与算力服务层**：云服务商和算力租赁商出租 GPU 集群，按小时或按合同收费。
4. **数据中心与能源层**：机房建设、电力供应、冷却设施，对应 5.4 节的能量流。
5. **硬件层**：加速器芯片设计公司、高带宽内存厂商、先进封装与晶圆代工厂、网络设备商。

需要说明的是，这是一种简化的分层，现实中许多大型科技公司同时跨越好几层，例如既自研芯片、又经营云服务、还开发模型和应用。另外，上下游之间并不只是单向付款：开源模型降低了应用层的进入门槛，硬件供给紧张时上游议价能力增强，这些都会改变利润在链条上的分布。

当你读到“某公司大规模采购 GPU”“某云服务商宣布降价”“数据中心电力紧张”这类新闻时，可以先问一句：这件事发生在产业链的哪一层？它会让哪一段的成本上升或下降，又会如何传导到你手机上那次提问的价格？

## 5.5.5 小结：价格是系统的读数

价值流把前面四种流动串成了一本账：数据流决定训练投入，计算流和令牌流决定推理开销，能量流决定电费与冷却成本，而价格就是这些物理过程在经济上的读数。理解了这一点，你就不会把“免费”看成没有成本，也不会把“降价”简单理解为营销手段——背后往往是芯片、软件和调度方式的真实进步。至此，第五章的五条流动已经全部走完，下一节我们将把它们收拢成一张完整的骨架图。
