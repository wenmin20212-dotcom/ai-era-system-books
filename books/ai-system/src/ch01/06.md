# 1.3 从规则系统到深度学习再到大模型：三代人工智能系统

拿起手机，你可能同时用着三种“年代”不同的智能。拨打银行客服电话时，“查询余额请按 1，挂失请按 2”的语音菜单，背后是一张事先写好的流程表。相册自动把照片归入“猫”“海边”“美食”，靠的是一个从大量图片里学出来的识别模型。打开聊天助手，请它把一段会议记录改写成邮件，回应你的是一个大语言模型。这三样东西都被叫作“人工智能”，但它们的造法、能力边界和背后的系统形态差别很大。理解这三代系统，有助于看清今天的大模型从哪里来，又继承了什么、改变了什么。

## 1.3.1 第一代：规则系统——把专家的知识写成条文

最早被广泛使用的人工智能，是由人直接编写规则的系统。工程师先请教领域专家，再把他们的经验整理成“如果……那么……”的条件语句。20 世纪七八十年代流行的专家系统（Expert System）就是典型。比如一个辅助诊断程序，内部可能写着“如果体温高于某值并且白细胞偏高，那么提示可能存在感染”。

这类系统的结构很清楚，主要有三块：

- **知识库**：存放成百上千条规则；
- **推理机**：按顺序匹配规则，得出结论；
- **用户界面**：让人输入情况、读取结论。

它的长处是可解释。每一个结论都能追溯到具体是哪几条规则起了作用，出错时也能找到是哪一条写错了。它的短处同样明显：世界上的情况太多，规则写不完。人能一眼认出一只猫，却很难用条文说清“猫长什么样”。规则一多，彼此还会冲突，维护成本迅速上升。今天，规则系统并没有消失，它仍然活在客服菜单、表单校验、风控策略和各种“兜底逻辑”里，常常和后两代系统配合使用。

## 1.3.2 第二代：深度学习——让机器从数据里学规律

既然规则写不完，能不能让机器自己从例子中总结规律？这就是机器学习（Machine Learning，ML）的思路。其中，用多层人工神经网络来学习的方法叫深度学习（Deep Learning，DL）。

用一个类比来说：规则系统像给学生发一本标准答案手册；深度学习则是给学生看大量带答案的练习题，让他自己摸索出解题方法。给模型看成千上万张标注好“猫”或“不是猫”的照片，模型内部数以百万计乃至更多的数值（称为参数）会被一点点调整，直到它能较准确地分辨新照片。这些调整由算法自动完成，不需要人写下“猫有尖耳朵”这样的规则。

2012 年前后，一个深度神经网络在大型图像识别竞赛 ImageNet 上明显超过了此前的方法，这件事在公开资料中常被视为深度学习兴起的标志。推动这次转折的有三股力量：互联网积累的大规模标注数据、图形处理器（Graphics Processing Unit，GPU）提供的并行算力，以及训练算法上的改进。此后，语音识别、人脸解锁、机器翻译、商品推荐等功能陆续进入手机和网站。

这一代系统的特点是“专用”：识别图片的模型不会翻译，翻译模型不会下棋。每个任务通常要单独收集数据、单独训练一个模型。系统的重心也从“写规则的人”转向了“数据 + 算力 + 模型”这三样东西。

## 1.3.3 第三代：大模型——一个底座，多种用途

2017 年，谷歌的研究者在论文中提出了 Transformer 架构，它更适合在大量 GPU 上并行训练，也更擅长处理长段文字中的前后关系（第六章会详细展开）。在此基础上，研究者发现：用海量文本训练一个参数规模极大的模型，只让它反复练习“根据前文预测下一个词”，它就能同时具备写作、翻译、总结、问答、编程辅助等多种能力。这类模型被称为大语言模型（Large Language Model，LLM），更宽泛的说法是基础模型（Foundation Model）。

公开资料中，这类模型的参数量通常在数十亿到数千亿甚至更高的数量级，训练需要成千上万块加速芯片连续运行数周到数月。2022 年底，OpenAI 推出的 ChatGPT 让这类系统进入了大众视野。写作时，国内外已有多家公司和研究机构发布各自的大模型，并且许多模型已扩展到能处理图片、语音等多种信息，产品形态仍在快速变化。

与上一代相比，大模型的关键变化是“通用”：先花大成本训练一个底座，再通过微调、提示词或接入工具，适配到各种具体场景。代价是可解释性变弱，它有时会一本正经地给出错误内容，还需要额外的对齐与安全机制来约束其行为。

## 1.3.4 三代对照：变的是什么，没变的是什么

| 对比维度 | 规则系统 | 深度学习 | 大模型 |
|---|---|---|---|
| 能力从哪来 | 人写下的规则 | 任务数据训练 | 海量数据预训练 + 适配 |
| 适用范围 | 单一、封闭的场景 | 单一任务 | 多任务、开放场景 |
| 主要成本 | 专家与工程师的人力 | 标注数据与算力 | 超大规模算力、数据与电力 |
| 可解释性 | 强 | 较弱 | 更弱，需要专门研究 |
| 手边例子 | 电话语音菜单 | 相册分类、人脸解锁 | 聊天助手、写作助手 |

从表中能看出一条主线：智能的来源从“人直接写下”逐步转向“从数据中学出”，系统的重心也从软件逻辑一步步移向数据、算力和基础设施。正因如此，第三代人工智能不再只是一段程序，而是牵动芯片、机房、电网和整条产业链的庞大系统。

同时也要看到，三代并非简单的替代关系。你向聊天助手提问时，前端可能先经过规则过滤敏感内容，中间调用深度学习模型识别语音，最后由大模型生成回答。真实的人工智能产品，往往是三代技术叠在一起协同工作。下一节，我们就把视线拉远，看看这些系统在现代社会中分布在哪里、占据什么位置。
