# 1.2 人工智能系统的边界：模型、软件、硬件、数据与人

打开手机里的 AI 助手，问一句“明天去爬山要带什么”，几秒钟后屏幕上出现一份清单。很多人会说：“这是模型回答的。”这话不算错，却只说对了一小部分。真正给出这份清单的，是一个由模型、软件、硬件、数据和人共同组成的系统。模型只是其中一环。

本节要做的事，是给“人工智能系统”画一条边界线：哪些东西在线内，它们各自扮演什么角色，线外又是什么。

## 1.2.1 只盯着模型，会看漏什么

先看一个对照。假设同一个模型被放进两种环境：

| 情况 | 结果 |
|---|---|
| 模型文件放在一块普通 U 盘里 | 什么也不会发生，它只是一个很大的数字文件 |
| 模型被加载到服务器显卡上，由推理软件调度，通过 App 接收你的问题 | 你得到一份爬山清单 |

模型本身是一堆参数，参数就是训练后确定下来的大量数字。没有芯片去计算，没有软件去调度，没有接口把你的问题送进去，这些数字就不会产生任何回答。所以人工智能更像一辆汽车，而不只是一台发动机。发动机很重要，但光有发动机，车开不起来。

## 1.2.2 边界线内的五类要素

按“它是什么”来分，可以把人工智能系统拆成五类要素：

1. **数据**：训练模型用的文本、图像、代码，标注员写下的示范答案，以及运行时你输入的问题、上传的文件。数据是能力的来源，也是系统每次工作的原料。
2. **模型**：由架构和参数组成。架构是计算的结构，例如后文要讲的 Transformer（一种以注意力机制为核心的神经网络结构）；参数是训练后得到的具体数值。两者合在一起，存成“权重文件”。
3. **软件**：深度学习框架（用来搭建和训练模型的软件工具库，如 PyTorch）、推理引擎、服务系统、App 和应用程序接口（API，Application Programming Interface，即程序之间约定好的调用方式）。软件负责把模型“用起来”。
4. **硬件**：图形处理器（GPU，Graphics Processing Unit）等 AI 加速芯片、内存、服务器、网络设备，以及数据中心的供电和冷却设施，还有你手里的手机。硬件提供计算、存储和传输的物理基础。
5. **人**：收集和清洗数据的工程师，设计和训练模型的研究者，给回答打分的标注员，运维人员，制定规则的管理者，还有提问的你。

最后一类最容易被忽略。一个模型回答问题时显得礼貌、会拒绝明显有害的请求，并不是它“天生如此”，而是训练过程中有大量人工示范和评价，把人的偏好写进了参数。你的每一次点赞、点踩，在一些产品里也可能被用来改进系统，具体做法因公司而异，通常在用户协议里有说明。

## 1.2.3 要素之间是“咬合”的，不是“堆放”的

五类要素并不是简单摆在一起，而是互相牵制。举几个例子：

- **模型与硬件**：模型越大，需要的显存和算力越多。一个参数规模在千亿量级的模型，通常无法装进一张显卡，只能拆到多张卡上，这又要求卡之间有高速互连。
- **数据与模型**：训练数据里缺少某个领域的内容，模型在这个领域就容易答错。模型的“知识面”大体上由数据划定。
- **软件与硬件**：同一块芯片，换一套更合适的推理软件，处理请求的速度可能有明显差别。软件决定了硬件能被用出几成。
- **人与系统**：安全规则定得严一些，系统拒答就多一些；定得松一些，风险就高一些。这类取舍最终由人来做。

所以，判断一个 AI 产品好不好用，不能只问“用的是哪个模型”，还要问数据从哪来、跑在什么硬件上、软件怎么调度、谁在为它设定规则。

## 1.2.4 边界画在哪里，取决于你看问题的尺度

系统的边界不是固定的，它随观察尺度变化：

| 观察尺度 | 系统边界大致包括 |
|---|---|
| 手机上的端侧模型 | 手机芯片中的神经网络处理器（NPU，Neural Processing Unit）、手机内存、本地小模型、App |
| 一次云端对话 | 你的手机、网络、云服务商的服务器、推理软件、大模型 |
| 一个大模型的完整生命周期 | 数据采集与清洗、训练集群、对齐与评测、部署上线、持续监控 |
| 社会层面 | 电力供应、芯片产业链、法律法规、使用者的习惯 |

写作时的情况是，不少手机厂商已经在设备上运行较小的模型来处理部分任务，更复杂的请求再交给云端。这说明同一个“AI 助手”，背后的系统边界可能每次都不一样：有时在你手心里结束，有时要穿过网络到达远处的数据中心。

线外的东西也并非与系统无关。电网、气候、法律都会影响系统，只是它们通常被看作“环境”。把什么划进来、把什么当环境，是分析者根据问题做的选择，本身没有唯一答案。

## 1.2.5 小结：先画边界，再谈能力

理解人工智能系统的第一步，是把注意力从“模型有多聪明”移开一点，看到数据、模型、软件、硬件和人共同组成的整体。模型给出回答的那一刻，其实是这五类要素在同一时间协同工作的结果。

有了这条边界线，我们就可以追问另一个问题：这样的系统是怎么一步步演变到今天的样子？下一节将沿着时间线，看规则系统、深度学习和大模型这三代人工智能系统，各自把边界画在了哪里。
