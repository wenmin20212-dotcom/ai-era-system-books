# 4.2 服务器之内：多 GPU 互连与主机总线

打开你的电脑机箱，或者在网上搜一张台式机主板的照片，你会看到一条长长的插槽，显卡就插在那里。这条插槽叫 PCIe 插槽，它把显卡和中央处理器（CPU）连在一起。一台普通游戏电脑通常只有一块显卡，这条插槽就够用了。可是数据中心里一台 AI 服务器常常装着 8 块 GPU，它们要不停地互相交换数据。上一节讲的是一颗芯片内部的结构，这一节把镜头拉远一点，看看一台服务器里的多块 GPU 怎样连成一个整体。

## 4.2.1 一台 AI 服务器长什么样

AI 服务器外形像一个扁平的金属抽屉，装在机柜里。写作时，业界常见的训练服务器配置是“8 卡机”，也就是一台服务器里装 8 块 GPU 或 AI 加速器。英伟达把这类整机设计称为 DGX 和 HGX 平台，其他厂商也有类似的 8 卡方案。它的主要部件可以列成一张表：

| 部件 | 作用 | 类比 |
|---|---|---|
| CPU（中央处理器，通常 1–2 颗） | 调度任务、读写硬盘、管理网络 | 车间主任 |
| GPU / 加速器（常见 8 块） | 承担绝大部分矩阵计算 | 生产线上的工人 |
| 主机内存（DRAM） | 存放待处理数据和程序 | 车间仓库 |
| GPU 间高速互连 | GPU 之间直接交换数据 | 工位之间的传送带 |
| PCIe 总线与交换芯片 | 连接 CPU、GPU、网卡、硬盘 | 车间主干道 |
| 网卡（NIC） | 与其他服务器通信 | 厂门口的物流出口 |
| 电源与散热 | 供电和带走热量 | 水电与空调 |

从表里能看出，服务器内部其实有两套“道路”：一套是通用的主机总线，一套是 GPU 专用的高速互连。

## 4.2.2 主机总线：PCIe 这条主干道

PCIe 的全称是“外围组件快速互连”（Peripheral Component Interconnect Express），它是计算机里连接各种设备的通用标准，由行业组织 PCI-SIG 制定。显卡、固态硬盘、网卡大多走 PCIe。

PCIe 的特点有三个：

- **点对点、分通道**：一条连接由若干“通道”（lane）组成，显卡通常用 16 条，记作 x16。通道越多，同时能传的数据越多。
- **按代升级**：从第 1 代到写作时已商用的第 5 代、正在推广的第 6 代，大致每一代单通道速率翻一番。
- **通用性强**：几乎所有厂商的设备都支持，换卡、扩容都方便。

在 AI 服务器里，PCIe 主要负责“进货和出货”：把训练数据从硬盘和主机内存送进 GPU，把模型权重加载到显存，也把 GPU 和网卡连起来。服务器里通常还装有 PCIe 交换芯片，作用类似路口的立交桥，让一个 CPU 能连上更多设备。

但 PCIe 有个局限：它是为“通用”设计的，带宽对 GPU 之间的频繁交换来说不够宽。拿写作时的情况作数量级对比，一条 PCIe 5.0 x16 链路的单向带宽在每秒几十 GB 量级，而一块高端 AI 芯片自身显存带宽已达到每秒数 TB 量级，两者相差几十倍到上百倍。如果 GPU 之间只能绕道 PCIe 交换数据，计算单元就会经常停下来等数据。

## 4.2.3 GPU 专用互连：工位之间的传送带

为了解决这个瓶颈，芯片厂商为 GPU 之间设计了专用的高速连接：

- **英伟达的 NVLink 与 NVSwitch**：NVLink 是英伟达自己的 GPU 互连技术，NVSwitch 是配套的交换芯片。在 8 卡机里，每块 GPU 通过 NVLink 接到 NVSwitch 上，任意两块 GPU 之间都能以很高的带宽直接通信，带宽比 PCIe 高一个数量级左右。写作时，英伟达还把这种连接从单台服务器扩展到整个机柜，让几十块 GPU 处在同一个高速互连域里。
- **AMD 的 Infinity Fabric**：AMD 在自家加速器之间使用的互连技术，思路类似。
- **谷歌 TPU 的芯片间互连（ICI）**：谷歌为自家 TPU 设计的专用连接，常把大量芯片连成网格或环形结构。
- **开放标准的尝试**：写作时，多家公司在推动 UALink 等开放的加速器互连标准，希望不同厂商的芯片也能高速直连。CXL（计算快速链路）则在 PCIe 物理层之上，让 CPU 与加速器、内存扩展设备更方便地共享内存。

不论名称如何，这些技术的目标是同一个：让一台服务器里的多块芯片在交换数据时，尽量像在用同一块大芯片。

## 4.2.4 为什么 GPU 之间要频繁“说话”

一个大模型往往装不进一块 GPU 的显存，或者一块 GPU 算得太慢，于是要把工作拆给 8 块卡一起做。常见的拆法有两种，第 4.3 节还会细讲：

1. **张量并行**：把一层神经网络里的大矩阵切成 8 份，每块 GPU 算一份。每算完一层，8 块卡就要把各自的部分结果汇总一次。这种交换非常频繁，几乎每一步都要发生，所以最依赖服务器内部的高速互连。
2. **数据并行**：每块 GPU 都有一份完整模型，各自处理不同的数据，最后把各自算出的“修改意见”（梯度）平均一下。交换次数少一些，但每次数据量大。

打个比方：张量并行像 8 个人合抄一页书，每写一行就要对一下；数据并行像 8 个人各抄一本，抄完再统一校对。前者必须坐在同一张桌子旁，后者可以分散一些。所以工程上通常把交换最频繁的工作放在同一台服务器、同一个高速互连域里，把交换较少的工作分给不同的服务器。

## 4.2.5 从 CPU 主导到 GPU 主导

传统计算机以 CPU 为中心，其他设备都是“外设”。AI 服务器里，CPU 仍然负责调度、读写数据和运行操作系统，但真正的计算主力换成了 GPU，CPU 更像后勤保障。为了少让数据绕路，工程师还设计了一些“直达通道”。比如英伟达的 GPUDirect 技术，让网卡和存储设备可以直接把数据送进 GPU 显存，不必先在主机内存中转。也有厂商把 CPU 和 GPU 封装在同一块板子上，用高带宽链路相连，如英伟达的 Grace Hopper 和 Grace Blackwell 系列，就是这类设计。

这种变化说明了一条系统规律：**哪里的数据交换最频繁，哪里就需要最宽的路。**服务器内部的设计，本质上是在为计算主力铺路。

当你在手机上提问时，回答你的模型很可能就分布在这样一台服务器的几块 GPU 上，它们通过高速互连在毫秒之间来回交换数据。但一台服务器的 8 块卡远远不够训练一个大模型，成千上万块 GPU 还要跨服务器连接起来。下一节，我们走出服务器，去看集群里的高速网络和集合通信。
