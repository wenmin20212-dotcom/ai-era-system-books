# 4.5 本章骨架小结与实物探索任务

你手机上的一次提问，离开屏幕后要先穿过基站和光纤到达某个数据中心，经过 API 网关排队、鉴权，被分到一组服务器。服务器里的几块 GPU 用高速互连传递中间结果，每块 GPU 内部的计算核心又不停地从高带宽内存里取数据。第一章看到了这个对象，第二、三章拆出了它的部件和职能，本章要回答的是：这些部件怎样连在一起。下面先把骨架收拢，再动手和动嘴去验证它。

## 4.5.1 一张从芯片到手机的连接骨架

本章沿着“由内向外”的方向走了四层，每一层都有自己的“连线”和“瓶颈”：

| 层级 | 连接的对象 | 典型连接方式 | 主要矛盾 |
|---|---|---|---|
| 芯片之内（4.1） | 计算核心、缓存、高带宽内存 | 片上互连、中介层封装 | 算得快，但数据喂不够快（“内存墙”） |
| 服务器之内（4.2） | 多块 GPU、CPU、网卡、存储 | GPU 直连（如英伟达的 NVLink）、PCIe 主机总线 | 卡间交换数据的带宽与延迟 |
| 集群之内（4.3） | 成百上千台服务器 | InfiniBand 或高速以太网、集合通信 | 并行切分后，通信会不会拖慢计算 |
| 数据中心与用户之间（4.4） | 云服务、网关、终端设备 | 互联网、API、负载均衡 | 延迟、并发、成本与可用性 |

把这张表竖着读，能读出三条贯穿全章的规律：

- **越往外，带宽越低、延迟越高。** 片上数据通路最快，卡间直连次之，跨服务器网络再次，公网最慢。工程师设计系统时总想让频繁交换的数据待在离计算最近的地方。
- **计算常常在等数据。** 无论是一块芯片还是一万块芯片，瓶颈往往不在“算”，而在“搬”。高带宽内存、NVLink、集合通信算法这些技术，解决的都是搬运问题。
- **并行策略是连接方式的“软件镜像”。** 数据并行、张量并行、流水线并行之所以这样分工，是因为不同层级的连线快慢不同。通信最密的切分放在最快的连线上，例如张量并行通常放在同一台服务器内部。

## 4.5.2 回到那次提问：连接决定体验

用本章的骨架重看第一章的场景。回答“一个字一个字地冒出来”，背后是 GPU 每生成一个令牌都要读一遍模型权重，这时卡在高带宽内存的带宽上；高峰期“稍等片刻”，可能是 API 网关在排队限流；手机端的离线助手能在没网时工作，是因为模型被压缩后存放在手机里，借助手机自带的神经网络处理器（NPU）等芯片在本地运行。这些都是连接层面的取舍，与模型“聪明不聪明”关系不大。看 AI 新闻时，也可以先问一句：这条消息说的是哪一层的连接？

需要说明的是，具体的互连产品名称、带宽代数和集群规模更新很快，本章提到的英伟达 NVLink、InfiniBand 等是写作时公开资料中常见的做法，谷歌 TPU 等其他系统另有自己的互连方案。不容易过时的，是“层级—带宽—瓶颈”这套分析方法。

## 4.5.3 实物探索任务

1. **测一次往返延迟。** 在手机上用同一个 AI 应用分别在 Wi-Fi 和移动数据下问同一个简短问题，用秒表记录“点击发送到出现第一个字”的时间和“全部生成完”的时间，各测三次。比较两个时间的差别，想一想：哪一段受网络影响大，哪一段主要取决于数据中心里的计算？
2. **画出你电脑的“服务器之内”。** 打开电脑的系统信息（Windows 的任务管理器“性能”页，或 macOS 的“关于本机—系统报告”），找出 CPU、内存、显卡（或集成显卡/NPU）、硬盘的型号和容量，画一张方框连线图，标出它们之间可能经过的总线。再和 4.2 节的 GPU 服务器结构对照，看看缺了什么。
3. **观察开机状态下的 NPU。** 如果你的手机或电脑标注有 NPU，查一查说明书或官方页面，它支持哪些端侧 AI 功能；打开飞行模式，逐一试试这些功能是否仍能使用，以此判断哪些计算在本地完成、哪些依赖云端。
4. **读一张数据中心照片。** 在新闻或云服务商官网上找一张 AI 数据中心机房照片，辨认机柜、线缆束、网络交换机和管道（液冷或风冷），用 4.3 节的知识写三句话说明：线缆为什么这么多、这么整齐。
5. **查一份 API 文档。** 找任意一家大模型服务商公开的 API 说明，找出“速率限制”“上下文长度”“按令牌计费”这几项，把它们分别对应到 4.4 节中网关、推理服务器和计费系统的位置。

## 4.5.4 可以直接拿去问 AI 的问题

- “请用快递分拣中心做类比，解释为什么 AI 集群训练时，张量并行一般放在同一台服务器内部，而数据并行可以跨服务器？请指出这个类比在哪里不准确。”
- “我测得某 AI 应用首字出现约需一两秒、之后每秒输出若干个字。请帮我分析，这两个时间分别主要受网络、排队、预填充计算和内存带宽中的哪些因素影响？”
- “请比较 PCIe、NVLink、InfiniBand 和以太网在 AI 系统中各自连接什么、处在哪一层，并提醒我哪些数据可能随产品更新而变化，应以官方资料为准。”

提问时，请把 AI 的回答和本章的骨架表对照：它说的是哪一层？有没有把某家公司的做法说成通用规律？带着这种核对习惯，下一章我们将不再看“线怎么连”，而是看线上“流着什么”——数据、计算、令牌、能量和价值。
