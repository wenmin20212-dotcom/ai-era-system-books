# 4.5 電池與熱量怎樣安置：續航、散熱和佩戴舒適性

把手錶摘下來放上充電座，你可能發現背面略微溫熱；外出記錄路線時，電量下降也可能比平日更快。這兩種現象把同一個設計問題帶到眼前：有限的電能存在哪裏，工作中產生的熱量又往哪裏去？電池、芯片、屏幕和錶殼並不是各自安放就算完成，它們的位置、接觸方式與工作安排，共同決定了續航和佩戴體驗。

## 4.5.1 電池佔據的不只是一個空位

智能手錶常用可充電鋰離子電池，具體形狀和封裝隨產品而異。拆解照片裏的電池可能呈扁平塊狀，也可能順應錶殼輪廓做成特殊外形。它通常需要佔據較大空間，因爲在技術條件相近時，儲存更多電能往往意味着需要更多電池體積。

但工程師不能把剩餘空隙全部塞滿電池。電池周圍還要安排固定材料、絕緣層、連接線路，以及滿足製造公差和使用變化的餘量。電池必須避免被螺釘、尖銳邊緣或連接器擠壓，也不宜承擔結構支撐任務。爲抗衝擊而增加的支架，又會擠佔原本能夠儲能的空間。

所以，外形稍厚的手錶未必續航更長，錶殼更大也不一定意味着電池更大。更大的屏幕、更多的傳感器或額外的通信器件，同樣會消耗空間。僅憑外觀，我們能夠描述尺寸，卻不能確定內部空間如何分配。

## 4.5.2 續航是儲能與用能共同給出的結果

電池容量常以毫安時標示，但比較不同電池能夠提供多少能量時，還要考慮標稱電壓。瓦時更直接地表達儲存的電能。即使兩款手錶儲能相近，續航也可能明顯不同，因爲屏幕亮度、定位時長、無線連接和處理任務都會改變平均耗電。

可以把電池理解爲水箱，但應記住這只是類比。水箱能用多久，既取決於裝了多少水，也取決於水流得多快。手錶並不是始終以同一速度消耗電能：短暫亮屏、持續定位和後臺待機，對應不同的負載。廠家給出的續航因此必須連同測試條件閱讀，不能脫離使用方式比較數字。

電池還會隨使用而老化，溫度也會影響其可用性能。低溫環境下，顯示電量和實際可支持的工作時間可能發生變化；長期處於不適宜的高溫環境則可能加快老化。把電池做大隻能解決部分問題，系統減少無效工作同樣重要。

## 4.5.3 熱量要擴散，而不是被藏起來

芯片運算、電源轉換、屏幕發光和充電都會伴隨發熱。尤其在無線充電時，充電座與手錶內接收部分的能量傳遞並非沒有損耗，溫熱不一定全部來自電池本身。熱源在哪裏，需要結合工作狀態和結構資料判斷，不能只憑某處摸起來熱就認定其下方有故障。

手錶通常沒有風扇，主要依靠固體之間的熱傳導，把局部熱量分散到更大區域，再通過表面與環境交換熱量。銅箔、石墨片、導熱界面材料或金屬結構，都可能參與這條通路；具體採用什麼材料、鋪在哪裏，要以相應產品資料爲準。

石墨片與石墨烯不是可以隨意替換的名稱。某些石墨材料沿片面方向較容易導熱，適合鋪散局部熱量，但這不意味着熱會瞬間消失。均熱的作用是減輕熱點，最終仍需要表面把熱量傳出去。

下面的示意圖表達的是可能存在的熱流關係，不代表某一型號的內部佈局：

```text
芯片、電源電路、充電接收部分
              │
       接觸層與擴散材料
              │
      ┌───────┴───────┐
   屏幕及側面結構    底殼與其他部件
      │               │
   周圍空氣        皮膚及周圍環境
```

圖中的分支提醒我們：熱量通常同時沿多條路徑傳遞。增加某一路的熱阻，可以減少該方向的傳熱，卻不能保證完全阻斷。電池也不應被當作專門吸收熱量的“緩衝池”，它本身就需要合適的工作溫度。

## 4.5.4 舒適性不能用一個溫升數字概括

貼膚面溫度不僅由芯片決定，還受環境、皮膚溫度、錶帶鬆緊、汗液和工作持續時間影響。相同的手錶，在陰涼室內和炎熱戶外可能有不同表現。衣袖覆蓋錶殼，也會改變向空氣散熱的條件。

因此，不能把“貼膚溫升不超過一攝氏度”當作所有手錶統一的安全線。接觸溫度、接觸時間、材料和適用標準都需要綜合考慮。金屬摸起來涼，也不等於內部溫度更低：它能較快從手指吸收熱量，因此觸感與塑料不同。

舒適性還涉及重量分佈與接觸壓力。較重的表體若固定不穩，運動時容易晃動；錶帶過緊雖然減少晃動，卻可能增加壓迫和悶溼。電池厚度、底殼曲面及錶帶連接位置，都會間接影響佩戴感受。

系統也會主動參與熱管理，例如降低充電速度、限制部分任務或顯示溫度提示。出現這類提示時，應遵循設備說明，而不是設法繞過保護繼續工作。

## 4.5.5 用日常記錄觀察，不做發熱試驗

可以在正常使用中做一次簡短記錄：註明環境大致冷熱、開始與結束電量、是否持續定位或通話，以及是否出現溫度提示。充電觀察應使用兼容設備，保持表面乾燥，按說明放在通風處，不覆蓋充電座。

不必爲了比較而讓手錶長時間滿負荷運行，也不要用冰箱、熱水或吹風機制造溫差。手摸只能提供粗略感受，不能證明內部使用了哪種導熱材料，更不能據此判定溫度安全。

若出現明顯異常發燙、鼓起、異味或外殼分離，應停止使用和充電，聯繫正規售後，不自行擠壓或拆卸電池。理解這一小塊空間的關鍵，不是尋找某種“神奇散熱層”，而是看清儲能、用能、傳熱和皮膚接觸之間的相互制約。
