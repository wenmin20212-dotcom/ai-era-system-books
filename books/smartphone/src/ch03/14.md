# 3.3 射频前端（RFFE）：空中电磁波的守门人

打开手机的状态栏，右上角那几格信号和“5G”标识每天都在那里，很少有人细看。你在地铁里刷视频、在电梯里收消息时，手机其实一刻不停地在两个世界之间转换：一边是芯片内部由 0 和 1 组成的数字世界，另一边是空气中看不见、摸不着的电磁波。这两个世界之间有一道关口，负责把比特“送出去”，再把电波“接进来”。这道关口叫作**射频前端**（Radio Frequency Front End，简称 RFFE）。

本节沿着一个数据包的往返路线，看看射频前端里几种关键器件各自负责什么。

## 3.3.1 先分清两个方向：上行与下行

手机通信有两个方向：

- **上行链路**（Uplink）：手机把数据发往基站，比如你发出一条消息、上传一张照片。
- **下行链路**（Downlink）：基站把数据发给手机，比如你加载网页、播放视频。

这两个方向面对的难题正好相反。上行的难处是**功率不够**，手机要把微弱的电信号放大到足以飞越几百米乃至数公里的强度。下行的难处是**信号太弱、干扰太多**，手机要从嘈杂的电磁环境里认出属于自己的那一丝信号。射频前端的器件，就是围绕这两个难题配置的。

## 3.3.2 发射之路：把比特“喊”到空中

假设你按下了“发送”键，一段文字已经被编码成一串数字比特，接下来它要经过以下几站。

**第一站：基带调制。** 基带处理器（Baseband）是负责通信“语言”的芯片部分，它把数字比特调制成一种频率较低的正弦波，称为**中频信号**。可以这样理解：比特本身没法在空气里传播，基带的工作是把它们“刻”进一段波形的振幅和相位变化里，就像把文字写进乐谱。

**第二站：收发机混频。** 中频信号的频率还不够高，不能直接用于 5G 通信。**收发机**（Transceiver）通过一种叫“混频”的操作，把信号整体搬移到更高的载波频率上，例如 5G 常用的 **3.5GHz** 频段。打个比方，同一首曲子从低音区整体移调到高音区，旋律没变，音高变了。频率搬上去以后，信号才能落进运营商获准使用的那段频谱里。

**第三站：功率放大器。** 收发机输出的信号依然很微弱，送到天线上传不了多远。这时要靠**功率放大器**（Power Amplifier，简称 PA）。PA 从电池汲取电能，把微波信号的功率放大**数千倍**，输出功率可以达到 **200 毫瓦（mW）** 量级。200 毫瓦听起来不多，但对一枚指甲盖大小的芯片来说，这是一份相当吃力的工作。PA 也是射频前端里最耗电、发热最明显的器件之一。打电话时手机贴脸发烫、信号差的地方掉电特别快，原因之一就是 PA 在加大马力“喊话”。

**第四站：带通滤波。** 放大器并不完美，它在放大目标信号的同时，也会产生落在目标频段之外的杂散成分。如果这些杂波原样发射出去，就会干扰别的频段、别的用户。所以信号还要经过**带通滤波器**（Band-Pass Filter），它只放行指定频段，把带外杂波挡在门外，好比一扇只认特定门禁卡的闸机。

**第五站：天线辐射。** 净化后的微波信号最终送入手机的金属天线，变成电磁波辐射到空中，飞向基站。手机边框上那几道细细的塑料缝隙，往往就是天线的分段位置。

## 3.3.3 接收之路：从噪声中捞出“耳语”

回程的难度更大。基站发出的信号穿过空气、墙壁和人体，到达手机时已经衰减得极其微弱，功率可能只有**皮瓦（pW）级**。1 皮瓦是 1 毫瓦的十亿分之一。手机发射时用的是毫瓦，接收时面对的是皮瓦，两者相差许多个数量级。这就好比一个人刚在操场上大声喊完话，转头又要在喧闹的人群中听清远处一句耳语。

**第一站：天线捕捉。** 天线从空中接收电磁波，把它转化为极其微弱的电信号。天线收到的不止目标信号，还有其他频段、其他设备甚至手机自己发射信号的“回声”。

**第二站：开关与滤波。** 一部手机要支持多个频段、多种制式，**射频开关**（RF Switch）负责把天线接到正确的通路上，像铁路道岔一样给信号分配轨道。紧随其后的滤波器把无关频段的干扰隔离出去，只让目标频段的信号进入下一站。

**第三站：低噪声放大器。** 皮瓦级的信号必须先放大才能处理，但这里有一个陷阱：任何放大器本身都会引入噪声，如果第一级放大器噪声很大，微弱信号会直接被淹没。**低噪声放大器**（Low Noise Amplifier，简称 LNA）的设计重点就在于自身的**噪底**（Noise Floor，即器件固有噪声的水平）足够低。它在尽量不添加杂音的前提下把信号抬高，相当于一个耳朵灵敏又不爱说话的翻译。

**第四站：基带解调。** 放大后的信号经收发机把频率搬回低处，交给基带解调，把波形还原成数字比特。网页上的文字、视频里的画面，就从这里重新出现。

## 3.3.4 一张表看清上下行分工

| 环节 | 发射（上行）链路 | 接收（下行）链路 |
|---|---|---|
| 起点 / 终点 | 基带把比特调制为中频正弦波 | 基带把信号解调还原为比特 |
| 频率搬移 | 收发机混频，上搬至 3.5GHz 等载波频段 | 收发机把高频信号搬回低频 |
| 放大器 | 功率放大器（PA），放大数千倍，可达约 200mW | 低噪声放大器（LNA），在极低噪底下放大 |
| 信号强度特点 | 从弱到强，核心矛盾是功率与耗电 | 到达时仅皮瓦级，核心矛盾是噪声与干扰 |
| 过滤与选择 | 带通滤波器滤除放大产生的带外杂波 | 开关选择通路，滤波器阻隔干扰频段 |
| 与空气的接口 | 金属天线辐射电磁波 | 金属天线捕捉电磁波 |

从表中可以看出射频前端的分工：**PA 负责“喊得响”，LNA 负责“听得清”，滤波器和开关负责“分得开”**。三类器件缺一不可，任何一环表现不佳，用户感受到的都是同样的结果：信号格变少、网速变慢、电量掉得快。

## 3.3.5 为什么称它为“守门人”

基带决定说什么语言，天线决定怎样与空气接触，射频前端夹在两者之间，管的是能量与纯净度：往外送的信号要足够强又不能“串门”，往里收的信号要足够灵敏又不能被噪声淹没。手机支持的频段越多，前端需要的滤波器、开关和放大器通路就越多，主板上的空间与功耗压力也随之增加。这正是第二章提到射频前端时，它在主板上占据可观面积的原因。
