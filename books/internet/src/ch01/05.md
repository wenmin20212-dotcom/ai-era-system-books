# 1.2 互联网是什么：网络的网络

打开手机的“设置”，找到 Wi-Fi 详情，你会看到一串类似 192.168.1.5 的地址；关掉 Wi-Fi 改用流量，再去网站上查“我的 IP 地址”，看到的又是另一串数字。同一部手机，换一种接入方式，就像换了一个“门牌”，可网页照样能打开。这说明你连上的不是某一根线、某一家公司，而是一个由许多独立网络拼起来的整体。互联网（Internet）这个词本身就点明了这一点：inter- 意为“在……之间”，Internet 原意是“网络之间的互联”。

## 1.2.1 不是一张网，而是成千上万张网

很多人想象中的互联网是一张覆盖全球的大网，由某个机构统一建设和管理。实际情况正好相反：互联网没有总建设方，也没有总控制室。它由大量各自独立运营的网络组成，比如：

- 你家的家庭网络：一台路由器加几部手机、电脑；
- 学校、企业的园区网；
- 电信运营商的宽带网和移动网；
- 视频网站、云服务商自己的数据中心网络；
- 跨国运营商的国际骨干网。

每张网都有自己的主人、预算和管理规则，设备可能来自不同厂商，内部结构也各不相同。它们约定用同一套“语言”交换数据，再通过一个个连接点相互接通，就成了“网络的网络”（network of networks）。

打个比方：全国的公路由国道、省道、城市道路、小区内部道路组成，修路的是不同单位，但车辆遵守同样的交通规则，路口彼此衔接，一辆车就能从小区开到另一个省。互联网中的“车”是数据包，“交通规则”是一组公开的协议。

## 1.2.2 把网络粘在一起的三样东西

各自独立的网络能拼成一个整体，靠的是三样东西：

| 要素 | 作用 | 类比 |
|---|---|---|
| 统一的协议 | 规定数据怎样打包、怎样标注地址，核心是网际协议（IP，Internet Protocol） | 统一的信封格式和地址写法 |
| 全局唯一的地址 | 每台对外通信的设备（或其所在网络的出口）有一个在全网可识别的 IP 地址 | 不会重复的邮政地址 |
| 网络之间的互联与路由 | 不同网络在连接点交换数据，并互相告知“哪些地址能经我到达” | 邮局之间的转运协议 |

其中最关键的是 IP。它只做一件事：把数据切成一个个带有源地址和目的地址的数据包，尽力送到目的地。它不管底下走的是光纤、铜线还是无线电，也不管上面跑的是网页还是视频。正因为 IP 要求得少，几乎任何物理网络都能接进来，任何应用都能跑在上面。这种“中间细、两头宽”的结构常被形象地称为“沙漏模型”，第四章讲分层模型时还会详细展开。

## 1.2.3 网络与网络如何相连：自治系统

在互联网的尺度上，一个由同一机构管理、对外采用统一路由策略的网络集合，叫作自治系统（AS，Autonomous System）。一家大型运营商、一所大学、一家大型内容公司，都可能各自是一个或几个自治系统，并拥有由地区互联网注册机构分配的自治系统号码。根据公开统计资料，目前全球处于活跃状态的自治系统数量在数万到十万量级。

自治系统之间用边界网关协议（BGP，Border Gateway Protocol）交换“可达信息”：A 告诉 B“这些地址段在我这里”，B 再根据自己的商业关系和策略决定是否转告别人。连接方式大致有两类：一类是付费请别人帮忙把流量送往全网，叫转接（transit）；另一类是双方对等交换各自用户之间的流量，通常不互相付费，叫对等互联（peering）。许多对等互联发生在互联网交换中心（IXP，Internet Exchange Point）。这些内容将在第二章和第四章展开，这里只需记住：互联网的整体连通，是无数个双边连接和协议一点点织出来的，而不是由谁统一规划的。

## 1.2.4 你的一次访问跨越了几张网

回到你点开的那个网页。数据包从手机出发，先经过家里的 Wi-Fi 和路由器，这是第一张网；路由器把它交给宽带运营商的接入网和城域网，这是第二张；如果网站服务器在另一家运营商或某个云服务商那里，数据包还要穿过运营商之间的互联点，进入对方网络；若服务器在海外，还会经过国际出口和海底光缆。在 Windows 的命令行里运行 `tracert`、在 macOS 终端里运行 `traceroute`，加上一个网址，就能看到沿途一跳跳的路由器地址，大致辨认出“出了家门”“进了运营商”“换了一家网络”的位置。第七章会教你仔细解读这些结果。

在这趟旅程中，没有哪一家网络知道全程路线。每台路由器只根据目的地址查自己的表，把数据包交给“下一跳”。全局的路，是由许多局部决定接力完成的。

## 1.2.5 小结：没有中心，却能连通

把以上几点合起来，可以给互联网下一个工作定义：**互联网是由众多独立管理的网络，按照以 IP 为核心的一组公开协议，通过相互协商的互联关系连接而成的全球性计算机网络系统。**

这个定义里有三个关键词：“独立管理”说明它没有总负责人；“公开协议”说明它的规则任何人都能读到，标准文档主要以 RFC（Request for Comments，意见征求稿）形式发布；“相互协商”说明它的连通靠的是网络之间的约定与合作。理解了“网络的网络”，你就能明白：为什么某条海缆出故障，有的网站变慢、有的不受影响；为什么换个运营商，同一个网站的速度会不一样。

不过，日常说的“上网”“万维网”“局域网”“5G 网络”，和互联网是不是一回事？它们的边界在哪里？这正是下一节要厘清的问题。
