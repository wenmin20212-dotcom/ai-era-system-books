# 1.3 互联网的边界：互联网、万维网、局域网与移动网络

晚上回到家，手机自动连上了家里的 Wi-Fi，你用电脑把一份文件“投”到客厅的打印机上，又在手机浏览器里打开一个新闻网页，接着切到微信给朋友发了条语音。出门下楼，Wi-Fi 信号断了，手机悄悄换成了 4G 或 5G，视频照样在播。

这几件事，我们平时都笼统地叫“上网”。其实它们分别用到了不同的“网”：有的只在你家里转了一圈，有的跨过了大洋；有的属于万维网，有的根本和网页无关。分不清这些边界，后面讲路由、讲域名时就容易混淆。本节就把这几个常被混用的词摆在一起，逐个划清界线。

## 1.3.1 互联网与万维网：公路和公路上的一种车

最常见的混淆，是把“互联网”（Internet）和“万维网”（World Wide Web，简称 Web 或 WWW）当成同一个东西。

上一节说过，互联网是“网络的网络”：成千上万个独立运营的网络，按照共同的 IP 协议（Internet Protocol，网际协议）互相连通，任何两台接入的设备都能互相送达数据包。它是一套**基础设施**，像一张覆盖全球的公路网。

万维网则是跑在这张公路网上的**一种应用**。它由三样东西组成：

- **网页的写法**：HTML（超文本标记语言），规定一个页面里有哪些文字、图片和链接；
- **网页的地址**：URL（统一资源定位符），比如浏览器地址栏里以 `https://` 开头的那一串；
- **取网页的规则**：HTTP（超文本传输协议）及其加密版本 HTTPS。

万维网由蒂姆·伯纳斯-李（Tim Berners-Lee）于 1989 年前后在欧洲核子研究中心（CERN）提出，而互联网的前身阿帕网早在 1969 年就已运行。也就是说，先有公路，二十年后才出现了万维网这种“车”。

公路上跑的不只有这一种车。你收发电子邮件、玩联网游戏、用即时通信软件打视频电话、让手机同步时间，这些都在使用互联网，但不一定经过网页。很多手机 App 的界面并不是网页，它在后台仍可能用 HTTP 和服务器交换数据，但这只是借用了万维网的“取货规则”。下面这张表可以帮你对照：

| 对比项 | 互联网（Internet） | 万维网（Web） |
|---|---|---|
| 本质 | 全球互联的网络基础设施 | 运行在互联网上的一种信息服务 |
| 核心规则 | IP、TCP 等 | HTML、URL、HTTP |
| 出现时间 | 前身阿帕网 1969 年 | 1989 年前后提出 |
| 打个比方 | 公路网 | 公路上的一类车 |
| 没有它会怎样 | 一切联网应用都无从谈起 | 网页打不开，但邮件、游戏等仍可运行 |

本书以“点开一个网页”为锚点，是因为网页最常见、最容易观察；但要始终记住，网页只是互联网众多用途中的一种。

## 1.3.2 局域网：你家里那一小块“自留地”

回到开头把文件发给打印机的场景。这份文件很可能根本没有离开你家：电脑把数据交给无线路由器，路由器转给打印机，全程在屋子里完成。这种覆盖一个家庭、一间办公室或一栋楼的小范围网络，叫作**局域网**（Local Area Network，LAN）。

局域网有几个特点：

- **范围小、归属清楚**：它属于你、你的公司或学校，由你自己（或网管）说了算；
- **常用以太网和 Wi-Fi 连接**：网线接的是以太网（Ethernet），无线连接的是 Wi-Fi；
- **使用“私有地址”**：家里设备拿到的地址多半形如 `192.168.x.x` 或 `10.x.x.x`，这类地址在 RFC 1918 中被划为私网专用，只在内部有效，到了外面的互联网上并不能直接被找到。

局域网可以完全不连互联网而独立工作。拔掉光猫上的入户光纤，你家电脑照样能把文件发给打印机，只是打不开外面的网页。家里的路由器正好站在边界上：一边是你的局域网，另一边通过运营商接入互联网。它负责把内部私有地址“翻译”成对外的地址，这项技术叫 NAT（网络地址转换），第五章会专门讲。

所以，局域网和互联网的关系，像是自家院子和外面的公路：院子里的小路自成一体，院门一开就和公路相连。

## 1.3.3 移动网络：另一条通往互联网的入口

下楼后手机换成了 4G/5G，这时你用的是**移动通信网络**，也叫蜂窝网络（Cellular Network）。它由运营商的基站和核心网组成，最初是为打电话、发短信设计的，后来才逐渐承担起大量上网流量。

这里要分清两层意思：

1. **移动网络本身是一张运营商的专用网**。基站负责无线信号，核心网负责认证你的 SIM 卡、计费、管理你在不同基站间的切换。打普通电话、发短信，可以只用到这张网。
2. **移动网络又是接入互联网的一种方式**。当你用流量刷网页时，数据先经过基站和核心网，再从运营商的出口进入互联网。

换句话说，移动网络和家里的宽带一样，都是把你“接进”互联网的入口，只不过一个用无线电波，一个用光纤。从互联网的角度看，移动运营商的网络也是“网络的网络”中的一员。至于基站怎样分配频谱、手机怎样在基站之间无缝切换，本系列《移动通信》一册会详细展开；Wi-Fi 的原理则留给《Wi-Fi》专册。

## 1.3.4 把几种“网”摆进同一张图

现在可以把开头的几件事重新归类：

| 日常操作 | 用到的网络 | 是否进入公共互联网 |
|---|---|---|
| 电脑把文件发给家里的打印机 | 局域网（Wi-Fi 或网线） | 通常不进入 |
| 用浏览器打开新闻网页 | 局域网 → 宽带接入 → 互联网，使用万维网服务 | 进入 |
| 微信发语音 | 同上，但使用的是即时通信应用，不是网页 | 进入 |
| 下楼后继续看视频 | 移动网络 → 互联网 | 进入 |
| 用手机打一个普通电话 | 移动通信网络的话音业务 | 传统方式下不经过公共互联网 |

（说明：随着 VoLTE 等技术普及，写作时不少运营商的语音已经以 IP 分组方式在其网络内承载，但这仍是运营商内部的网络，不等于走公共互联网。）

如果画成一张示意图，大致是三个圈：最里面是你家的局域网，外面一层是运营商的接入网络（宽带或移动网），最外面是由众多网络互联而成的互联网；万维网、电子邮件、视频、即时通信等应用，则像不同的车辆，跑在这些圈连成的道路上。

## 1.3.5 小结：分清“路”和“车”，“院子”和“入口”

这一节划出了四条边界：互联网是全球互联的基础设施，万维网是其上的一种应用；局域网是归你管的小范围网络，路由器是它通往互联网的院门；移动网络是运营商的专用网，同时也是进入互联网的无线入口。有了这几条边界，下一节回顾互联网的演变时，你就能看清：每一次变化，究竟是“路”变了，还是路上的“车”变了，或是“入口”变了。
