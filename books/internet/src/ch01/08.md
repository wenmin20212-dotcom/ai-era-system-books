# 1.5 本章骨架小结与实物探索任务

第一章的任务是“认识对象”：在拆开互联网之前，先看清它是什么、边界在哪里、从哪里来。我们从按下回车的那一秒出发，一路追问到“网络的网络”这个定义，再把互联网和几个常被混用的概念分开，最后回顾了它半个多世纪的演变。本节先把这些内容收拢成一副骨架，再请你放下书，拿起手边的设备，亲手验证这副骨架。

## 1.5.1 本章骨架回顾

把本章内容压缩成五个要点，大致如下：

1. **一个网页背后是一连串协作。** 按下回车后，浏览器要先通过域名系统（DNS，Domain Name System）把名字换成 IP 地址，再与服务器建立连接，多数网站还要完成加密协商，然后发送请求、接收内容、渲染页面。这些步骤常常在一秒左右完成，涉及的设备可能分布在不同城市甚至不同国家。
2. **互联网是“网络的网络”。** 它不是某一家公司建成的一张大网，而是成千上万个独立管理的网络，按照共同的协议（以 TCP/IP 协议族为核心）互相连接而成。每个网络自己做主，又遵守同一套“交通规则”。
3. **互联网有清楚的边界。** 互联网是底层的连接设施；万维网（WWW，World Wide Web）是跑在它上面的一种应用；局域网（LAN，Local Area Network）是家庭、学校、公司内部的小网络；移动网络是一种接入手段。它们是层与层、部分与整体的关系，不能画等号。
4. **互联网是逐步长出来的。** 从 20 世纪 60 年代末的阿帕网（ARPANET），到 1983 年阿帕网全面切换到 TCP/IP，再到 90 年代万维网普及、商业化开放，以及之后的宽带、移动互联网与云服务，每一阶段都在原有基础上叠加，而不是推倒重来。
5. **“开放、分层、去中心”贯穿始终。** 这几个设计特点让互联网能够不断接入新设备、新网络和新应用，也带来了安全和管理上的难题。后面的章节会反复回到这条线索。

用一张对照表把易混概念再过一遍：

| 概念 | 它是什么 | 一个日常例子 |
|---|---|---|
| 互联网 | 全球互联的网络集合，提供数据传送能力 | 你的手机能连上海外服务器 |
| 万维网 | 用网址和超链接组织的网页系统 | 在浏览器里点开一个新闻页面 |
| 局域网 | 小范围内的本地网络 | 家里路由器下的电脑和打印机 |
| 移动网络 | 运营商提供的无线接入方式 | 出门后手机改用 4G/5G 上网 |

## 1.5.2 实物探索任务

下面的任务只需要手机或电脑，不必编程，每个十几分钟即可完成。

**任务 1：给一次打开网页计时。** 用电脑浏览器打开一个常用网站，按 F12 打开“开发者工具”，切换到“网络”（Network）选项卡后刷新页面。观察列表里有多少条请求、总共用了多长时间，再点开第一条请求，看看“时间”（Timing）分项里有没有 DNS 查询、建立连接、等待响应等阶段。把它和 1.1 节描述的步骤一一对应起来。

**任务 2：找到你家网络的“分界线”。** 在手机的 Wi-Fi 设置里查看当前连接的详细信息，记下“IP 地址”和“路由器”（或“网关”）两项。你多半会看到以 192.168 或 10 开头的地址，这是局域网内部使用的私有地址。再用浏览器搜索“我的 IP”，看看外部网站眼中的你是什么地址。两个地址不同，正说明你家局域网和互联网之间隔着一道“门”，第二章和第五章会详细讲这道门。

**任务 3：切换接入方式做对照。** 先在 Wi-Fi 下用搜索引擎查一次“我的 IP”，再关掉 Wi-Fi 改用移动数据查一次。两个结果通常属于不同运营商或不同网段。这说明同一部手机可以通过不同的接入网进入同一个互联网，接入方式变了，互联网本身没有变。

**任务 4：画一张“我的上网路径草图”。** 在纸上从左到右画出：你的设备、家里的路由器、光猫（或手机基站）、运营商、远方的网站服务器。先凭本章的理解画，不追求准确，把不确定的地方打上问号。读完第二章后再回来修改，看看问号减少了多少。

**任务 5：查一段历史原文。** 在 RFC 编辑部的官方网站上搜索 RFC 1，看看这份 1969 年发布的文档讲了什么，标题叫什么。体会一下：今天的互联网标准仍然以这种公开编号的文档形式发布。

## 1.5.3 可以直接拿去问 AI 的问题

把下面的问题复制给你常用的 AI 助手，读完回答后，再用本章内容核对它说得对不对：

- “请用中学生能听懂的话，解释互联网和万维网有什么区别，并各举两个不属于对方的例子。”
- “我在手机 Wi-Fi 设置里看到的 IP 地址是 192.168.1.5，但网站显示我的 IP 是另一个地址，这是为什么？请分步骤解释。”
- “阿帕网为什么在 1983 年统一改用 TCP/IP？这一变化对后来互联网的扩展起了什么作用？请注明可以查证的资料来源。”

AI 的回答可能有遗漏或错误，尤其在年份和细节上。要求它给出资料来源，再到 RFC、互联网相关机构官网等原始资料中核对，这本身就是一种学习方法。

## 1.5.4 小结与过渡

到这里，我们已经从外部看清了互联网这个对象：它是什么、不是什么、怎么来的。下一章，我们把它拆开，沿着数据从你手中出发的方向，依次走过家庭网络、接入网、骨干网与交换中心、海底光缆，直到远方的服务器和内容分发网络，看看这张“网络的网络”究竟由哪些部件组成。
