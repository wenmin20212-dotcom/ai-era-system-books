# 5.3 热量流：从芯片到天空

用手机连续录几分钟 4K 视频，机身会明显发烫；笔记本电脑跑一会儿大型游戏，风扇就会呼呼作响。这些热量不是“故障”，而是电子设备工作的必然产物。把这个场景放大几万倍，就是数据中心每天面对的局面：每一台服务器都是一个小暖炉，成千上万台排在一起，热量一刻不停地产生。上一节我们追踪了电力从电网到芯片的路径；这一节反过来，看这些电变成热之后，怎样一步步离开机房，最终散到大气中。

## 5.3.1 热从哪里来：电进来，热出去

先建立一个最重要的直觉：**服务器消耗的电，几乎全部变成了热**。芯片处理你的照片、生成缩略图、回应你的请求，并不会把电能“储存”在数据里。从能量角度看，计算的结果是信息，而电能最终以热的形式释放（第八章 8.1 节会从热力学角度解释原因）。

所以，一个 IT 负载为 1 兆瓦（MW）的机房，就意味着要持续搬走大约 1 兆瓦的热量，相当于五百到一千台家用电暖器同时开着。热量流和电力流在规模上是“镜像”的：电送进来多少，热就要搬出去多少。只要有一处搬不出去，温度就会上升，设备会降频、报警，甚至自动关机保护。

热量的主要来源可以列成一张表：

| 热源 | 特点 |
|---|---|
| CPU、GPU 等处理器 | 发热最集中，单颗芯片功耗从几十瓦到上千瓦不等（写作时高端 AI 芯片已达千瓦量级） |
| 内存、硬盘、网卡 | 单个功耗较小，但数量多 |
| 电源模块、UPS | 电能转换中的损耗也变成热 |
| 照明、人员 | 占比很小 |

## 5.3.2 一路接力：热量的五段旅程

热量离开数据中心，像一场接力赛，每一棒都把热交给下一棒，而且每一棒都要求“下游比上游更凉”，因为热只会自发地从高温流向低温。以常见的风冷加冷冻水系统为例：

1. **芯片到散热器**：芯片内部温度可达几十到近百摄氏度，热量通过导热材料传给金属散热片。
2. **散热器到空气**：服务器风扇把冷通道的空气吸进来，吹过散热片，排出时温度升高十几摄氏度。
3. **空气到冷水**：热空气回到机房空调（CRAH）的盘管，把热交给盘管里流动的冷冻水。
4. **冷水到制冷机或冷却水**：冷水机组（Chiller）把热量“泵”到温度更高的冷却水回路中；在天气凉爽时，也可以绕过压缩机，直接利用室外冷源，这叫自然冷却（Free Cooling）。
5. **冷却塔到天空**：冷却塔让水部分蒸发，借助蒸发吸热把热量带进大气；干冷器则靠风吹金属翅片直接散热。

可以用一个类比理解：热量像一群从山顶往山下走的人，每一段路都必须是下坡（温差）。制冷机的作用，相当于在中间某处装一台“电梯”，把热量硬抬到更高处，让它能顺着坡走到室外，但这台电梯本身要耗电，而且耗的电最后也变成热，一并排出。

## 5.3.3 温度刻度：每一段到底多热

热量流动需要温差，于是每一段都有自己的典型温度区间。美国采暖、制冷与空调工程师学会（ASHRAE）在公开的数据中心热环境指南中，给出的服务器进风推荐范围大约是 **18–27°C**，并允许在一定条件下更宽。

| 位置 | 典型温度（公开资料中的常见范围） |
|---|---|
| 芯片内部 | 数十至约 100°C |
| 服务器进风（冷通道） | 约 18–27°C |
| 服务器出风（热通道） | 常比进风高 10–20°C |
| 传统冷冻水供水 | 约 7–12°C，新建设计趋向更高 |
| 室外环境 | 随地区和季节变化 |

这里藏着一条节能逻辑：**进风温度允许得越高，链条中每一段的“坡”就越容易，制冷机需要出力的时间就越少**。这正是许多数据中心逐步提高送风和供水温度、并倾向于选址在凉爽地区的原因（选址问题见 8.5 节）。

## 5.3.4 热量的时间节奏与“新出口”

热量流不是匀速的。白天视频播放、晚上集中备份、AI 训练任务启动时，负载起伏，热量随之起伏；夏季室外温度高，最后一棒最难跑，制冷系统能耗随之上升。运维人员会盯着机柜进出风温度和水温曲线，一旦某个机柜出现局部过热（俗称“热点”），就要调整气流或负载。

另一个变化来自 AI 算力中心。单个机柜的功率从过去常见的几千瓦，上升到几十千瓦乃至更高，空气的携热能力跟不上，于是越来越多的设计让冷却液直接贴近芯片，跳过“空气”这一棒，这就是 7.3 节要讲的液冷。

热量也不一定非要排到天上。北欧等地已有数据中心把余热接入城市集中供暖管网，为居民楼供热，这在公开报道中多有记载；液冷系统回水温度较高，更便于回收利用。这时，你上传照片产生的那一点热，可能在冬天为某户人家的暖气片提供了一份温度。

## 5.3.5 小结

热量流是电力流的另一面：电从电网流进芯片，热从芯片流向天空，两者数量大体相当。它沿着“芯片—空气—冷水—冷却塔—大气”的接力链条，依靠一级级温差向外传递，必要时由制冷机消耗额外电能来推动。理解了这条热量流，就能明白 PUE 中“非 IT 能耗”的很大一部分花在了哪里。下一节，我们转向数据中心里另一种看不见却同样不停流动的东西——运维人员的监控、告警与工单。
