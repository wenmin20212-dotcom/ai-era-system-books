# 4.1 搜索引擎与网站：爬虫协议、站点地图与搜索引擎优化

随便打开一个网站，在浏览器地址栏的域名后面加上“/robots.txt”，比如 example.com/robots.txt，按下回车。很多网站会显示几行朴素的文字，例如“User-agent: \*”“Disallow: /admin/”。这是网站写给搜索引擎爬虫的一张告示，说明哪些地方欢迎来抓取，哪些地方请绕行。再换成“/sitemap.xml”试试，有时会看到一长串网址列表，那是网站主动递给搜索引擎的“访问清单”。

这两个小文件说明了一件事：网页并不是被动等着爬虫来搬运的。网站和搜索引擎之间有一套约定、一套沟通渠道，也有一门围绕排名展开的专门手艺。本节就来看这条连接线。

## 4.1.1 爬虫协议：门口的一张告示

robots.txt 的正式名称是“机器人排除协议”（Robots Exclusion Protocol，REP）。它诞生于上世纪 90 年代中期的互联网早期，长期只是业界的默契。2022 年，它以 RFC 9309 的编号被互联网工程任务组（IETF）发布为标准文档。

它的规则很简单：

| 指令 | 含义 | 示例 |
|---|---|---|
| User-agent | 这组规则针对哪个爬虫 | `User-agent: Googlebot` 只对谷歌爬虫生效，`*` 表示所有爬虫 |
| Disallow | 不要抓取的路径 | `Disallow: /cart/` |
| Allow | 在禁止范围内单独放行的路径 | `Allow: /cart/help.html` |
| Sitemap | 告诉爬虫站点地图在哪里 | `Sitemap: https://example.com/sitemap.xml` |

理解 robots.txt，要抓住三个容易混淆的地方。

第一，**它是君子协定，不是门锁**。主流搜索引擎的爬虫会遵守它，但它没有任何技术上的强制力。恶意爬虫完全可以无视它。真正需要保密的内容必须靠登录验证、权限控制来保护，写在 robots.txt 里反而等于公开告诉所有人“这里有东西”。

第二，**禁止抓取不等于禁止收录**。谷歌的官方文档明确说明：如果一个被 robots.txt 屏蔽的网页被其他网站大量链接，它的网址仍可能出现在搜索结果中，只是没有摘要。要让网页不进入索引，应该允许抓取，并在网页里放上“noindex”标记，即 `<meta name="robots" content="noindex">`，或在服务器响应头中声明。爬虫必须先读到网页，才能看到这条“请勿收录”的指令。

第三，**规则是按爬虫名字分别写的**。近几年出现了大量为训练大语言模型而采集网页的爬虫，不少网站开始在 robots.txt 中单独屏蔽它们，同时保留对传统搜索爬虫的开放。这让这份老协议在 AI 时代又成了讨论焦点。

## 4.1.2 站点地图：主动递上的清单

如果说 robots.txt 是“别去哪里”，站点地图（Sitemap）就是“请来这里”。它通常是一个 XML 格式的文件，列出网站希望被发现的网址，还可以附上每个页面的最后修改时间。2006 年前后，谷歌、雅虎、微软共同支持了 sitemaps.org 上的这一格式，此后它成为各大搜索引擎通行的做法。

站点地图对这几类网站特别有用：

- **新网站**：外部链接还很少，爬虫顺着链接很难找过来；
- **大网站**：页面成千上万，有些深藏在多层目录之下；
- **更新频繁的网站**：新闻、电商，需要让爬虫知道哪些页面刚刚变了。

要注意的是，站点地图只是建议，不是命令。搜索引擎会参考它来发现网址、安排抓取，但抓不抓、收不收、排第几，仍由搜索引擎自己判断。

除了这两个文件，各大搜索引擎还提供面向网站管理员的工具平台，比如写作时谷歌的 Search Console、微软必应的 Webmaster Tools、百度的搜索资源平台。站长可以在这里提交站点地图、查看哪些页面被收录、发现抓取错误。这是网站与搜索引擎之间少有的“双向窗口”。

## 4.1.3 搜索引擎优化：顺着系统的逻辑做内容

搜索引擎优化（Search Engine Optimization，SEO）指的是通过改进网站本身，让它在搜索结果中获得更好的自然排名。所谓“自然”，是相对于付费广告而言的，广告的问题留到 4.3 节再谈。

按本书第二章的拆解，SEO 的工作其实正好对应搜索引擎的几个部件：

| 搜索引擎环节 | 网站可以做什么 |
|---|---|
| 爬虫抓取 | 网站结构清晰、内部链接通畅、服务器稳定、不误封爬虫 |
| 文档处理 | 页面标题（title）准确、正文是可读的文字而不是全部做成图片、图片有替代文字说明 |
| 查询匹配 | 使用用户真正会搜的词汇来写内容，而不是只用行业黑话 |
| 排序 | 内容有用、可信、加载快、在手机上好用，并获得其他网站的自然引用 |

谷歌公开的《搜索引擎优化入门指南》和搜索质量评估指南反复强调一个方向：为人写作，而不是为搜索引擎写作。它在质量评估指南中提出经验、专业性、权威性和可信度这几个维度（常简称 E-E-A-T），用来指导人工评估员判断内容质量。需要说明，这是谷歌评估体系中的概念，它说明了谷歌希望排序系统奖励什么，但并不等于某一个可以直接打分的排名因子。

至于搜索引擎究竟用了哪些信号、各占多少权重，各家都没有完整公开。市面上流传的“两百多个排名因素”之类说法，多来自业内经验总结和推测，读者应当把它们与官方文档区分开。

## 4.1.4 白帽与黑帽：一条持续较量的边界

业内常把 SEO 分成两类：遵守搜索引擎指南、靠改进内容和体验获得排名的“白帽”做法；以及靠操纵系统漏洞获取排名的“黑帽”做法，例如堆砌关键词、给爬虫和用户看不同内容（称为“伪装”，cloaking）、批量购买链接、大量生成低质量页面。

黑帽手段之所以存在，是因为排名意味着流量，流量意味着收入。而搜索引擎一旦被这些手段攻破，用户得到的结果就会变差。于是，网站与搜索引擎的关系天然带着双重性：一方面是合作，网站提供内容，搜索引擎带来访客；另一方面是博弈，部分网站试图“走捷径”，搜索引擎则不断升级识别手段。这正是第三章 3.5 节反作弊的来由。

## 4.1.5 小结：一条双向的连接线

把本节的内容串起来，网站与搜索引擎之间流动着两类东西：网站发出的**信号**，包括 robots.txt 的边界、站点地图的清单、页面上的标题和标记；搜索引擎回馈的**流量**，以及通过站长平台给出的收录和错误报告。理解了这条连接线，你就能明白，为什么有些好文章搜不到，可能只是被误挡在了门外；也能明白，为什么最稳妥的“优化”，往往就是把内容做得真正对人有用。
