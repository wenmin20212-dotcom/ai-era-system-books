# 0.2 一张 Wi-Fi 与无线网络的认知骨架地图

晚上回到家，手机屏幕右上角的扇形图标自动亮起，几秒钟后微信消息涌进来。这个过程熟悉得让人忘了它的存在。可是如果有人追问一句：“刚才那几秒里，到底是谁在和谁说话？”大多数人会发现，自己对无线网络的了解是一堆零散的碎片：知道路由器要放高一点，知道 5G 的 Wi-Fi（其实是 5 GHz 频段）更快但穿墙差，知道要设密码，却说不清这些碎片之间是什么关系。

本节要做的，是先给这些碎片搭一副骨架。有了骨架，后面五十多节的内容就各有挂靠之处，读者也能随时知道自己“走到了哪里”。

## 0.2.1 从一个图标出发的九层阶梯

本书把对无线网络的认识分成九层，每一层回答一个不同的问题。它们由浅入深，前一层是后一层的台阶：

| 层次 | 对应章节 | 回答的核心问题 | 以家里的 Wi-Fi 为例 |
|---|---|---|---|
| 对象 | 第一章 | 它是什么？ | Wi-Fi 是一种无线局域网，替代了一段网线 |
| 结构 | 第二章 | 由什么组成？ | 手机网卡与天线、路由器、光猫、频段与信道 |
| 功能 | 第三章 | 各部分做什么？ | 发现网络、关联连接、收发数据、加密、漫游 |
| 连接 | 第四章 | 各部分怎样衔接？ | 802.11 分层、与以太网和互联网对接、标准与频谱规则 |
| 流动 | 第五章 | 里面流动着什么？ | 电磁波、管理帧、数据帧、一屋子设备的流量 |
| 机制 | 第六章 | 系统怎样运行？ | 先听后说、避让碰撞、按距离调速、多天线并行 |
| 关键技术 | 第七章 | 主流技术有哪些？ | Wi-Fi 6/6E/7、蓝牙、Zigbee 与 Thread、测量排障 |
| 原理 | 第八章 | 为什么能这样工作？ | 香农定理、电磁波传播、随机接入、免许可频谱 |
| AI 协同 | 第九章 | 怎样继续深入？ | 用 AI 读懂路由器后台、画信号地图、分级提问 |

这张表可以当作全书的目录说明来读，但它更重要的用处是一种思考顺序：遇到任何一个无线网络问题，都可以沿着这九个问题依次追问下去。

## 0.2.2 三条主线：设备、信号与规则

九层阶梯是纵向的。横向看，贯穿全书的还有三条主线，它们在每一层都会出现。

**第一条是设备线。** 从手机、电脑里的无线网卡（Wireless Network Interface Card）和天线，到路由器中的接入点（Access Point，AP），再到有线一侧的光猫（光网络终端，Optical Network Terminal，ONT）和交换机，最后延伸到 Mesh 组网和企业里统一管理几百个接入点的无线控制器。这条线回答“东西在哪里”。

**第二条是信号与数据线。** 网页里的文字先变成比特，比特被打包成帧（Frame，无线链路上传输的数据单元），帧再被调制到电磁波上，穿过客厅、卧室的墙壁，在另一端还原回比特。这条线回答“东西怎样跑过去”。

**第三条是规则线。** 无线电波是大家共用的，必须有规矩：IEEE 802.11 工作组制定技术标准，Wi-Fi 联盟（Wi-Fi Alliance）负责互通认证和“Wi-Fi 6”这类代际命名，各国无线电监管机构规定哪些频段可以免许可使用、发射功率不能超过多少。这条线回答“凭什么可以这样做”。

三条线交织的地方，往往就是日常问题的答案所在。比如“为什么隔两堵墙网速就掉了”，同时涉及设备（天线与发射功率）、信号（穿墙衰减与调制方式降档）和规则（功率上限由监管规定）。

## 0.2.3 一个小场景：把骨架“跑”一遍

用开头那几秒钟来试一试这副骨架。

1. **对象层**：手机连接的是家里的无线局域网，它的另一端最终通向互联网。
2. **结构层**：参与者包括手机的无线芯片与天线、路由器的接入点部分、路由器背后的光猫，以及它们所使用的某个频段和信道。
3. **功能层**：手机先“听到”路由器定时广播的信标，认出熟悉的网络名称，再完成认证、关联并获得 IP 地址。
4. **连接层**：这一切发生在 802.11 的物理层和 MAC 层（介质访问控制层），数据随后交给以太网和互联网的协议继续传递。
5. **流动层**：空中先流过的是管理帧和控制帧，然后才是承载消息内容的数据帧。
6. **机制层**：如果家人也在刷视频，手机发送前要先监听信道是否空闲，忙就随机等待一会儿。
7. **关键技术层**：如果路由器和手机都支持 Wi-Fi 6，它们还可以用 OFDMA 把一个信道切成小块同时分给多台设备。
8. **原理层**：信道越宽、信噪比越高，理论速率上限越高，这背后是香农定理；离路由器越远信号越弱，这背后是电磁波传播规律。
9. **AI 协同层**：把路由器后台里看不懂的参数截图交给 AI，请它逐项解释，再自己去验证。

九步走完，一个“自动连上 Wi-Fi”的瞬间，就从一件理所当然的事，变成了一条可以逐段检查的链条。

## 0.2.4 骨架之外：本书的边界

无线连接的世界很大，本书有意划定了边界。Wi-Fi 是主角，蓝牙、低功耗蓝牙、Zigbee 和 Thread 作为近距离无线的“同族”专门成节；手机的 4G、5G 蜂窝网络属于本系列第二十六册《移动通信系统》，互联网的路由与协议属于第二十五册《互联网》，光猫背后的光纤线路、数据中心、云计算与卫星通信也各有专册。本书遇到它们时只点到为止，并指明去处。

另外两条边界同样重要：凡是涉及标准中的速率，书里给出的都是理论峰值，并提醒读者实际体验通常低得多；凡是涉及安全，只讲原理与防范，不讲攻击方法。

## 0.2.5 小结：先有地图，再去旅行

这张认知骨架地图由九层阶梯和三条主线组成，纵横交错，覆盖了从手机上一个图标到电磁波物理规律的全部路程。读者不必一次记住所有格子，只需记住那九个依次追问的问题。下一节将讨论：当书本给出稳定的骨架之后，怎样让 AI 成为沿着骨架继续向下挖掘的工具，而不是替代思考的捷径。
