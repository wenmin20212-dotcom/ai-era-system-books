# 9.2 动手实验：画一张你家的 Wi-Fi 信号地图

很多人都遇到过这种情况：客厅里刷视频很流畅，走进卧室就开始转圈，到了卫生间干脆断线。我们通常只会说“那边信号不好”，可是具体差多少、从哪里开始变差、原因是墙还是距离，说不清楚。这一节我们做一个小实验：拿着手机在家里走一圈，把每个位置的信号强弱记下来，画成一张“信号地图”，再请 AI 帮你分析。这样，前面几章讲到的衰减、穿墙、频段和信道，就能在你自己家的格局里一一对上。

## 9.2.1 准备工作：一张草图、一部手机、一张表

实验需要三样东西。

- **户型草图**：用纸笔或手机画图软件，画出房间、墙体、门窗的大致位置，并标出路由器（以及 Mesh 子节点）所在的位置。不需要精确比例，但墙的位置要画对，因为墙是影响信号的主要因素。
-**测量工具**：手机或笔记本电脑。不少系统的无线设置页面能显示连接详情；各大应用商店里也有许多“Wi-Fi 分析”类应用，能显示接收信号强度。具体有哪些功能，因系统版本和应用而异，这里说的是写作时的一般情况。我们只用它们来读取自己设备收到的信号，属于正常的网络维护用途。
- **记录表**：每个测量点记录下表这几项。

| 记录项 | 含义 | 从哪里看 |
|---|---|---|
| 位置编号 | 草图上标的点，如 A1、B2 | 自己标注 |
| 信号强度（dBm） | 接收信号强度指示（RSSI），多数设备以分贝毫瓦（dBm）显示 | 分析类应用或系统详情页 |
| 频段 | 2.4 GHz / 5 GHz / 6 GHz | 连接详情 |
| 连接速率 | 设备与路由器协商出的物理层速率 | 连接详情 |
| 测速结果 | 实际下载速度，可选 | 测速网站或应用 |
| 主观体验 | 视频是否卡、通话是否断 | 自己感受 |

## 9.2.2 测量方法：定点、多次、分频段

测量时有几个注意点，可以让数据更可信。

第一，**测量点要均匀**。每个房间至少测两三个点：门口、房间中央、平时最常待的位置（比如床头、书桌）。路由器旁边也要测一个点，作为参照。

第二，**每个点停留十几秒，读三次取中间值**。无线信号会随时波动，人走动、手的握法、门开关都会让读数变化几个 dB，只读一次容易误判。

第三，**手机姿势保持一致**。尽量用同样的方式拿手机，站在同样的高度。人体本身也会吸收信号，姿势不同，读数就不同。

第四，**分频段测**。如果路由器同时有 2.4 GHz 和 5 GHz（双频合一时系统会自动选择），可以在后台临时把它们分成两个网络名称，分别测一遍。这样能直接看到第八章讲的规律：频率越高，穿墙衰减越明显。测完记得改回原来的设置。

关于 dBm 的读法：它是负数，越接近 0 越强。下面是公开资料和厂商指南中常见的经验范围，仅供参考，不是标准规定：

| 信号强度 | 大致体验 |
|---|---|
| 高于 -50 dBm | 很强，通常就在路由器附近 |
| -50 ～ -67 dBm | 良好，视频、通话一般都流畅 |
| -67 ～ -75 dBm | 一般，网页可用，视频可能偶尔卡顿 |
| 低于 -75 dBm | 较弱，容易掉速或断线 |

## 9.2.3 把数字画成地图

数据收齐后，在草图上的每个点旁写下读数，再用颜色区分：绿色表示良好，黄色表示一般，红色表示较弱。把相近颜色的区域连成片，一张简易的“信号热力图”就出来了。专业的无线勘测软件能自动生成连续的热力图，原理相同，只是测得更密、计算更细。

看图时可以对照前面学过的知识，问自己几个问题：

- **红色区域和路由器之间隔了几堵墙？** 承重墙、钢筋混凝土墙、卫生间的瓷砖墙和镜子，通常比轻质隔墙衰减更大。
- **5 GHz 的“绿区”是不是比 2.4 GHz 小？** 如果是，这正是频率与穿透能力关系的直接证据。
- **信号强度够，速率却很低的点在哪里？** 这往往说明问题不只是距离，可能是同信道干扰多，或者多径反射严重，可以回头用信道分析功能查看周围有多少邻居网络。

## 9.2.4 请 AI 当你的分析助手

把记录表整理成文字或表格发给 AI，再附上户型的文字描述，比如“路由器在客厅电视柜里，主卧隔着一堵承重墙，书房在走廊尽头”。然后可以这样提问：

- “根据这些测量数据，我家信号最弱的区域是哪里？最可能的原因是什么？”
- “如果只能调整路由器位置，应该往哪个方向挪？”
- “我是该加一个 Mesh 节点，还是换个信道就够了？请说明判断依据。”

AI 的建议要回到实物上验证：挪动路由器或加装节点之后，按同样的点位、同样的方法再测一遍，对比前后两张地图。如果红区变黄、黄区变绿，说明调整有效；如果没有变化，就把新数据再交给 AI，让它换个思路分析。注意，发给 AI 的数据里不需要也不应该包含 Wi-Fi 密码、后台管理密码等敏感信息。

这张地图的意义，不只是找到一个更好的路由器摆放位置。它把“信号不好”这种模糊的感受，变成了可测量、可比较、可解释的数据，而“测量—分析—调整—再测量”这个循环，正是网络工程师日常工作的基本方法。下一节，我们会把这种用 AI 追问的方法整理成一套由浅入深的提问阶梯。
