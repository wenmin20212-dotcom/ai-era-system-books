# 2.3 有线的一侧：光猫、交换机与网线

很多人家里的网络角落都是这样的：弱电箱里塞着一台带指示灯的小盒子，一根细细的黄色或白色线缆从墙里钻出来插在上面；旁边一根网线连到客厅的无线路由器；有时还有一台巴掌大的、带一排网口的小设备，接着电视机顶盒和台式电脑。手机上的 Wi-Fi 图标满格时，我们很少想到这些盒子。但无线网络只负责“最后几米到几十米”，数据真正进出家门，靠的是有线的一侧。这一节就顺着那根从墙里伸出来的线，看看光猫、交换机和网线各自做什么。

## 2.3.1 从墙里伸出来的那根线：光猫

在今天的许多城市家庭里，宽带是通过光纤入户的。光纤里传的是光信号，而电脑、路由器认识的是电信号，中间需要一个“翻译”。这个翻译就是俗称的“光猫”，正式名称是光网络终端（Optical Network Terminal，ONT）或光网络单元（Optical Network Unit，ONU）。“猫”这个叫法来自早年的调制解调器（Modem），当年拨号上网和 ADSL 宽带用的“猫”负责在电话线上做信号转换，名字就沿用了下来。

光猫的核心工作可以概括为三件事：

- **光电转换**：把光纤送来的光信号变成电信号，反方向再把电信号变成光信号送出去。
- **接入认证**：向运营商的网络证明“我是这户人家的合法终端”，通过后才放行数据。
- **提供网口**：背面通常有若干个以太网口，有的还带电话口和机顶盒口，并可能内置 Wi-Fi。

在家庭宽带中，常见的光纤接入方式是无源光网络（Passive Optical Network，PON）：运营商机房的一根光纤经过无源分光器分给多户人家，各家的光猫轮流与机房设备通信。光纤本身怎样传光、PON 如何组织，属于本系列《光纤通信》一册的内容，这里只需要记住：光猫是你家网络与运营商网络的分界点，它之外归运营商管，它之内基本由你自己掌握。

## 2.3.2 光猫和路由器：谁来当“家门口的管家”

不少读者会发现，自家光猫本身就能发 Wi-Fi，那还要无线路由器做什么？这牵涉到一个常见的配置选择：由谁负责拨号和分配地址。

| 工作模式 | 谁负责拨号上网与分配地址 | 常见特点 |
|---|---|---|
| 光猫路由模式 | 光猫 | 安装简单；路由器多作为扩展无线信号使用 |
| 光猫桥接模式 | 后面的无线路由器 | 路由器统一管理家中设备，功能设置更灵活 |

这两种模式没有绝对优劣，关键是家里只保留一个“管家”统一负责地址分配，避免两台设备各管一摊、造成地址重叠或网络层层嵌套。具体怎样切换，通常需要按运营商的说明或联系客服处理，不同地区、不同运营商的默认设置各不相同。上一节讲到的“无线路由器是一台盒子里的几种设备”，在这里就体现为：当光猫已经承担了路由功能时，后面的路由器可以只当接入点用。

## 2.3.3 交换机：让一个网口变成很多个

无线路由器背后一般只有寥寥几个网口。家里如果有台式电脑、网络电视、游戏主机、网络存储设备都想插网线，口就不够了。这时用到的是交换机（Switch）。

交换机像一个聪明的分拣中心。每台联网设备的网卡都有一个出厂时写入的硬件地址，叫 MAC 地址（Media Access Control Address，媒体访问控制地址）。交换机会记住“哪个地址的设备插在哪个口上”，收到数据时只把它送往目标设备所在的端口，而不是向所有端口广播。这样，客厅电视在看高清视频的同时，书房电脑拷贝大文件，两路流量可以各走各的，互不挤占。

需要注意区分两类设备：

- **交换机**：在同一个局域网内部转发数据，按 MAC 地址分拣，不管“上外网”这件事。
- **路由器**：在不同网络之间转发数据，按 IP 地址选路，负责把家里的局域网接到互联网上。

家用交换机常见的是即插即用的“傻瓜交换机”，不需要设置；企业里则会用可管理交换机，能划分虚拟局域网（VLAN）、为接入点供电等。后面讲企业无线时还会遇到它们。

## 2.3.4 网线：被低估的那一段

人们升级了 Wi-Fi 路由器，却常常忽略连接它的网线。家庭和办公室常用的是双绞线，即铜导线两两绞合、减少相互干扰的线缆，插头是 RJ45 水晶头。网线按性能分成不同类别，印在线皮上：

| 类别（常见标注） | 常见用途范围 |
|---|---|
| 五类（Cat5） | 较老布线，多见于百兆网络 |
| 超五类（Cat5e） | 家庭最常见，一般可支持千兆以太网 |
| 六类（Cat6）及以上 | 适合千兆及更高速率，抗干扰更好 |

这里的速率是相关以太网标准在规定距离内（通常为 100 米以内）的设计能力，实际表现还取决于施工质量和两端设备的端口速率。一个常见的现象是：家里办了千兆宽带，测速却只有百兆上下，原因除了 Wi-Fi 本身，也可能出在某段老网线、某个百兆端口或接触不良的水晶头上。整条链路的速度，由最慢的那一段决定。

网线还有一项无线做不到的本事：通过以太网供电（Power over Ethernet，PoE），一根线同时送数据和电力。企业里吸顶安装的无线接入点，很多就是靠交换机经网线供电，省去了在天花板上单独接电源。

## 2.3.5 小结：无线是延伸，有线是骨干

把这一节串起来，一条家庭网络的典型路径是：运营商光纤 → 光猫 → 路由器 → 交换机或网线 → 各个设备，其中路由器再用无线信号把手机、平板接进来。无线网络并不是取代了有线，而是在有线骨干的末端，把“网口”延伸到空中。理解了这一点，排查网速问题时就会先问一句：慢在空中，还是慢在线上？
