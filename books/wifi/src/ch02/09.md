# 2.1 终端里的无线网卡与天线

拿起你的手机，翻到背面，你看不到任何“网卡”，也找不到一根天线。可它每天都在和路由器交换大量数据。笔记本电脑也一样：老式机型或许还有一块能插拔的小卡片，如今的轻薄本多半把它焊在主板上，连同几根细细的同轴线一起藏进了屏幕边框。拆解系统的第一站，就从这些“看不见的部件”开始：终端设备（手机、电脑、平板、智能电视等，统称 STA，Station，即“站点”）靠什么把比特变成无线信号。

## 2.1.1 无线网卡：不止一块“卡”

“无线网卡”（WNIC，Wireless Network Interface Controller，无线网络接口控制器）这个名字来自早年的电脑配件，当时它确实是一块插在电脑上的卡或一个 U 盘大小的外接设备。今天它的形态主要有三种：

| 形态 | 常见于 | 特点 |
|---|---|---|
| 外接 USB 网卡 | 台式机、老电脑升级 | 即插即用，体积和天线受限 |
| M.2 等插槽式模块 | 笔记本、台式机主板 | 可更换，天线另接 |
| 集成在芯片或模组里 | 手机、平板、智能家居 | 与其他无线功能共用一颗芯片 |

在手机里，Wi-Fi 往往和蓝牙做在同一颗无线连接芯片或同一个模组中，有的方案甚至集成进手机的主处理器芯片（SoC，System on Chip，片上系统）。所以“网卡”更准确地说是一组功能，而不是某个特定形状的零件。

## 2.1.2 拆开看：基带、射频与驱动

不管形态如何，一块无线网卡内部大致分为三层分工，可以用“写信—寄信”来类比：

1. **主机侧的驱动与系统软件**：操作系统通过驱动程序（driver）告诉网卡要发什么、连哪个网络。你在设置里点选一个 Wi-Fi 名称，指令就是经由驱动下达的。驱动版本会影响稳定性，这也是排障时常建议“更新驱动”的原因。
2. **基带与 MAC 处理部分**：基带（baseband）负责把要发送的数据编码、调制成数字形式的信号，并把收到的信号还原成数据；MAC（Media Access Control，介质访问控制）部分负责“什么时候能说话、说完要不要等确认”。这相当于把信的内容按规定格式写好、贴好邮票，并决定何时投递。这些规则来自 IEEE 802.11 标准，后面第四章和第六章会细讲。
3. **射频前端**：射频（RF，Radio Frequency）电路把基带信号搬到 2.4 GHz、5 GHz 或 6 GHz 的载波频率上，经功率放大器放大后送到天线；接收时则由低噪声放大器把天线收到的微弱信号放大，再交给基带。这一层相当于真正把信送出门的邮差。

一句话概括：**驱动管“要做什么”，基带与 MAC 管“按什么规则做”，射频管“怎样变成电磁波”。**

## 2.1.3 天线：把电流变成电磁波的“喇叭”

天线是一段专门设计的导体，作用是在电路中的高频电流与空间中的电磁波之间互相转换。它不产生功率，只决定能量“往哪儿去、从哪儿收”。

- **天线尺寸与频率有关**。常见的天线长度与波长相当或为其几分之一。2.4 GHz 电磁波的波长约 12.5 厘米，5 GHz 约 6 厘米，6 GHz 约 5 厘米，所以手机里的 Wi-Fi 天线可以做得很小，常以金属片、电路板走线或利用金属边框的一部分来实现。
- **方向性与增益**。理想的天线向四面八方均匀辐射，实际天线都有偏好方向。所谓“增益”（gain，单位常用 dBi）不是放大了能量，而是把能量更集中地送往某些方向，代价是其他方向变弱，像把手电筒的光聚拢成一束。
- **天线数量与 MIMO**。许多笔记本和中高端手机带有两根 Wi-Fi 天线，可以同时收发两路数据，这就是 MIMO（Multiple-Input Multiple-Output，多输入多输出）的基础。参数表里的“2×2”即指两发两收，第六章 6.4 节会解释它为什么能提高速率。

手握手机时信号变差、笔记本合上一半时速度下降，很多时候与天线被手掌、金属或角度遮挡有关。这也提醒我们：终端的天线通常比路由器的更小、增益更低、发射功率也受电池和法规所限，**在一条无线链路中，手机往往是较弱的一端**。

## 2.1.4 读懂终端的“无线能力”

一台设备能连多快、能用哪些频段，主要取决于它的网卡芯片与天线，而不是路由器单方面决定。查看规格时可关注几项：

- **支持的标准代际**：如 Wi-Fi 5（802.11ac）、Wi-Fi 6（802.11ax）、Wi-Fi 7（802.11be）。路由器再新，终端不支持也用不上新特性。
- **支持的频段**：是否支持 5 GHz、6 GHz。6 GHz 能否使用，还取决于所在国家或地区是否开放（详见 2.5 节与 4.4 节）。
- **空间流数**：如 1×1、2×2，影响理论峰值。
- **理论最大速率**：规格表上的数字是标准条件下的理论值，实际吞吐量通常明显更低，受距离、干扰和同时在线的设备影响。

不同操作系统查看方式不同：电脑一般可在系统信息或网络适配器属性中看到网卡型号；手机往往只在“关于手机”或连接详情里给出部分信息，如当前连接速率和频段。这些界面随系统版本变化，以写作时为准。

## 2.1.5 小结与过渡

终端这一侧的无线系统可以浓缩为一条链：**应用数据 → 驱动 → 基带/MAC → 射频 → 天线 → 电磁波**，接收时反向走一遍。它决定了你的设备“会说哪种语言、嗓门多大、耳朵多灵”。但一场对话需要两方，信号飞出天线之后，迎接它的是家里那台路由器。下一节，我们就打开路由器这只盒子，看看里面究竟装了几种设备。
