# 3.1 发现：信标帧与网络名称（SSID）

打开手机的无线局域网设置页，屏幕上会列出一串名字：自家的“ChinaNet-XXXX”、隔壁的“TP-LINK_5G”、楼下咖啡店的“Guest”，有时还有一个叫“DIRECT-xx-打印机”的陌生条目。你没有做任何操作，这些名字却自己“冒”了出来，而且走到不同房间，列表的顺序和信号格数还会变化。这份列表就是 Wi-Fi 连接的第一步，叫作“发现”（Discovery），也叫“扫描”（Scanning）。本节回答三个问题：列表里的名字从哪里来，手机用什么办法找到它们，网络名称本身意味着什么。

## 3.1.1 名字从哪里来：网络在不停地“报名”

列表里的每个名字，都来自接入点（Access Point，AP）周期性广播的一种短消息，叫信标帧（Beacon Frame）。它好比车站的广播：不管站台上有没有人，每隔一段时间就播一遍“这里是某某站，开往哪些方向”。

在 IEEE 802.11 标准中，信标帧属于管理帧。发送间隔以“时间单位”（Time Unit，TU）计量，1 TU 等于 1024 微秒。家用和企业设备普遍采用 100 TU 的默认间隔，约 0.1 秒发一次，所以一个接入点每秒大约广播十次自己的存在。管理员可以调整这个间隔，但多数人用不到。

一条信标帧里装着手机决定“要不要连、怎么连”所需的基本信息，常见内容如下：

| 字段 | 中文含义 | 对用户的意义 |
|---|---|---|
| SSID | 服务集标识，即网络名称 | 列表里显示的名字 |
| BSSID | 基本服务集标识，通常就是该接入点无线接口的 MAC 地址 | 区分同名网络背后的不同设备 |
| 信标间隔与时间戳 | 广播周期和接入点的时钟 | 帮助终端对时、安排省电休眠 |
| 能力信息 | 是否加密、支持哪些速率 | 决定列表里是否显示“锁”图标 |
| 安全参数（RSN 信息） | 支持的加密与认证方式，如 WPA2、WPA3 | 决定手机用哪种方式认证 |
| 信道与频段信息 | 工作在哪个信道 | 手机据此调到对应频率 |
| 扩展能力 | 是否支持 Wi-Fi 6、7 等新特性 | 决定双方能用哪些新功能 |

这里有两个名词值得分清。服务集标识（Service Set Identifier，SSID）是给人看的名字，最长 32 字节，可以重复，两家人都叫“Home”完全合法。基本服务集标识（Basic Service Set Identifier，BSSID）是给机器看的编号，每个接入点的每个无线接口各不相同。一台双频路由器如果 2.4 GHz 和 5 GHz 用同一个名字，你在列表里只看到一个“Home”，背后其实有两个 BSSID。

## 3.1.2 两种找法：被动聆听与主动询问

手机获取这份列表有两条途径。

**被动扫描**（Passive Scanning）：手机依次切换到各个信道，在每个信道上停留一小段时间，收听有没有信标帧。这就像收音机逐个频道调台，好处是自己不用发声，代价是慢，信道越多，扫一遍用的时间越长。

**主动扫描**（Active Scanning）：手机在某个信道上主动发出探测请求帧（Probe Request），意思是“这里有网络吗”，或者“某某网络在吗”。收到请求的接入点回一个探测响应帧（Probe Response），内容与信标帧大体相同。这好比走进大厅喊一声“有人吗”，比站着等广播快得多。

实际设备通常两种方式结合使用，具体策略由手机操作系统和网卡驱动决定，各家做法不同。还有一点限制：部分频段的部分信道，监管规则要求设备先确认没有雷达等其他用户，或者先听到接入点的信标，才能主动发送。这类规则因国家和地区而异，第四章 4.4 节会专门讨论。

每扫到一个网络，手机同时会测出它的接收信号强度，换算成你看到的信号格数。你在家里走动时列表顺序变化，就是因为各个接入点的信号强度在变。

## 3.1.3 网络名称不只是名字：隐藏、重名与仿冒

路由器设置里常有一个选项叫“隐藏 SSID”。打开后，信标帧里的名称字段留空，列表里就看不到这个网络了。不少人以为这样更安全，实际上作用很有限：网络照样在广播信标，只是没有署名；已经保存过这个网络的手机，为了找到它，往往要主动发出带有名称的探测请求，名字依然会出现在空中。隐藏 SSID 还可能让一些设备连接变慢或不稳定。真正决定安全性的是加密方式和密码强度，例如启用 WPA3、设置足够长且不易猜测的密码，这些在 3.4 节详细展开。

重名问题更常见。手机判断“是不是我保存过的网络”，主要依据名称和安全类型。这带来一个风险：有人可以架设一个与咖啡店同名的开放热点，诱导手机自动连接，这类仿冒热点常被称为“邪恶双胞胎”。防范的思路很简单：

- 不随意连接无密码的公共网络，对“似曾相识”的开放网络保持警惕；
- 在公共场所关闭对开放网络的自动加入；
- 在可选的情况下优先使用 WPA3 加密的网络，并保持手机和路由器固件更新。

还有一个与发现过程相关的隐私设计。早期手机在扫描时总是用自己固定的 MAC 地址发出探测请求，旁人收集这些请求，就可能追踪一部手机的行踪。截至本书写作时，主流手机操作系统大多已默认在扫描和连接时使用随机 MAC 地址（各系统称呼不同，如“私有地址”“随机 MAC”），以降低被追踪的可能。这是终端厂商的实现方式，并不是每台设备都相同。

## 3.1.4 小结与过渡

“发现”这一步可以用一句话概括：接入点用信标帧不断报名，手机用被动聆听和主动询问两种方式收集名单，再按名称、安全类型和信号强度决定显示什么、优先连谁。读者在 Wi-Fi 列表里看到的每个名字、每把小锁、每格信号，都能在信标帧或探测响应的字段里找到来源。

不过，看到名字只是起点。点下“Home”之后，手机与路由器还要经过认证、关联，再拿到一个 IP 地址，才算真正连上。这正是下一节要讲的内容。
