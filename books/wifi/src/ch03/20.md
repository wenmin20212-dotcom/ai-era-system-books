# 3.6 本章骨架小结与实物探索任务

从手机屏幕上弹出一串 Wi-Fi 名称，到你点一下、输入密码、图标变成满格，再到你拿着手机从客厅走进卧室而视频没有中断，这一连串习以为常的体验，背后是 Wi-Fi 网络的五项基本功能在接力。本章把它们拆开逐一看过，下面先把骨架收拢，再请你回到自家的路由器和手机上去验证。

## 3.6.1 本章骨架回顾：五项功能的接力

- **发现**：接入点（AP）周期性广播信标帧（Beacon），其中带有网络名称（SSID，服务集标识符）、支持的速率、安全方式等信息；终端也可以主动发出探测请求（Probe Request）去询问附近有哪些网络。手机上的 Wi-Fi 列表，就是收集到的信标和探测响应的汇总。
- **关联**：选定网络后，终端与 AP 先完成认证，再发送关联请求、获得关联响应，建立起“我属于这个网络”的关系；如果启用了 WPA2/WPA3，还要通过四次握手协商出本次会话的加密密钥；最后通过 DHCP（动态主机配置协议）拿到 IP 地址，才算真正“能上网”。
- **收发**：无线链路不可靠，所以 802.11 采用“发送—确认—重传”的思路：接收方收到单播数据帧后回一个确认帧（ACK），发送方迟迟收不到确认就重传，并可能降低速率再试。
- **安全**：从早期的 WEP（有线等效保密）到 WPA、WPA2，再到 WPA3，安全机制不断修补设计缺陷。WPA3 引入的 SAE（对等实体同时认证）让离线猜测密码变得困难得多；但无论哪一代，弱密码、陈旧固件依然是最常见的薄弱环节。
- **管理**：多 AP 环境下，终端在信号变弱时寻找更合适的 AP 完成漫游；802.11k/v/r 等标准修订分别帮助终端了解邻居 AP、接受网络的引导建议、加快重新认证。负载均衡和访客网络则属于“让网络更好用、更安全”的管理手段，其中不少具体策略是厂商各自的实现，并非标准统一规定。

把这五项连成一条线，可以记作一张简表：

| 功能 | 核心问题 | 关键“道具” |
|---|---|---|
| 发现 | 附近有哪些网络？ | 信标帧、探测请求/响应、SSID |
| 关联 | 我能加入吗？ | 认证、关联、四次握手、DHCP |
| 收发 | 数据送到了吗？ | 数据帧、ACK、重传、速率调整 |
| 安全 | 别人能偷听或冒充吗？ | WPA2/WPA3、SAE、强密码 |
| 管理 | 走动时、人多时怎么办？ | 漫游、802.11k/v/r、访客网络 |

下一章将转向“各部分怎样连接”：这些功能分别落在协议的哪一层，又是怎样与以太网、互联网衔接起来的。

## 3.6.2 实物探索任务

1. **数一数信标**：打开手机或电脑的 Wi-Fi 列表，记录你能看到的网络名称数量，并注意是否有名字相近、只差“-5G”之类后缀的两个网络（常见于把 2.4 GHz 和 5 GHz 分开命名的双频路由器）。白天和深夜各记一次，看看列表有无变化。
2. **观察“连上”的几个阶段**：在手机上“忘记”家里的网络后重新连接，留意界面上依次出现的提示，如“正在连接”“正在获取 IP 地址”“已连接”。对照本章内容，说出每个提示大致对应哪一步。
3. **检查安全设置**：登录家里路由器的管理后台（地址通常印在路由器底部标签上），查看无线安全方式是否为 WPA2 或 WPA3，确认密码足够长、不使用生日或连续数字，并检查固件是否为最新版本。注意只在自己有管理权限的设备上操作。
4. **走一圈测漫游**：如果家里有 Mesh 系统或多个 AP，打开一段视频通话或音乐流，从房间一端慢慢走到另一端，留意是否有卡顿，以及手机显示的信号格数何时跳变。
5. **试建访客网络**：查看路由器是否支持访客网络功能，记录它与主网络在设置上的区别（例如是否能访问家里的打印机或其他设备）。

## 3.6.3 可以直接拿去问 AI 的问题

- “我的手机 Wi-Fi 列表里，同一个网络名称出现了两次，后面分别带着 2.4G 和 5G。请用通俗的话解释这是为什么，我该连哪一个？”
- “请对比 WPA2 和 WPA3 在保护家庭 Wi-Fi 密码方面的主要区别，并告诉我作为普通用户应该检查和调整哪些设置。”
- “我家用的是 Mesh 路由器，走到卧室时视频偶尔会卡一下。请帮我分析可能的原因，并说明 802.11k/v/r 在漫游中各起什么作用。”

把书上的骨架和手边的设备对上号，再让 AI 帮你补充细节，这五项功能就不再是抽象的名词，而是你每天都在使用、并且能够亲手检查和改善的真实过程。
