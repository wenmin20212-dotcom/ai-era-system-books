# 7.5 网络测量与故障排查：信号强度、测速与信道分析

晚上九点，卧室里的视频又卡住了。手机上的 Wi-Fi 图标明明是满格，测速软件跑出来的数字却忽高忽低。很多人这时的第一反应是重启路由器，或者干脆换一台更贵的。重启偶尔管用，但它解决不了“为什么会卡”这个问题。排查无线网络和医生看病是一个路数：先量体温、测血压，拿到客观数据，再判断病在哪里。本节介绍家用场景下最常用的三类“体检指标”：信号强度、速率与时延、信道占用，并给出一套从易到难的排查顺序。

## 7.5.1 信号强度：满格不等于信号好

手机上的 Wi-Fi 图标只有三四格，是把一个连续的测量值粗略分档后的结果。真正的测量值叫**接收信号强度指示**（Received Signal Strength Indicator，RSSI），通常以 dBm（相对于 1 毫瓦的分贝值）表示，数值是负数，越接近 0 越强。不少系统的诊断界面或路由器后台都能看到它。

公开资料和厂商部署指南中常见的经验范围大致如下（不同设备的测量方式有差异，只作参考）：

| 信号强度（dBm） | 大致体验 |
|---|---|
| -30 ~ -50 | 很强，通常就在路由器附近 |
| -50 ~ -67 | 良好，视频通话、高清视频一般流畅 |
| -67 ~ -75 | 可用，网页和普通视频尚可，速率明显下降 |
| -75 ~ -85 | 较差，容易卡顿、掉线 |
| 低于 -85 | 基本难以维持稳定连接 |

dBm 是对数单位，每差 3 dB，功率大约差一倍；每差 10 dB，功率差十倍。从 -50 降到 -70，看起来只差 20，实际功率差了约一百倍。

只看信号强度还不够，还要看**信噪比**（Signal-to-Noise Ratio，SNR），也就是有用信号比背景噪声高出多少。同样是 -65 dBm，在安静的环境里可能跑得很顺，在噪声大的环境里却只能用低速率。第六章讲过，设备会根据链路质量自动选择调制编码方案（MCS），SNR 越高，能用的调制阶数越高。第八章还会说明，香农定理给出的速率上限也取决于信噪比。所以“满格却很慢”并不矛盾：格数反映的是信号够不够强，速率还要看噪声和干扰的大小。

## 7.5.2 测速：把“无线段”和“宽带段”分开

测速软件给出的数字，是你的手机到某台远端测速服务器之间整条路径的表现。这条路径至少包括三段：手机到路由器的无线链路、路由器到运营商的宽带接入，以及互联网骨干上的传输。后两段的知识分别见本系列的《互联网》与光纤通信相关分册。排查时要做的，就是判断瓶颈在哪一段。

一个简单的对照实验：

1. **有线基准**：用网线把电脑接到路由器上测一次，得到宽带段的大致能力。
2. **近距离无线**：手机放在路由器旁边测一次。
3. **问题位置无线**：在卧室等卡顿的地方再测一次。

如果三次结果都低，问题多半在宽带或运营商一侧。如果有线正常、近处无线也正常、只有卧室慢，问题就在无线覆盖。如果有线正常、近处无线也慢，就要怀疑终端网卡、路由器设置或信道干扰。

另外，测速通常会报告三个指标：

- **下载/上传速率**：吞吐量，决定大文件和高清视频能否跑满。
- **时延**（延迟，Latency）：数据往返一次所需的时间，影响游戏和视频通话。
- **抖动**（Jitter）：时延的波动程度，波动大时语音会断断续续。

视频会议卡顿，往往不是速率不够，而是时延和抖动太大。无线链路上的重传和信道竞争（见第六章的 CSMA/CA）正是抖动的常见来源。还要注意，标准里的“理论峰值速率”是在理想条件、最宽信道、最多空间流下算出来的数值，实测数据远低于它是正常现象，不能用来判断设备坏没坏。

## 7.5.3 信道分析：看看邻居在用什么

在住宅楼里打开手机的 Wi-Fi 列表，常常能看到十几个甚至几十个网络名。它们共享同一片频谱。**信道分析**就是把周围各个网络分别用哪个信道、信号多强列出来，判断你的信道是否拥挤。

许多路由器后台带有“信道扫描”或“无线环境检测”功能，一些手机和电脑上也有可以显示信道分布的分析软件（具体功能以写作时各产品为准）。看结果时抓住几点：

- **2.4 GHz**：常用的互不重叠信道通常是 1、6、11。若周围大量网络挤在同一信道，或者有人用了 40 MHz 宽信道，拥塞会很明显。
- **5 GHz**：信道多，拥挤程度一般低于 2.4 GHz。其中部分信道需要遵守**动态频率选择**（Dynamic Frequency Selection，DFS）规则，检测到雷达信号时设备必须让出信道，可能出现短暂断连。
- **6 GHz**：在已开放该频段的国家和地区，信道最宽松。开放情况各国不同（参见第四章 4.4 节），具体以当地监管机构的最新规定为准。

还有一个指标值得关注：**信道利用率**（Channel Utilization），即该信道有多大比例的时间处于忙碌状态。部分路由器和企业级接入点会显示这个值。信号再强，信道总是忙，你的设备也只能排队等待。

## 7.5.4 一套从易到难的排查顺序

把上面的工具串起来，家庭和小型办公室可以按下面的顺序排查：

1. **确认范围**：是一台设备慢，还是所有设备都慢？是某个房间慢，还是哪里都慢？
2. **分段测速**：用有线和无线对照，判断瓶颈在宽带还是无线。
3. **查看信号**：在问题位置看 RSSI。低于 -70 dBm 左右时，优先调整路由器位置（放高、放中央、避开金属柜和鱼缸），或增加 Mesh 节点、有线回程的接入点。
4. **分析信道**：信号尚可但仍慢，就检查信道拥挤程度，尝试手动更换信道，或让设备改用 5/6 GHz。
5. **检查终端与固件**：老旧网卡可能不支持新频段和新标准；路由器和终端都应更新到最新固件，这样既能修复缺陷，也能堵上安全漏洞。
6. **记录与对比**：改动前后在同一位置、同一时段各测几次，用数据判断改动是否有效，不要凭一次测量下结论。

## 7.5.5 小结

排障的核心是**分段与对照**：用信号强度和信噪比看覆盖，用有线与无线对照测速来区分是宽带的问题还是无线的问题，用信道分析看周围的竞争，用改动前后的对比来验证效果。这些指标背后，正是前几章讲过的传播、调制编码和共享接入机制。下一节，我们把第七章的关键技术重新串成一张骨架图，并把这些测量方法变成可以动手完成的实物任务。
