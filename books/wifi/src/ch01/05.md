# 1.2 无线局域网是什么：一根“看不见的网线”

晚上在客厅沙发上用平板看视频，书房的台式机插着网线在下载文件，卧室里的手机在同步相册。三台设备都在“上网”，可只有台式机身后真的拖着一根线。平板和手机的数据走的是哪条路？上一节我们跟着手机走完了连上 Wi-Fi 的那几秒钟，这一节退后一步，先回答一个更基础的问题：我们口中的“Wi-Fi”，在网络世界里到底算什么。

## 1.2.1 先从“局域网”三个字说起

把家里所有能联网的设备想成一个小社区。社区内部的道路网，就是局域网（Local Area Network，LAN）：覆盖范围有限，通常是一套住宅、一间办公室或一层楼；由使用者自己搭建和管理；设备之间可以直接互相找到、互传数据。打印机、电视投屏、家里的 NAS 文件共享，用的都是这张内部路网，不必绕到外面的互联网去。

传统的局域网靠网线把设备接在一起，最常见的技术叫以太网（Ethernet）。每台电脑一根线，插到交换机或路由器的网口上。线是实实在在的“专用车道”：数据只在铜线里跑，别人家的信号进不来，也几乎不会互相干扰。

无线局域网（Wireless LAN，WLAN）做的事情，就是把其中一部分“车道”从铜线换成空中的无线电波。设备不再需要插线，只要在路由器信号覆盖范围内，就能加入同一个局域网。所以，手机上的 Wi-Fi 图标亮起来，首先意味着的不是“连上了互联网”，而是“加入了家里的局域网”。能不能继续通到互联网，还要看路由器背后那条宽带线路。很多人遇到过“Wi-Fi 满格却打不开网页”，原因正在这里：无线这一段没问题，问题出在更远的地方。

## 1.2.2 Wi-Fi、WLAN 与 802.11：三个名字是什么关系

日常说话时这三个词常被混用，其实各有所指：

| 名称 | 是什么 | 打个比方 |
|---|---|---|
| WLAN（无线局域网） | 一类网络的统称：用无线方式组成的局域网 | “公路”这个概念 |
| IEEE 802.11 | 电气电子工程师学会（IEEE）制定的无线局域网技术标准系列 | 公路的设计规范 |
| Wi-Fi | Wi-Fi 联盟（Wi-Fi Alliance）的认证商标，表示产品按 802.11 实现并通过互通测试 | 验收合格的标牌 |

从原理上说，WLAN 也可以用别的技术来实现，历史上确实出现过其他方案；但今天全世界家庭和办公室里的无线局域网，几乎都基于 802.11，于是“Wi-Fi”成了它的代名词。本书沿用这个习惯，但在需要精确时会区分“标准”与“认证”，第四章还会专门讲这两个组织的分工。

## 1.2.3 为什么说它是一根“看不见的网线”

这个比喻抓住了 Wi-Fi 最核心的定位：在网络的层层结构里，它主要替换的是“线”这一段，而上面跑的东西几乎不变。

手机通过 Wi-Fi 发出的数据，到了路由器那里，会被转换成和以太网相同格式的数据，再交给有线网络继续传。对网页、视频、聊天软件来说，底下是网线还是无线电波，它们基本感觉不到。正因为“接口”保持一致，Wi-Fi 才能无缝嵌入已有的网络世界——这一点在 4.2 节会展开。

不过，比喻总有边界。这根“线”看不见，也就带来了几处和真网线的本质差别：

- **它是共享的。** 一根网线连接一台设备，空中的一个信道却由附近所有设备共用，包括邻居家的路由器。大家要轮流说话，人越多，每人分到的时间越少。
- **它是会变的。** 网线的质量基本恒定，无线信号却会随距离、墙壁、人体遮挡而起伏，速率也跟着变化。你从客厅走进卫生间，视频卡一下，就是这根“线”变细了。
- **它是敞开的。** 电波向四面八方传播，楼道里的人也能接收到。所以无线网络必须靠加密保护内容，而网线天然就有物理隔离。
- **它通常是半双工的。** 同一时刻、同一信道上，一台设备一般要么在发、要么在收，不像常见的有线以太网那样能同时双向传输。

这四点——共享、多变、开放、轮流——几乎贯穿了全书后面的所有内容：CSMA/CA 解决“轮流”，调制编码应对“多变”，WPA3 守护“开放”，OFDMA 改进“共享”。

## 1.2.4 它在网络全景中的位置

把视野拉远，从你的手机到某个网站的服务器，数据要经过一条很长的链路：手机——Wi-Fi——家里的路由器——光猫——运营商的接入网和骨干网——数据中心。Wi-Fi 只占其中最靠近你的那一小段，通常是几米到几十米。

| 网段 | 典型距离 | 本丛书对应 |
|---|---|---|
| 设备到路由器（Wi-Fi） | 几米到几十米 | 本书 |
| 家到运营商（光纤宽带） | 数百米到数公里 | 光纤通信专册 |
| 运营商之间与骨干 | 跨城市乃至跨国 | 互联网（第二十五册） |
| 手机直连基站（4G/5G） | 数百米到数公里 | 移动通信系统（第二十六册） |

这一段虽短，却是用户体验最直接的一环。公开资料和运营商的常见说法是：家庭网络“慢”的投诉里，相当一部分问题出在屋内的无线覆盖和干扰，而不是外面的宽带。学会看懂这根“看不见的网线”，往往就能解决身边大半的网络烦恼。

## 1.2.5 小结

无线局域网是用无线电波代替部分网线组成的局域网；802.11 是它的技术标准，Wi-Fi 是通过认证的标牌。它对上层“装作一根网线”，对下层却有着共享、多变、开放、轮流的独特脾气。下一节我们把目光放宽，看看 Wi-Fi 在无线家族里还有哪些兄弟——蓝牙、Zigbee、NFC 和蜂窝网络——它们各自又守着哪一段距离、哪一类任务。
