# 1.5 本章骨架小结与实物探索任务

到这里，第一章的任务完成了：我们把手机上的 Wi-Fi 图标和家里的无线路由器当作“实物锚点”，回答了“Wi-Fi 是什么、属于哪个家族、从哪里一路演进而来”。下面先把本章内容收拢成一副骨架，再请你放下书，拿起手边的设备，亲自验证这些知识。

## 1.5.1 本章骨架回顾

本章对应九层认知阶梯的第一层“认识对象”，可以用四根“骨头”概括：

- **一次连接的全貌（1.1）**：点开 Wi-Fi 列表到图标亮起，背后依次是**发现**（路由器周期性广播信标帧，手机据此列出网络名称 SSID）、**认证与关联**（核对密码、登记身份）、**获取地址**（通过 DHCP，即动态主机配置协议，拿到 IP 地址），之后才开始真正的数据收发。这几步就是后面第三章“功能解析”的提纲。
- **本质定位（1.2）**：无线局域网（WLAN，Wireless Local Area Network）可以理解为一根“看不见的网线”。它替代的是从设备到路由器这最后几米到几十米的线缆，而不是整条通往互联网的线路。路由器背后仍然连着光猫、光纤和运营商网络。
- **家族坐标（1.3）**：Wi-Fi、蓝牙、Zigbee、NFC（近场通信）与蜂窝网络各有分工。粗略地说，它们在“覆盖距离、速率、功耗、是否需要运营商”几个维度上取舍不同。见下表。
- **代际脉络（1.4）**：从 1997 年发布的初版 IEEE 802.11，到 802.11n（Wi-Fi 4）、802.11ac（Wi-Fi 5）、802.11ax（Wi-Fi 6/6E）、802.11be（Wi-Fi 7），每一代都在回应当时最突出的矛盾：先是“能不能连上、够不够快”，后来是“人多设备多时还顺不顺”。“Wi-Fi 6”这类数字名称是 Wi-Fi 联盟为方便大众识别而采用的代际命名，技术标准本身仍由 IEEE 制定。

| 技术 | 典型距离 | 典型用途 | 是否依赖运营商 |
|---|---|---|---|
| Wi-Fi | 室内几十米量级 | 上网、视频、文件传输 | 否（自建网络） |
| 蓝牙 / 低功耗蓝牙 | 通常十米量级 | 耳机、手表、外设 | 否 |
| Zigbee / Thread | 单跳十米量级，可多跳组网 | 智能家居传感器 | 否 |
| NFC | 几厘米 | 刷卡、碰一碰配对 | 否 |
| 蜂窝网络（4G/5G） | 基站覆盖可达千米量级 | 户外移动上网、通话 | 是 |

（距离均为公开资料中的典型范围，实际取决于设备、环境与发射功率。）

记住一句话：**Wi-Fi 是一套由标准定义、在免许可频段上运行、把终端接入有线网络的短距无线系统。**后面八章都在给这句话里的每个词“加肉”。

## 1.5.2 实物探索任务

以下任务都不需要专业工具，用手机、电脑和家里的路由器就能完成。

1. **数一数身边的网络。** 打开手机的 Wi-Fi 列表，记下能看到多少个网络名称，哪些带锁形图标、哪些没有。换到卧室、阳台再看一次，比较列表的变化。这是在直接观察“发现”环节：每个名字背后都有一台设备在持续广播信标帧。
2. **找到路由器的身份信息。** 翻看路由器底部或背面的铭牌，找出型号、默认管理地址、默认网络名称等信息，并留意外壳上是否标有“Wi-Fi 6”“AX”“BE”之类字样，对照 1.4 节判断它属于哪一代。注意：铭牌上的“AX3000”这类数字通常是各频段理论速率的相加值，并不代表你实际能跑到的速度。
3. **画一张“看不见的网线”示意图。** 在纸上画出：手机—（无线）—路由器—（网线）—光猫—（光纤）—运营商。再把家里所有联网设备标上去，区分哪些走 Wi-Fi、哪些插网线、哪些用蓝牙或其他方式。
4. **给家里的无线设备分家族。** 列出家中所有“不插线却能联网或配对”的东西，如耳机、手表、智能灯、门锁、公交卡等，按上表归入 Wi-Fi、蓝牙、Zigbee/Thread、NFC 或蜂窝网络。拿不准的设备可以查说明书，这一步本身就是很好的练习。
5. **查看手机的连接详情。** 在已连接网络的详情页里，找找能否看到“频率”（2.4 GHz 或 5 GHz 等）、“IP 地址”“信号强度”等项目。不同品牌手机显示的内容不同，记下你能看到的条目，它们会在第二、三章逐一出现。

## 1.5.3 可以直接问 AI 的问题

- “我的路由器型号是××，铭牌上写着××。请告诉我它大概属于哪一代 Wi-Fi，支持哪些频段，铭牌上的速率数字是怎么算出来的？如果不确定，请说明需要查看哪些官方资料。”
- “请用中学生能听懂的话，按顺序解释手机连上家里 Wi-Fi 时经过的发现、认证、关联、获取 IP 地址这几步，每一步各用一个生活类比说明。”
- “我家有这些无线设备：（列出清单）。请帮我判断它们分别用的是哪种无线技术，并说明为什么它们没有统一都用 Wi-Fi。”

向 AI 提问时，把你在实物任务里记下的真实信息贴进去，得到的回答会具体得多；对 AI 给出的型号参数，也要养成回到厂商官网或标准资料核对的习惯。
