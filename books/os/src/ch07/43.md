# 7.6 本章骨架小结与实物探索任务

前面几章讲的是“操作系统一般怎样工作”，这一章换了视角，看真实世界里有名有姓的系统：服务器机房里的 Linux，你桌上的 Windows 或 Mac，口袋里的 Android 或 iPhone，云上成千上万的虚拟机和容器，汽车和家电里不显眼的实时系统，以及正在把 AI 能力接进来的新一代系统。它们共用调度、虚拟内存、文件系统、特权级这些机制，又因为用途不同做了不同取舍。本节先回顾本章骨架，再请你在自己的设备上把这些“关键技术”找出来。

## 7.6.1 本章骨架回顾

- **Linux 与开源生态**：Linux 严格说是一个内核，加上 GNU 工具、软件包管理器、桌面环境等，才组成 Ubuntu、Debian、Fedora 这类“发行版”（Distribution）。源代码公开，许多公司和个人共同维护。服务器、超级计算机、云平台大量采用它，Android 也以它为内核基础。
- **四大终端系统**：Windows 采用混合内核设计，长期重视向后兼容；macOS 与 iOS 同出苹果公司，内核叫 XNU，软硬件一体设计；Android 在 Linux 内核之上加了自己的运行时和应用框架，每个应用默认以独立用户身份运行在沙箱里；iOS 对应用后台活动和权限管理得很严。
- **虚拟化与容器**：虚拟机监控器（Hypervisor）在一台物理机上虚拟出多台“完整的计算机”，每台运行自己的操作系统；容器共用宿主机内核，靠 Linux 的命名空间（Namespace）和控制组（cgroups）做隔离和资源限制，更轻、启动更快，隔离强度一般不如虚拟机。
- **实时操作系统与嵌入式系统**：实时操作系统（RTOS）首先要保证“按时”，不追求平均最快。硬实时要求截止时间绝不能错过，软实时允许偶尔延误。FreeRTOS、Zephyr 等常见于微控制器。
- **安全机制与面向 AI 的操作系统**：安全启动、地址空间布局随机化（ASLR）、沙箱、应用签名、权限弹窗和自动更新叠在一起，形成“纵深防御”。写作时，主流系统都在加入端侧 AI 能力，调度和电源管理需要考虑神经网络处理器（NPU），系统级 AI 助手需要什么权限也成了新的设计问题。

用一张表把它们放在一起对照：

| 系统类别 | 首要目标 | 典型取舍 | 你可能接触的地方 |
|---|---|---|---|
| 服务器 Linux | 稳定、吞吐、可定制 | 图形界面常常省略 | 网站后台、云主机 |
| 桌面系统 | 兼容性与交互体验 | 资源占用较多 | 办公电脑 |
| 手机系统 | 续航、流畅、隐私 | 严格限制后台与权限 | 智能手机 |
| 虚拟机/容器 | 隔离与资源复用 | 性能损耗与隔离强度的平衡 | 云服务、开发环境 |
| 实时系统 | 时间确定性 | 功能精简 | 汽车、医疗设备、工控 |

本章的主线是：**同一套机制，按场景配置出不同的系统**。下一章追问更深一层：这些机制为什么行得通，背后有哪些原理。

## 7.6.2 实物探索任务

1. **认出你的系统身份**。Windows 打开“设置—系统—系统信息”，Mac 点击左上角苹果菜单“关于本机”，手机进入“设置—关于手机”。记下系统名称、版本号、处理器型号。Android 用户可以留意“内核版本”一栏，找到 Linux 的身影。
2. **找一找 Linux**。家里的路由器、电视盒子、智能音箱，说明书或设置页里的“开源许可声明”中常能看到 Linux 或其他开源组件。列一张清单，标出哪些设备你原本不知道在运行 Linux。
3. **体验一次虚拟化**。Windows 可在“启用或关闭 Windows 功能”中查看 Hyper-V、“适用于 Linux 的 Windows 子系统”（WSL）等选项（只看名称即可，不必勾选）；Mac 用户可以了解虚拟机软件的系统要求。想一想：这台电脑同时运行两个操作系统时，内存和处理器怎样分配？
4. **检查一遍安全设置**。在手机上逐个查看几款常用应用的“定位、相机、麦克风、通讯录”权限，关掉明显不需要的；再看看系统更新页面，记下最近一次安全补丁的日期。
5. **寻找身边的实时系统**。观察洗衣机、微波炉、汽车仪表或电梯，思考哪些动作“晚一秒都不行”（如安全气囊、刹车控制），哪些晚一点也无妨（如显示屏刷新），用这个区分理解硬实时和软实时。

## 7.6.3 可以直接拿去问 AI 的问题

- “我的手机是 Android，内核版本显示为 X（填你看到的），请解释这个版本号各部分的含义，以及 Android 和标准 Linux 发行版的主要区别。”
- “请用开公寓楼和独栋别墅打比方，比较虚拟机和容器在隔离、启动速度、资源占用上的差别，并说明这个比喻在哪些地方不准确。”
- “手机系统里的端侧 AI 功能会用到哪些硬件和系统权限？操作系统通常怎样防止它被滥用？请区分已公开的通用做法和某家厂商特有的做法。”

AI 给出的版本细节和产品功能可能已经过时，请对照官方文档或你设备上的实际显示加以核实。这也是本丛书“书 + 实物 + AI”的用法：书给骨架，设备给证据，AI 帮你往下展开。
