# 1.1 按下电源键之后：屏幕亮起前的几秒钟

早上打开笔记本电脑，手指按下电源键，风扇轻轻一转，键盘灯闪了一下，屏幕上先出现厂商标志，接着转圈，最后是登录界面。整个过程短则几秒，长则几十秒，很多人会趁这段时间去倒杯水。手机也一样：长按侧边键，先是品牌标志，再是开机动画，最后停在锁屏。

这几秒钟常被看作“等待”，其实电脑一直在干活，而且干得很有次序。它要从一块什么都不知道的硅片开始，一步步认出自己的身体，找到操作系统，再把整台机器交给它管理。看懂这段过程，就抓住了理解操作系统的第一个入口：**操作系统不是天生就在那里的，它是被一层层“请”上来的。**

## 1.1.1 通电与复位，处理器从固定地址醒来

按下电源键，实际上是给主板上的电源管理电路发出一个信号。电源先把交流电或电池电压转换成芯片需要的若干种低电压，等各路电压稳定后，再发出“电源就绪”的信号，处理器这才解除复位（Reset）状态。

刚醒来的处理器像一个失忆的人：内存里全是随机的电荷，硬盘里有什么它一概不知。它只记得一件被设计进芯片的事，就是去某个固定地址取第一条指令。这个地址指向主板上一块断电也不会丢失内容的存储芯片，里面存放着**固件**（Firmware）。正因为第一条指令的位置是事先约定好的，开机才有了确定的起点。

## 1.1.2 固件自检，认清“自己有哪些零件”

固件是整台机器最先运行的软件。在传统个人电脑上，它叫**基本输入输出系统**（BIOS，Basic Input/Output System）；现在的电脑大多改用**统一可扩展固件接口**（UEFI，Unified Extensible Firmware Interface），它可以看作功能更强、更规范的新一代固件标准。手机没有 BIOS 这个说法，但同样有一段固化在芯片里的启动代码，常被称为启动只读存储器（Boot ROM），承担类似的角色。

固件这一阶段主要做几件事：

- **初始化关键硬件**：让内存控制器开始工作，内存这时才真正能用；
- **上电自检**（POST，Power-On Self-Test）：检查内存、显卡、键盘等基本部件是否正常，有的旧电脑出故障时会用“嘀嘀”的蜂鸣声报错，就发生在这一步；
- **枚举设备**：清点硬盘、固态硬盘、U 盘、网卡分别接在哪里；
- **查阅启动设置**：按照用户事先设定的启动顺序，决定从哪个设备找操作系统。

你在开机时按某个键进入的“设置界面”，就是固件自带的配置程序，与操作系统无关。所以即便硬盘是空的，这个界面照样能打开。

## 1.1.3 引导程序登场，把操作系统“搬”进内存

固件认清了硬件，但它并不懂 Windows、macOS 或 Linux 怎样运行。它只负责找到存储设备上约定位置的**引导程序**（Bootloader），把它装进内存，然后交出控制权。

引导程序像一位接力的搬运工，要做的事是：找到操作系统内核所在的文件，把它读入内存，准备好必要的启动参数，再跳过去执行。不同系统用的引导程序不一样，例如 Windows 使用 Windows 启动管理器（Windows Boot Manager），许多 Linux 发行版使用 GRUB；在装有两个系统的电脑上弹出的“请选择要启动的系统”菜单，就是引导程序给出的。

这一步还常常伴随一道安全检查。在支持**安全启动**（Secure Boot）的 UEFI 电脑上，固件会核对引导程序的数字签名，签名不对就拒绝运行。苹果和许多安卓手机也有类似的逐级校验机制：每一级在把控制权交出去之前，先确认下一级没有被篡改。这种逐级验证形成的链条，常被称为“信任链”，后面讲安全时还会回到它。

## 1.1.4 内核接管，系统服务依次启动，直到你看见登录界面

**内核**（Kernel）是操作系统最核心的部分。它一旦开始运行，便接过整台机器的管理权：重新识别和初始化硬件，加载各类**驱动程序**（Driver），建立内存管理、进程管理等基本机制。随后它启动第一个用户程序，再由这个程序把各种后台服务逐个拉起来，比如网络、声音、打印、时间同步。最后，图形界面和登录窗口出现，你看到的就是“开机完成”了。

把这四步排成一张表，接力关系就清楚了：

| 阶段 | 谁在运行 | 存放在哪里 | 主要任务 | 你能看到的迹象 |
|---|---|---|---|---|
| 通电复位 | 硬件电路 | 主板、处理器 | 稳定供电，唤醒处理器 | 风扇转动、指示灯亮 |
| 固件 | BIOS / UEFI / Boot ROM | 主板或芯片内的存储 | 初始化硬件、自检、选启动设备 | 厂商标志、设置界面入口 |
| 引导程序 | Bootloader | 硬盘或闪存的特定位置 | 找到并加载内核 | 多系统选择菜单 |
| 内核与服务 | 操作系统 | 硬盘或闪存上的系统文件 | 接管硬件，启动服务与界面 | 转圈动画、登录界面 |

可以看到一个规律：**每一级程序都比上一级更复杂，也更懂得怎样使用硬件；每一级做完自己的事，就把控制权交给下一级。**这种从简单到复杂、一级托起一级的方式，计算机界有个形象的说法叫“自举”（Bootstrapping），取自“提着自己的鞋带把自己拎起来”这个俗语，“开机”的英文 boot 正是由此简化而来。

## 1.1.5 这几秒钟告诉我们什么

回到日常经验，这条接力链能帮你解释不少现象：

- **为什么换了固态硬盘，开机明显变快？**因为引导程序和内核要从存储设备读出大量文件，读得快，等待就短。
- **为什么有些电脑卡在厂商标志不动？**问题往往出在固件阶段，比如硬件故障或设置异常，这时操作系统根本还没上场。
- **为什么系统更新有时要“重启才能生效”？**因为内核和一些核心组件正在运行，只有重新走一遍启动流程，新文件才会被加载。

开机的几秒钟，是操作系统从无到有的过程，也是它接管整台机器的过程。登录界面出现以后，它要干的事才真正开始：同时管着几十上百个程序、分配内存、调度处理器、守护你的文件和权限。下一节，我们就来看看这位“幕后总管”接手之后到底在做什么。
