# 7.4 小基站、室内覆盖与开放无线接入网

走进一座大型商场或地铁站，抬头看天花板，常能在灯具和烟感探头之间找到一个白色的小圆盘或方盒子，不比路由器大多少。它不是 Wi-Fi 设备，而是移动网络的室内天线，或者干脆就是一台小基站。很多人以为手机信号都来自楼顶或山头的铁塔，其实今天相当一部分流量是在室内产生的。公开资料中常见的说法是，移动数据流量的多数发生在室内，具体比例因地区和统计口径而不同。要让室内信号好、容量够，只靠室外宏基站往里“打”是不够的。这一节就从天花板上的小盒子讲起，看移动网络怎样把覆盖延伸到墙里面，以及无线接入网怎样从“一家设备包到底”走向更开放的结构。

## 7.4.1 为什么室外信号进不了屋

第八章会专门讲电磁波传播，这里先记住一个直观结论：信号穿墙要付出代价。混凝土墙、金属结构、镀膜节能玻璃都会大幅衰减电磁波，频率越高衰减通常越厉害。5G 常用的 3.5 GHz 左右中频段，穿透能力就比 4G 常用的 1.8 GHz、900 MHz 等较低频段弱；毫米波则几乎无法指望穿墙。

于是出现了一个矛盾：用户大多在室内，信号却在室外。即使宏基站功率再大，也只能让室内勉强“有格”，速率和稳定性都难以保证。还有一个容量问题：一座写字楼里可能同时有成千上万部手机，如果都挤在附近一两个宏基站的同一个小区里，资源再多也会被分薄。解决办法的思路很朴素：**把基站搬到离用户更近的地方，把一个大小区拆成许多小小区。**

## 7.4.2 小基站家族：从微站到家庭基站

“小基站”（Small Cell）不是一个严格的单一产品，而是一类发射功率低、覆盖范围小的基站的统称。按公开资料中的常见分法，大致如下：

| 类型 | 典型覆盖范围（数量级） | 常见场景 |
|---|---|---|
| 宏基站（Macro Cell） | 数百米到数公里 | 城区、郊区、公路的广域覆盖 |
| 微基站（Micro Cell） | 百米量级 | 街道、广场、热点补盲 |
| 皮基站（Pico Cell） | 数十米 | 商场、写字楼楼层、交通枢纽 |
| 家庭基站（Femto Cell） | 十米量级 | 家庭、小型办公室 |

注：范围随频段、功率和环境变化很大，表中只是量级参考，各厂商和标准组织的划分口径也不完全一致。

小基站带来的好处有两层。一是**覆盖**：离手机近，信号强，墙体损耗被绕开。二是**容量**：每个小小区都能独立复用频谱资源，同样的频率在一栋楼里用了几十次，总容量自然成倍增加。这正是第三章讲过的蜂窝复用思想在更小尺度上的延续。代价是干扰和管理变复杂：小区越密，边界越多，手机越容易在小区之间频繁切换，相邻小区之间的干扰也需要更精细地协调。

## 7.4.3 室内分布系统：把天线铺进大楼

在小基站普及之前，大型建筑主要靠**室内分布系统**（Distributed Antenna System，DAS，国内常简称“室分”）。它的做法是：在机房放一台信源设备（可以是基站，也可以是从室外引入的信号），再用同轴电缆、功分器、耦合器把射频信号一路分配到各楼层的吸顶天线上。天花板上的白色小圆盘，很多就是这种无源天线。

传统室分像一套“自来水管”，结构简单，但有明显局限：电缆越长损耗越大；一套系统对应一个信号源，容量难以按楼层细分；增加新频段往往要改造线缆和器件。为此，业界发展出了**数字化室分**，这类方案的一种典型结构是“基带单元 + 汇聚单元 + 头端”三级：机房里的基带单元处理信号，经过网线或光纤连到每层的汇聚单元，再带动天花板上有源的小型射频头端。国内运营商和设备商部署较多，不同厂商的产品名称各不相同，原理相近。它的好处是每个头端可以被单独监控，容量可以按区域划分，故障也能远程定位。

从结构上看，数字化室分其实就是把第二章讲过的“基带单元 BBU + 射频单元 RRU”拆分思路搬进了大楼，只不过射频单元变得很小、数量变得很多。

## 7.4.4 开放无线接入网：把基站拆成可替换的积木

传统上，一个运营商在某个区域买基站，基带、射频、软件、网管往往来自同一家设备商，彼此之间的接口有不少是厂商私有的。这样做集成度高、性能好调，但运营商很难混用不同厂商的部件。

**开放无线接入网**（Open Radio Access Network，Open RAN）想改变的正是这一点。由运营商发起的产业组织 O-RAN 联盟（O-RAN Alliance）在 3GPP 标准的基础上，定义了一套开放接口规范，核心思路有三点：

1. **功能拆分**：把基站拆成无线单元（O-RU）、分布单元（O-DU）和集中单元（O-CU）。其中 DU 和 CU 的划分沿用了 3GPP 在 5G 中定义的 CU/DU 分离架构，O-RAN 进一步规范了 DU 与 RU 之间的前传接口。
2. **接口开放**：各部分之间的接口公开标准化，理论上不同厂商的设备可以对接。
3. **软件化与智能化**：DU、CU 可以运行在通用服务器上；同时引入“RAN 智能控制器”（RIC），允许第三方开发应用来优化调度、节能、干扰协调等，这为第九章将谈到的 AI 参与网络运营留出了接口。

需要冷静看待的是：开放并不自动意味着更便宜或更好。多厂商集成需要大量测试，性能调优与故障定界比单一厂商更难，通用服务器处理高强度基带运算的能效也仍在改进。写作时（2026 年）的情况是，Open RAN 已在一些运营商网络中有商用和试点部署，但全球主流仍是传统单厂商方案，两者并存，具体进度应以运营商和 O-RAN 联盟的公开资料为准。

## 7.4.5 小结：越靠近用户，网络越“碎”也越灵活

把本节串起来看，有一条清晰的主线：为了覆盖室内、承载密集流量，基站在**空间上**越做越小、越铺越密；为了降低成本、增加灵活性，基站在**结构上**越拆越细，从一体机到 BBU/RRU，再到 CU/DU/RU 和开放接口。小区更多、部件更多、厂商更多，网络也就更难靠人工盯着管好。下一节要讲的路测、信令分析和网管系统，正是工程师用来“看清”这张越来越碎的网的工具。
