# 7.1 4G LTE：全 IP 化的移动宽带

打开手机设置里的“移动网络”，很多人会看到“首选网络类型”一栏写着“5G/4G/3G/2G 自动”，状态栏有时显示“4G”，有时显示“LTE”或“4G+”。在不少地方，5G 信号还没覆盖到的电梯口、郊区公路和老小区里，撑起刷视频、扫码支付的，依然是 4G。本节把这个熟悉的“4G”拆开看：它到底换掉了什么，为什么说它是移动通信从“打电话的网络”变成“上网的网络”的分水岭。

## 7.1.1 名字里的含义：LTE 是什么，4G 又是什么

LTE 是“长期演进”（Long Term Evolution）的缩写，是 3GPP 在第 8 版标准（Release 8）中定义的无线接入技术。“长期演进”这个名字本身就说明了它的定位：它不是在 3G 上修修补补，而是为未来十多年的移动宽带重新设计一套系统。

与 LTE 同步定义的还有核心网的新架构，称为“系统架构演进”（System Architecture Evolution，SAE），其核心网部分叫“演进的分组核心网”（Evolved Packet Core，EPC）。无线侧加核心网合起来，3GPP 称为“演进的分组系统”（Evolved Packet System，EPS）。

需要说明的是，严格按国际电信联盟（ITU）的定义，4G 对应的是 IMT-Advanced 要求，3GPP 用来满足这一要求的是后续的 LTE-Advanced（Release 10 起）。不过在市场和日常用语中，LTE 及其演进版本普遍被称为 4G，手机上的“4G+”通常指使用了载波聚合等 LTE-Advanced 特性。这是行业习惯用法，读者知道两者的区别即可。

## 7.1.2 最大的变化：全 IP，取消电路交换

回顾第五章讲过的语音流：2G、3G 网络里有两套并行的“管道”——一套是给通话用的电路交换域，一套是给上网用的分组交换域。LTE 做了一个大胆的决定：**只保留分组交换，所有业务都用 IP 分组传送**。

| 对比项 | 3G（以 UMTS 为例） | 4G LTE |
|---|---|---|
| 核心网域 | 电路域 + 分组域 | 只有分组域（EPC） |
| 语音承载 | 电路交换 | IP 分组（VoLTE）或回落到 2G/3G |
| 基站之上的控制器 | 有无线网络控制器（RNC） | 取消，功能并入基站 |
| 设计重心 | 语音为主、兼顾数据 | 数据为主、语音也是数据 |

全 IP 带来的直接后果是：在 LTE 里，打电话也只是一种特殊的数据业务。这就是为什么早期 4G 手机打电话时会“掉回 2G/3G”——那时很多网络还没部署基于 IP 多媒体子系统（IMS）的 VoLTE，只能用“电路域回落”（CSFB）方案让通话退回旧网络。随着 VoLTE 普及，通话也留在了 4G 上。

## 7.1.3 更扁平的结构：eNodeB 与 EPC

LTE 的另一个关键词是“扁平化”。3G 时代，基站（NodeB）之上还有一层无线网络控制器（RNC）负责切换、资源管理等决策。LTE 把这一层拿掉，让基站自己变聪明，新基站称为“演进型基站”（eNodeB，常写作 eNB）。

可以用一个类比理解：3G 像是每个网点都要请示片区经理才能办业务，LTE 则给每个网点充分授权，邻近网点之间还能直接沟通。邻近 eNB 之间通过 X2 接口直接交换信息，用于切换和干扰协调；eNB 向上通过 S1 接口连接核心网。

EPC 内部又实现了“控制与转发分离”：

- **移动性管理实体（MME）**：负责信令，处理手机登记、鉴权、寻呼和位置管理，相当于“调度室”；
- **服务网关（S-GW）**：用户数据在网内的锚点，手机切换基站时数据路径在这里接续；
- **分组数据网网关（P-GW）**：通往互联网等外部网络的出口，分配 IP 地址、执行计费与策略；
- **归属用户服务器（HSS）**：存放用户签约数据和鉴权信息。

层级少了，一个数据分组经过的节点就少了，时延随之下降。按 3GPP 的需求文档，LTE 用户面单向时延目标在空载条件下小于 5 毫秒，明显低于 3G 的典型水平。

## 7.1.4 空口的三件“利器”：OFDMA、MIMO 与灵活带宽

第六章讲过的几项机制，在 LTE 上第一次被系统地组合起来：

1. **正交频分多址（OFDMA）**：下行把频带切成大量 15 kHz 宽的子载波，以“资源块”为单位分给不同用户，抗多径能力强。上行则采用单载波频分多址（SC-FDMA），降低手机发射信号的峰均功率比，有利于省电。
2. **多天线（MIMO）**：标准从第一版就支持多天线收发，可以在同一频率上并行传多路数据。
3. **灵活带宽**：单个载波可配置为 1.4、3、5、10、15、20 MHz 六档，运营商可以根据手中频谱“量体裁衣”；LTE-Advanced 再用载波聚合把多个载波捆绑使用。

此外，LTE 同时定义了频分双工（FDD）和时分双工（TDD）两种模式，后者常称为 TD-LTE。两种模式核心技术基本一致，主要区别在上下行如何分享频谱。各国选用哪种、比例如何，取决于各自的频谱分配，并非全球统一。

## 7.1.5 小结：LTE 为 5G 铺好了路

把本节内容压缩成一句话：**LTE 用 OFDMA 和 MIMO 重做了空口，用扁平化的 eNB 和全 IP 的 EPC 重做了网络，让“移动宽带”成为日常。** 它留下的设计思想——全 IP、扁平化、控制与转发分离、按资源块灵活调度——几乎都被 5G 继承并进一步推进。写作时，在许多国家和地区 4G 仍是覆盖最广的移动网络，5G 非独立组网也依赖 4G 作为“锚点”。下一节我们将看到，5G 新空口是如何在这个基础上，把带宽、频段和帧结构推向更灵活的方向。
