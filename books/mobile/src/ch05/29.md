# 5.4 语音流：从电路交换到 VoLTE 与 VoNR

拨出一个电话时，留意一下手机屏幕：在不少手机和运营商网络上，通话期间状态栏会出现“HD”“VoLTE”或“VoNR”之类的小标记；有时你还会发现，打电话时右上角的“5G”短暂变成了“4G”，挂断后又变回来。这些小标记背后，是移动通信几十年来对“语音怎么走”的几次改造。上一节我们跟着一个视频分组走完了旅程，这一节换一种流动物：你说出的每一句话。

## 5.4.1 电路交换：为一通电话“包下一条专线”

在 2G（GSM）和 3G 时代，语音走的是**电路交换**（Circuit Switching，CS）。可以用“包车”来类比：电话接通前，网络先在手机、基站、基站控制器、移动交换中心（Mobile Switching Center，MSC）之间预留一整套资源，形成一条端到端的“专线”。整个通话期间，这条线一直归你，哪怕双方都沉默不语，资源也不会让给别人。

这种方式的优点很直接：时延稳定、不会因为别人在刷视频而卡顿，通话质量可预期。代价是效率低，因为人打电话时大约有一半时间在听而不在说，预留的资源有相当部分空转。那时的网络因此分成两张“半独立”的网：语音走电路交换域（CS 域），上网走分组交换域（PS 域），两套核心网设备并存。

## 5.4.2 4G 的难题：一张没有“电话专线”的网

4G LTE 在设计时做了一个大胆决定：核心网只保留分组交换，一切都是 IP 分组（见 7.1 节）。这让上网效率大幅提升，却带来一个现实问题：既然没有 CS 域，电话怎么打？

早期 4G 部署中，常用的过渡办法是**电路域回落**（Circuit Switched Fallback，CSFB）：手机平时驻留在 4G 上网，一旦要打或接电话，网络通知它退回 2G/3G，用老办法完成通话，挂断后再回到 4G。很多读者可能有过印象：在当时的部分网络里，打电话期间网速明显变慢，甚至上不了网，原因就在于手机被“请回”了老网络。回落过程也会让接通时间多出一两秒量级的等待。

## 5.4.3 VoLTE：把语音变成享有特权的数据分组

彻底的解决方案是 **VoLTE**（Voice over LTE，基于 LTE 的语音）。它的思路是：既然网络只会传 IP 分组，那就把语音也切成分组，但要给它特殊待遇。这需要三个部件配合：

| 环节 | 电路交换语音 | VoLTE |
|---|---|---|
| 呼叫控制 | MSC 负责 | IMS（IP 多媒体子系统）负责，用 SIP 协议“打招呼” |
| 语音承载 | 预留的专用电路 | IP 分组，经 RTP（实时传输协议）传送 |
| 质量保障 | 专线天然独占 | 网络为语音建立保证比特率的专用承载 |
| 典型编码 | AMR 等窄带编码较常见 | AMR-WB 宽带编码、EVS 等 |

**IMS**（IP Multimedia Subsystem，IP 多媒体子系统）是 3GPP 定义的一套核心网子系统，相当于 IP 世界里的“电话交换局”。拨号时，手机通过 **SIP**（Session Initiation Protocol，会话初始协议）向 IMS 发出邀请，对方振铃、应答，双方再协商用什么编码。这个过程本质上是 5.2 节所说的信令流，只不过换成了 IP 上的“对话”。

接通之后，语音分组并不是和视频分组挤在一起排队。LTE 用服务质量等级来区分业务：在 3GPP 规范里，会话类语音对应 QCI 1，属于“保证比特率”（Guaranteed Bit Rate，GBR）类型，时延预算在百毫秒量级；IMS 信令也有自己的高优先级等级。基站调度器（见 6.4 节）看到这些标记，会优先给语音分配资源。打个比方，语音分组是持“绿色通道”证的旅客，和普通旅客走同一个车站，却不必排普通队。

状态栏上的“HD”，往往对应的就是宽带编码：传统电话只保留约 300–3400 Hz 的声音频段，宽带编码把范围扩展到大约 50–7000 Hz，声音听起来更饱满、更像面对面。同一套 IMS 框架还支持视频通话，部分运营商称之为 ViLTE。

## 5.4.4 5G：从 EPS 回落到 VoNR

5G 独立组网（SA）的核心网同样是纯分组的，语音依然交给 IMS。在 5G 新空口上直接承载 IMS 语音，就叫 **VoNR**（Voice over New Radio，基于 5G 新空口的语音），其服务质量等级在 5G 中用 5QI 表示，会话语音同样对应 5QI 1。

不过在 5G SA 部署初期或某些区域，网络对 VoNR 的支持尚未完善，常见做法是 **EPS 回落**（EPS Fallback）：呼叫建立时把手机转回 4G，用 VoLTE 通话，结束后再回到 5G。这正是开头提到的“5G 变 4G”现象的常见原因之一。各国运营商开通 VoNR 的进度不同，是否显示标记也取决于手机厂商和运营商设置，以写作时的情况看，VoLTE 已是许多国家 4G/5G 网络中的主流语音方式，而 2G/3G 退网正在许多国家推进，这也使 VoLTE 的普及成为退网的前提条件。

## 5.4.5 小结：语音从“特殊公民”变成“特权分组”

回看这条演进线：电路交换时代，语音是拥有专属道路的特殊公民；4G 起，语音并入 IP 的大道，靠 IMS 控制呼叫、靠服务质量机制保住“专线般”的体验；5G 则延续这一思路，把语音带到新空口上。下次看到状态栏的 HD 或 VoNR 标记，你就知道，那一刻你的声音正以每 20 毫秒左右一帧的节奏被打包成分组，在优先通道里穿过网络。语音是对时延最敏感的流量，但它在总量里只占很小一部分；真正撑满网络的是什么，又会在何时何地集中爆发，正是下一节要讨论的问题。
