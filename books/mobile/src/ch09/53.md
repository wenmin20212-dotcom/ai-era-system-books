# 9.4 本章骨架小结与实物探索任务

翻到这里，你手里的手机还是那部手机，右上角的信号格也还是那几格。不同的是，这一章给了你一套和 AI 一起往下挖的方法：先让 AI 帮你读懂手机里显示的网络信息，再动手测量、记录、画图，最后用分层提问把问题一路追到原理。这一节把第九章的骨架收拢，再给出几个可以马上动手的任务。它也是全书的最后一节，所以会顺带把九层认知阶梯从头到尾串一遍。

## 9.4.1 本章骨架回顾

第九章讲的是“书 + 实物 + AI”三者怎样配合，可以归纳为三条主线：

- **读懂（9.1）**：手机的“关于本机”“SIM 卡状态”页面，以及测速应用的结果页，都是移动网络留给用户的观察窗口。信号强度通常以 dBm（分贝毫瓦）为单位，数值是负数，越接近 0 越强。参考信号接收功率（RSRP）衡量信号有多强，参考信号接收质量（RSRQ）和信号与干扰加噪声比（SINR）衡量信号有多“干净”。测速结果里的下载速率、上传速率和时延（Ping）分别对应容量、上行资源和往返路径。AI 的作用是把这些读数翻译成你听得懂的话，并指出各项读数之间的联系，比如“信号强但速率低”往往和干扰或小区拥塞有关。
- **测量（9.2）**：单次读数说明不了什么，按地点和时间连续记录才有价值。在同一地点的不同时段测，看到的是流量潮汐；在不同地点测，看到的是覆盖和遮挡；从室外走到室内或电梯里测，看到的是穿透损耗和切换。把数据整理成表格交给 AI 画图，书里讲过的传播衰减、负荷和切换就能在你自己的数据里找到对应。
- **提问（9.3）**：同一个现象可以分三个层级来问。中学生层级问“是什么、为什么”，入门者层级问“由哪些部分组成、怎样运作”，工程师层级问“怎样量化、怎样权衡、依据哪份标准”。每往上走一级，问题就更具体，AI 的回答也更容易用书本和实测去核对。

贯穿三条主线的有一条纪律：**AI 的回答需要核实**。涉及标准条款时，应回到 3GPP 技术规范（TS）或 ITU 建议书原文；涉及某家运营商的频段和部署时，以该运营商或监管机构公布的信息为准；涉及具体数值时，问清楚这是典型范围还是实测值。AI 可能把不同制式、不同国家的做法混在一起，也可能编出看起来很合理的数字。

## 9.4.2 全书九层阶梯的再串联

本章是第九层，它落在前八层之上。下表把各层和读者手边能做的事对应起来：

| 认知层 | 核心问题 | 手边的观察入口 |
|---|---|---|
| 对象 | 移动通信系统是什么 | 打电话、刷视频时的信号格 |
| 结构 | 由哪些部分组成 | 手机、楼顶天线、路边机柜 |
| 功能 | 各部分做什么 | 开机找网、来电、坐车时的切换 |
| 连接 | 各部分怎样相连 | 网络制式图标、运营商名称 |
| 流动 | 系统中流动着什么 | 流量统计、通话时长 |
| 机制 | 系统怎样运行 | 不同时段测速的差异 |
| 关键技术 | 用了哪些主流技术 | 4G/5G 图标、VoLTE/VoNR 开关 |
| 原理 | 为什么能这样工作 | 信号强度随距离、遮挡的变化 |
| AI 协同 | 怎样继续往下学 | 把读数和问题交给 AI 并核实 |

前八层是稳定的骨架，第九层负责把骨架接到不断变化的现实网络上。写作时的主流制式是 4G 与 5G，今后终端界面、制式名称和测速工具都会变，而“读数—测量—分层提问—核实”这套方法不会因此失效。

## 9.4.3 实物探索任务

1. **读一张自己的网络名片**：打开手机的 SIM 卡状态或网络信息页面（不同品牌的入口不同，可以让 AI 告诉你自己机型的位置），记下网络类型、信号强度（dBm）和运营商名称。如果能看到 RSRP、SINR，也一并记下。把截图交给 AI，请它逐项解释，再对照本书第五章、第八章核实。
2. **一天三测**：在同一个位置，分别于早上、午间、晚上各测速一次，记录下载速率、上传速率和时延。观察结果是否随时段变化，并结合 5.5 节的流量潮汐和 6.4 节的调度机制，解释你看到的现象。
3. **一条路线的信号剖面**：从家走到学校或单位，每隔几分钟记录一次信号强度和网络类型，特别留意楼道、电梯、地下通道这几个位置。把数据交给 AI 画成折线图，找出信号最弱的一段，并用 8.2 节的遮挡和穿透损耗作出解释。
4. **对照制式开关**：如果你的套餐和手机都支持，在保证能正常通话的前提下，于设置中切换“优先 5G”与“仅 4G”，在同一地点各测一次速率和时延，比较两者的差异，同时记下手机发热和电量消耗的感受。
5. **做一页自己的骨架图**：只用一张纸，把本书九层阶梯和你在上面四个任务里看到的现象连起来画成一页图，再请 AI 检查有没有错位或遗漏。

以上任务只需要观察自己的手机，不需要也不应该尝试截获他人的信号或改动网络设备。

## 9.4.4 可以直接问 AI 的问题

- “我的手机显示 5G，RSRP 是 −105 dBm，SINR 是 3 dB，测速只有十几 Mbps。请分层解释可能的原因，并告诉我每个判断可以用哪项读数或哪份 3GPP 规范来核实。”
- “请用中学生、通信入门者、网络优化工程师三个层次，分别解释‘为什么地铁里人一多，网速就变慢’，并指出三个层次的解释之间是怎样衔接的。”
- “根据我记录的这份路线信号数据（附表），哪些位置可能发生了切换？请说明判断依据，同时说明这个判断有哪些不确定的地方。”

## 9.4.5 结语：信号格之后

回到序章的那几格信号。它们背后有终端里的基带与射频，有铁塔上的天线，有机房里的核心网和地下的光纤，有 3GPP 与 ITU 的标准，有频谱规划和产业链分工，有多址、编码、波束赋形和调度，也有香农定理和电磁波传播的物理约束。“边走边连”能够实现，靠的是这一整套系统协同工作。书已经把这套骨架交给你，手机就在你手边，AI 可以陪你继续往下问。下一次信号格少了一格时，希望你能顺着这套骨架，自己找出原因。
