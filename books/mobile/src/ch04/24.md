# 4.4 运营商、设备商与终端厂商：产业链的分工

拿起手机，翻到“设置—关于本机”，你能看到手机品牌和型号；打开“SIM 卡信息”，能看到运营商名称；如果再查一下手机的规格说明，往往还会看到一个陌生的名字：基带芯片或处理器的供应商。走到街上，铁塔下机柜的铭牌上又印着另一家公司的标志。一次普通的通话，背后至少站着三四类企业。它们彼此不隶属，却必须严丝合缝地配合。本节就来看这条产业链怎样分工，又靠什么连在一起。

## 4.4.1 从一部手机往外数：产业链上的几类角色

按照信号从你手里出发的方向，可以把主要角色排成一串：

| 角色 | 主要做什么 | 你能在哪里看到它 |
|---|---|---|
| 芯片厂商 | 设计基带芯片、射频芯片、应用处理器 | 手机规格页、拆机报告 |
| 终端厂商 | 设计、集成、销售手机和物联网模组 | 手机背面的品牌标志 |
| 运营商（Mobile Network Operator，MNO） | 持有频谱牌照，建设和运营网络，向用户卖套餐 | 信号栏旁的运营商名称、话费账单 |
| 网络设备商 | 制造基站、核心网设备、传输设备 | 铁塔机柜、机房设备铭牌 |
| 铁塔与基础设施公司 | 建设铁塔、机房、供电等配套 | 铁塔底座上的标识牌 |
| 测试认证与软件服务方 | 一致性测试、网络规划优化、运维软件 | 一般用户看不到 |

此外还有一个常被忽略的角色：虚拟运营商（Mobile Virtual Network Operator，MVNO）。它自己不建基站、不持有频谱，而是向运营商批发网络能力，再以自己的品牌卖给用户。所以你手机上显示的“运营商名称”，背后承载网络的未必是同一家。

## 4.4.2 谁出钱、谁建网、谁收钱：运营商处在中枢

运营商是整条链上的“甲方”。它的工作可以概括成三件事：

- **拿频谱**：向国家频谱主管部门申请或竞拍频段使用权（上一节已讲过频谱如何分配）；
- **建网络**：向设备商采购基站、核心网和传输设备，规划站址、组网、调试和优化；
- **做运营**：发放 SIM 卡，管理用户签约数据，设计套餐，计费收费，提供客服。

运营商的收入主要来自用户话费和流量费，而建网是一次性投入巨大、回收周期很长的生意。这就解释了很多日常现象：为什么新一代网络总是先覆盖城区热点，再慢慢铺到乡村；为什么运营商之间会共建共享基站。在中国，2014 年起由几家运营商共同出资组建的铁塔公司统一建设和管理铁塔等配套设施；在欧洲一些国家，运营商之间也有共享站址甚至共享无线接入网的协议。共享的具体形式因国家和公司而异，不能一概而论。

## 4.4.3 设备商与终端厂商：网络两端的制造者

网络这一端是**设备商**。基站的射频单元、基带处理单元、天线，核心网的各类网元，传输网的光设备，都出自它们之手。这类设备需要长期研发投入和大量标准专利积累，全球范围内能提供完整端到端网络设备的公司数量很少。在写作时，公开资料中常被提及的主要包括华为、爱立信、诺基亚、中兴、三星等，各家的市场地位随地区和年份变化较大，这里不列份额数字。

用户这一端是**终端厂商**。一部手机里，真正负责“和基站说话”的是基带芯片，它实现了从物理层到无线资源控制层的整套空口协议；射频前端负责把信号放大、滤波并送到天线。能设计成熟蜂窝基带芯片的公司同样屈指可数，许多手机品牌选择外购芯片，再做整机集成、外观设计与系统软件；也有少数厂商自研部分或全部芯片。哪家采用哪种方案，以具体机型的公开规格为准。

一个有用的对照是：**设备商和终端厂商各自实现同一套标准的“两头”**。基站说的话，手机必须听得懂；手机发的信号，基站必须收得到。双方从未一起写过代码，靠的却是同一份 3GPP 规范。

## 4.4.4 把各方连在一起的四根“纽带”

不同公司之所以能协同，靠的不是谁指挥谁，而是几根公认的纽带：

1. **标准**：3GPP 规范规定了空口和各网元接口的行为。设备商、芯片厂商、运营商都派代表参与制定，把自己的技术方案写进标准，这是上一节“标准与组织”在产业层面的落点。
2. **专利与许可**：写进标准、实现标准所必需的专利称为标准必要专利（Standard Essential Patent，SEP）。专利持有人通常承诺以“公平、合理、无歧视”（FRAND）条件授权，手机和设备厂商据此支付许可费。
3. **测试与认证**：新手机上市前，需要通过协议一致性和射频测试，例如由运营商和厂商共同参与的行业认证组织所规定的测试项目；进入不同运营商网络，还常要做运营商自己的入网测试。各国监管机构另有无线电型号核准等要求。
4. **互操作测试**：同一张网里可能混用不同设备商的产品（例如核心网用一家、基站用另一家），手机又来自几十个品牌。上线前要做大量互通测试，确保“甲家的基站 + 乙家的芯片 + 丙家的手机”也能正常工作。后面 7.4 节要讲的开放无线接入网（O-RAN），正是想把基站内部也拆成可以混搭的模块，让这种互操作更进一步。

## 4.4.5 一次通话里的产业链

回到开头的场景。你按下拨号键：芯片厂商设计的基带把语音编码、调制，射频前端送上天线；电波到达铁塔公司建的铁塔、设备商造的基站；基站经运营商的传输网把数据送进核心网，核心网核对你在运营商那里签约的身份和套餐，再把呼叫接到对方。几秒钟里，至少五六类企业的产品依次接力，而你只看到了一个“正在呼叫”。

可以把这条产业链想成一场接力赛：运营商是组织比赛并卖票的一方，设备商和终端厂商是跑在两端的选手，芯片厂商为选手提供心脏，标准则是所有人共同遵守的赛道规则。看清了这些角色，就能理解很多新闻背后的逻辑：频谱拍卖影响的是运营商的投资节奏，专利纠纷影响的是手机的成本，入网测试决定的是新机能不能在某张网上用好。到这里，第四章“建立关系”的四个层面——协议、标准、频谱、产业——已经全部展开，下一节将把它们收拢成一张骨架图。
