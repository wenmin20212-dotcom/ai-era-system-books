# 1.3 移动通信的边界：蜂窝网络、Wi-Fi、卫星与互联网

晚上回到家，手机右上角的“5G”图标悄悄变成了一个扇形的 Wi-Fi 图标；周末去山里徒步，信号格一路掉到“无服务”，有些新款手机却提示“可通过卫星发送紧急消息”；而无论用哪种方式连上，打开的都是同一个视频应用、同一个“互联网”。这几种连接方式在手机上切换得悄无声息，看起来像一回事，其实是几套不同的系统。弄清它们的边界，才能知道本书讨论的“移动通信系统”具体指什么，不指什么。

## 1.3.1 蜂窝网络：本书的主角

本书所说的移动通信系统，主要指**蜂窝移动通信网络**（Cellular Network）。它把大片地区划分成许多相邻的小区，每个小区由基站覆盖，就像蜂巢由一个个六边形格子拼成，“蜂窝”一名由此而来。它有三个标志性特点：

- **使用授权频谱**：运营商从国家监管机构获得某段频率的使用权，在该区域内独占使用，干扰可以统一规划和控制。
- **为移动而生**：网络时刻知道你大致在哪片区域，你在高速行驶的车上从一个小区进入另一个小区，通话和下载能够继续，这叫**切换**（Handover）。
- **有一套完整的身份与计费体系**：SIM 卡里保存着用户身份和密钥，核心网负责鉴权、计费和漫游，你到了另一个城市甚至另一个国家，依然能被找到、被计费。

从 1G 到 5G，变化的是技术细节，不变的是这套“大范围覆盖 + 随时移动 + 可运营可计费”的系统思路。

## 1.3.2 Wi-Fi：家门口的“短绳”

Wi-Fi 是基于 IEEE 802.11 系列标准的**无线局域网**（WLAN，Wireless Local Area Network）技术。家里那台路由器就是一个小小的无线接入点，覆盖范围通常是一套房子、一间办公室，量级在几十米左右。

和蜂窝网络相比，它的差异很清楚：

| 对比项 | 蜂窝网络 | Wi-Fi |
|---|---|---|
| 频谱 | 授权频谱为主，运营商专用 | 免授权频谱（如 2.4 GHz、5 GHz 等频段），大家共用 |
| 建设与管理者 | 运营商统一规划 | 家庭、企业、商场各自部署 |
| 覆盖范围 | 城市、道路、乡村，连续成片 | 一个房间到一栋楼，零散分布 |
| 移动性 | 系统级的切换与位置管理 | 主要在静止或慢速场景使用，跨接入点切换能力有限 |
| 身份认证 | SIM 卡与核心网鉴权 | 通常是密码或企业账号 |

打个比方：蜂窝网络像覆盖全国的公共交通网，有统一调度和票务；Wi-Fi 像小区里的自行车，自己买、自己管、骑起来方便，但出了小区就不顶用。两者并不是谁取代谁，而是互补：手机常常在家用 Wi-Fi、出门用蜂窝，标准组织也定义了让两者协同的机制，比如部分运营商提供的 Wi-Fi 通话（VoWiFi）功能。Wi-Fi 的技术细节在本系列另有专册，本书只在涉及协同时简要提及。

## 1.3.3 卫星通信：把“基站”搬上天

卫星通信把转发设备放在太空中，一颗或一群卫星就能覆盖海洋、沙漠、高山这些建基站不现实的地方。它的长处是覆盖广，短处也来自距离：信号要上天再下来，路径损耗大、时延较长（尤其是距地面约 3.6 万千米的地球同步轨道卫星），单位面积能提供的容量远低于密集部署的地面基站。

近年的变化是两者开始融合。3GPP 从 Release 17 起把**非地面网络**（NTN，Non-Terrestrial Network）纳入标准，研究让普通手机或物联网终端直接经卫星接入。写作时，市场上已有部分手机支持卫星紧急消息或卫星通话，但不同厂商、不同国家采用的方案各不相同，有的基于 3GPP 标准，有的是厂商与卫星公司的专有方案，不能一概而论。卫星通信本身在本系列另有专册，本书把它看作蜂窝网络覆盖边缘的“延伸”。

## 1.3.4 互联网：蜂窝网络通往的目的地

最容易混淆的是“移动网络”和“互联网”。刷视频时，视频文件存放在内容提供商的服务器上，那些服务器属于互联网；蜂窝网络负责的是把你的手机**接入**互联网，并在你移动时保持这条路不断。

可以把整条路径分成两段：

1. **移动网络段**：手机 → 基站 → 传输网 → 核心网。核心网里有一个“网关”角色的设备（4G 中的 PGW、5G 中的 UPF），它是移动网络与外部数据网络的出入口。
2. **互联网段**：从网关出去之后，数据进入运营商骨干网和互联网，经过路由器层层转发，到达视频服务器。

也就是说，蜂窝网络是互联网的一种“接入方式”，与家里的光纤宽带、Wi-Fi 处在相似的位置。至于数据在互联网中如何寻址、如何路由，第二十五册已有详细讨论，本书不再展开。反过来，打普通电话、发短信这些业务，传统上并不经过公共互联网，而是在运营商网络内部完成，这也说明移动网络有自己独立的一套体系。

## 1.3.5 小结：画出本书的地图边界

把几者放在一起，可以得到一张清楚的分工图：Wi-Fi 管“屋里”，蜂窝网络管“路上和城里”，卫星管“天涯海角”，互联网是它们共同通往的内容与服务世界。本书聚焦的，是中间那张能让人“边走边连”的蜂窝网络。理解了边界，下一节回到时间轴上，看看这张网从 1G 到 5G，每一代究竟解决了什么问题。
