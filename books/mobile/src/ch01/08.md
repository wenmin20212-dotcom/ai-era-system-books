# 1.5 本章骨架小结与实物探索任务

拿起手机，看一眼右上角：几格信号、一个“4G”或“5G”的标识，也许旁边还有一个 Wi-Fi 扇形图标。读完第一章，这几个小符号背后应当已经浮现出一张粗略的图：信号格对应着附近某个基站的无线覆盖，“5G”说明你此刻接入的是哪一代系统，而 Wi-Fi 图标提醒你，手机同时站在两张不同的网络边上。本节先把这张图收拢成骨架，再请你动手去验证它。

## 1.5.1 本章骨架回顾

第一章回答的是“这是什么”，可以压缩为四个要点：

1. **一次通话或一段视频的路径（1.1）**：信号从手机的天线出发，经空中无线电波到达基站，再经传输网的光纤或微波进入核心网，最后去往对方手机或互联网上的视频服务器。无线只是“第一公里”，后面大部分路程走的是有线网络。
2. **系统的定义（1.2）**：移动通信系统的核心任务是让“边走边连”成为可能。它要同时解决三件事：在大范围内提供无线覆盖，在用户移动时保持连接不中断，在海量用户之间公平而高效地分配有限的频谱资源。蜂窝结构、切换与位置管理、多址与调度，都是为这三件事服务的。
3. **系统的边界（1.3）**：蜂窝网络与 Wi-Fi、卫星通信、互联网既相互衔接，又分工不同。蜂窝网络使用运营商持有的授权频谱，强调广域覆盖和移动性；Wi-Fi 多用免授权频段，覆盖局部区域；卫星通信补足偏远地区与海上空中；互联网则是蜂窝网络接入后要去的“目的地网络”。这几类系统在本系列另有专册，本书只在交界处带过。
4. **代际演进（1.4）**：从 1G 到 5G，每一代都在回应上一代留下的难题。

| 代际 | 主要解决的问题 | 标志性变化 |
|---|---|---|
| 1G | 让电话能“移动” | 模拟语音，频分多址 |
| 2G | 容量不足、易被窃听 | 数字化，加密，短信 |
| 3G | 上网需求出现 | 分组数据，码分多址为主 |
| 4G | 移动宽带 | 全 IP 化，正交频分多址 |
| 5G | 更多场景、更多连接 | 大带宽、低时延、海量连接、网络切片 |

把四个要点串起来，就是本书九层阶梯的第一层“对象”：先认清系统的轮廓、边界和来历，后面各章再逐层拆开它的结构、功能与机制。

## 1.5.2 实物探索任务

下面的任务只需要一部手机和一点耐心，不涉及任何专业设备。不同品牌、不同系统版本的菜单名称差别很大，以下描述是写作时常见的情况，找不到时可以请 AI 根据你的机型指路。

**任务 1：信号格观察日记。** 在家中客厅、卧室、卫生间、电梯、地下车库各停留一分钟，记录信号格数和网络标识（4G/5G）。你会发现，同一栋房子里信号差别可能很大。先写下你的猜测：墙体、楼层、金属门哪个影响最大？这些猜测会在第八章“电磁波传播”中得到解释。

**任务 2：关掉 Wi-Fi 看一看。** 在家里分别打开和关闭 Wi-Fi，用同一个视频应用播放同一段视频，观察画面清晰度或加载速度的变化，并留意手机流量统计的变化。这能帮你直观区分“蜂窝数据”和“Wi-Fi”两条路，印证 1.3 节讲的系统边界。

**任务 3：找一找你的代际。** 在手机设置中查找“首选网络类型”之类的选项（部分机型在“移动网络”或“SIM 卡与移动数据”中），看看可选的有哪些代际。注意只观察、不随意更改；若修改后通话或上网异常，恢复默认即可。

**任务 4：边走边看。** 坐公交或地铁时，留意信号格和网络标识是否变化，进出隧道、经过高架桥时尤其明显。你看到的跳变，往往对应着手机在不同基站之间的切换，或在 4G 与 5G 之间的转换。第三章和第六章会讲清楚这个过程。

**任务 5：寻找基站。** 外出时抬头留意楼顶、路灯杆、铁塔上的板状或柱状天线。拍照记下位置，但不要攀爬或靠近设备。第二章会告诉你这些天线分别是什么。

## 1.5.3 可以直接问 AI 的问题

把以下问题复制给你常用的 AI 助手，并在问题后补上你的手机型号或所在环境，回答会更贴切：

1. “我的手机信号显示满格，但网速很慢，可能有哪些原因？请按‘手机—基站—核心网—互联网’的路径逐段分析。”
2. “请用中学生能懂的语言，解释为什么移动通信要把覆盖区域分成一个个‘蜂窝小区’，而不是用一座超大功率的发射塔覆盖整个城市。”
3. “2G 到 5G 的演进中，哪些问题是一代代逐步解决的，哪些问题至今仍然存在？请注明哪些说法有 3GPP 或 ITU 公开资料可以查证。”

对 AI 的回答保持一点审慎：凡是涉及具体数字、具体运营商做法的内容，最好追问出处，或对照官方资料核实。

## 1.5.4 走向下一章

第一章让我们看清了移动通信系统“是什么”：它从哪里来，到哪里去，边界在哪里。可一个系统不能只看外形。手机里究竟装了哪些部件，基站铁塔下的机房里放着什么，核心网的“大脑”如何运作，光纤又怎样把千万个基站连成一张网——第二章将把这台庞大的机器逐块拆开。
