# 1.2 移动通信系统是什么：让“边走边连”成为可能

坐地铁时，你戴着耳机和朋友通话。列车穿过隧道、驶过站台，窗外几分钟就换了一片街区，电话却一直没断。到站出闸，你顺手打开地图导航，画面加载如常。这件事我们习以为常，但仔细想一想：你的手机没有连任何一根线，人在高速移动，身边还有成百上千个乘客同时在打电话、刷视频。是什么让这一切成立？回答这个问题，就是给“移动通信系统”下定义。

## 1.2.1 三个难题：无线、移动、众人共用

把“边走边连”拆开看，它要同时解决三个难题。

**第一，没有线。**有线电话靠铜线把声音送到交换机，信号沿着固定的路走。手机只能靠电磁波在空气中传播，而电磁波会随距离衰减，会被墙体和车厢遮挡，还会在楼宇之间反射叠加、忽强忽弱。手机右上角的信号格时多时少，反映的正是这种变化。

**第二，人在动。**固定电话的号码对应一个固定位置，网络知道该把来电送到哪里。手机用户今天在北京、明天在上海，走路时也在不断改变位置。网络必须随时知道“这个人大概在哪”，并在他移动时把连接从一个基站平稳交给下一个基站。

**第三，很多人共用。**能用于通信的无线频率资源有限，而一座城市里同时使用手机的人数以百万计。系统必须想办法让大量用户共享同一份频谱，彼此干扰又不能太大。

用一句话概括：**移动通信系统是一套让大量用户在移动中，通过无线方式随时接入、并与世界上任何其他用户或服务保持连接的通信基础设施。**其中，“无线”“移动”“大量用户”三个关键词，正好对应上面三个难题。

## 1.2.2 一套系统，而不是一个基站

很多人以为手机信号就是“从楼顶那根天线来的”。基站确实是你最容易看到的部分，但它只负责最后一段无线连接。一次完整的通信要经过好几个环节分工协作。下面是一张粗略的对照表，后面第二章会逐一展开：

| 组成部分 | 通俗比喻 | 主要职责 |
|---|---|---|
| 终端（UE，User Equipment，用户设备） | 你手里的“话筒和收音机” | 发射与接收无线信号，保存身份凭证（SIM 卡） |
| 无线接入网（RAN，Radio Access Network） | 遍布各处的“收发站” | 用电磁波与手机通信，管理空中资源 |
| 核心网（CN，Core Network） | 中枢“调度中心” | 认证身份、记录位置、计费、把数据转发到目的地 |
| 传输网 / 承载网 | 连接各站的“高速公路” | 用光纤或微波把基站和核心网连起来 |

可以看到，真正“无线”的只有手机到基站那一段，通常从几十米到几公里。信号进入基站后，大部分路程走的是光纤，最终可能经由互联网到达视频服务器，或经由另一张移动网络到达朋友的手机。所以，移动通信系统更像一张**“无线的末梢 + 有线的骨架”**组合起来的网。

## 1.2.3 让难题变得可解的几个关键思想

面对三个难题，移动通信系统用了几种基本思路，它们会贯穿全书。

- **蜂窝化**：把大片区域划分成许多小的覆盖区域，叫作“小区”（cell），每个小区由一个基站扇区负责。相隔足够远的小区可以重复使用同一组频率，有限的频谱就能服务更多人。“蜂窝网络”（cellular network）这个名字由此而来，第三章和第八章会详细讨论。
- **移动性管理**：网络持续跟踪手机大致所在的区域（位置管理），并在通话或上网时，把连接从信号变弱的小区交给信号更好的小区（切换，handover）。地铁里电话不断，靠的就是一次次快速切换。
- **多址与资源调度**：用划分频率、时间、编码或子载波等方法，让众多用户“分时分频”地共用空中资源，由基站决定每一刻分配给谁多少资源。
- **身份与安全**：SIM 卡里保存着用户身份和密钥，网络在接入时核验“你是谁”，并对无线链路加密，防止被冒用或窃听。

这几点合起来，才使“随时、随地、在移动中”的连接从理想变成工程现实。

## 1.2.4 为什么必须靠“标准”把它们捆在一起

还有一个容易被忽视的事实：你的手机、街边的基站、运营商机房里的核心网设备，往往来自不同的厂家；你出国旅行时，手机还要连上另一个国家运营商的网络。它们之所以能互相听懂，是因为大家遵循同一套技术规范。目前全球主流移动通信标准由 3GPP（第三代合作伙伴计划）制定，ITU（国际电信联盟）则负责划定代际的总体要求和频谱的国际协调。第四章会专门讲标准与组织的关系。正因为有共同标准，移动通信才成为一张覆盖全球、可以漫游的大网，而不是许多互不相通的孤岛。

## 1.2.5 小结：从“一根天线”到“一个系统”

回到地铁上的那通电话。它不断线，不是因为某个基站功率特别大，而是因为终端、无线接入网、核心网和传输网在标准约束下紧密配合：基站负责空中接力，核心网记住你是谁、在哪、该把数据送去哪里，光纤把这一切串起来。理解移动通信，就是要从“楼顶有根天线”的直觉，升级为“这是一个分工协作的系统”的视角。

下一节，我们将划出这个系统的边界：同样是无线上网，Wi-Fi、卫星通信与蜂窝网络有什么不同，它们又和互联网是什么关系。
