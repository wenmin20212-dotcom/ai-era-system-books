# 5.6 实物观察与AI协同：分析一条供电散热链路

面对一台计算机，电源、主板和散热器很容易被看成三个独立部件。本节把它们连成一条可观察、可解释的链路：电能如何到达处理器，处理器工作时产生的热量又如何进入周围环境。目标不是凭外观判断供电“够不够强”，而是依据实物线索，说明各环节承担什么任务，以及哪些判断仍需资料或测量支持。

## 5.6.1 从实物中找出两条路径

以常见的风冷台式机为例。观察前应正常关机、切断外部电源，并遵循设备维护说明。不要拆开电源内部，也不要触碰运行中的风扇或带电电路；无法安全打开的设备，可以改用官方内部结构图。

先找到电源、主板供电插头、处理器插座附近的电感与电容，以及处理器散热器。不要仅凭颜色或形状给器件定名，应结合主板说明书、板上标识和清晰照片交叉确认。散热片下方可能遮住供电器件，此时记录“不可见”，无需为完成观察而继续拆卸。

接着画两条箭头：

- **供电路径：**电源输出 → 主板供电接口 → 处理器供电转换电路 → 处理器。
- **散热路径：**处理器芯片 → 封装中的导热结构 → 导热界面材料 → 散热器 → 流动空气 → 周围环境。

这是帮助理解的简化图。具体封装、供电布局和散热结构因设备而异，实际还有热量经主板等路径传出。笔记本电脑也可能使用热管或均热板，把热量送到远离处理器的鳍片处。

| 观察对象 | 可以记录的线索 | 不能仅凭外观确定的内容 |
|---|---|---|
| 电源与线缆 | 铭牌、插头、连接位置 | 实际负载下的输出质量 |
| 主板供电区域 | 电感、电容、散热片的位置 | 电路承载能力与转换效率 |
| 处理器散热器 | 底座、鳍片、风扇、安装位置 | 实际接触状态与散热能力 |
| 机箱通风区域 | 开孔、滤网、线缆遮挡 | 运行时的实际风量与回流情况 |

这张表把“看见了什么”和“据此能知道什么”分开，避免把线索直接当成结论。

## 5.6.2 解释电与热为什么相连

电源提供的电能，一部分在供电转换过程中变成热，另一部分进入处理器，支持晶体管切换等活动。处理器消耗的电能最终大多也转化为热。因此，处理器附近既有需要供电的计算部件，也有自身需要散热的供电器件。

散热器并不把热量消除，而是提供热量向外传递的路径。底座接收热量，鳍片扩大与空气接触的面积，风扇促进空气流动。导热界面材料用于改善接触面之间的传热；如果接触不良，后面的鳍片和风扇即使正常工作，整条路径仍可能受阻。

这里可以引入“热阻”：在其他条件相近时，某段路径越难传热，为传出相同热量所需的温差就越大。它帮助我们理解，散热效果取决于整条路径，不能只看风扇转得快不快。

## 5.6.3 用一次运行记录检验解释

完成观察并按要求恢复设备后，可以在正常使用中，分别记录空闲状态和同一项日常任务运行一段时间后的情况。选用能够识别本机传感器的监测工具，记录处理器温度、功耗读数、频率和风扇转速，同时注明室温、任务名称和观察时长。部分读数可能缺失，功耗也可能是估算值，应保留工具给出的名称与说明。

假设任务开始后，功耗和温度上升，随后风扇加速，温度逐渐稳定。这与“发热增加—散热调节—形成新的热平衡”的解释相符。但温度稳定不一定表示性能保持不变：处理器也可能通过降低功耗或频率控制温度，需要结合任务表现判断。

如果发现温度较高，也不能立即断言散热器故障。环境温度、持续负载、灰尘、风扇策略、接触状态及传感器含义都可能影响结果。先核对记录，再提出候选原因，证据比直觉更有用。

## 5.6.4 让AI整理证据并提出下一步

把观察记录交给AI时，应明确哪些来自照片，哪些来自说明书，哪些来自监测软件。可以使用以下Prompt：

> 你是一名计算机硬件教学助手。请依据我提供的设备型号、内部照片说明和运行记录，分析处理器的供电与散热链路。
>
> 请依次输出：①用箭头画出供电路径与主要散热路径；②解释各环节的功能和相互影响；③把结论分为“已有证据支持”“合理推测”“信息不足”；④若存在异常，列出候选原因及安全、可逆的核查步骤。
>
> 不要凭外观推定供电能力，不要仅凭单个温度值判断故障。涉及型号参数、温度限制和维护方法时，请指出需要核验的官方资料；无法确认时明确说明。

完成这项练习后，应能沿着一条具体路径解释电从哪里来、热向哪里去，并指出证据的边界。这种追踪连接、识别瓶颈的方法，也将用于理解下一章的系统互连。
